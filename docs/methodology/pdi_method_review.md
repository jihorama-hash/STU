# PDI 방법론 검토 및 GPT_Round 적용 방안

## 1. 문서 목적

이 문서는 Dąbkowski et al.의 *Pedestrian Danger Index – a novel surrogate
measure of pedestrian safety at unsignalized crossings*를 검토하고, 무신호
횡단보도 Vision AI 분석 프로젝트 `GPT_Round`에 적용할 수 있는 범위와 구현 원칙을
정리한다.

현재 보유 자료는 분석 가능 구간 합계가 약 29.31분인 8개 영상 묶음이다. 논문이 권고한
정식 PDI 산정기간과 대표성을 충족하지 않으므로, 현 단계에서는 지점의 대표 PDI나
안전등급을 산출하지 않는다. PDI의 상호작용 분류와 핵심 변수 개념을 반영한 간이
분석절차만 시험한다.

## 2. 현재 구현 상태

이 문서의 PDI 절차와 출력 스키마는 목표 방법론이며 현재 구현 설명이 아니다.

| 기능 | 현재 상태 |
|---|---|
| raw tracker trajectory | `tracks.csv`로 구현 |
| 필터·병합 trajectory | 별도 CSV와 보고서로 구현 |
| ROI 순차점유 PET 후보 | `events.json`으로 구현, 잠정값 |
| 국소 일정속도 TTC 후보 | `events.json`으로 구현, 잠정값 |
| raw detection 별도 저장 | 미구현 |
| 보행자 crossing event | 미구현 |
| 보행자-차량 interaction event | 미구현 |
| A0/A1/B0/B1/B2 자동분류 | 미구현 |
| \(S_m,V_m,V_x,a_5\) 실세계 변수 | 미구현 |
| DPD/PDI | 미구현 |

현행 PET는 같은 ROI에서 선행 객체가 이탈한 뒤 후행 객체가 진입하기까지의 시간차다.
현행 TTC는 후행 객체의 ROI 진입 부근에서 두 객체가 국소 일정속도를 유지한다고 가정해
계산한 영상평면 근사다. 두 값 모두 확정된 상충 또는 충돌 지표가 아니라 수동검토가 필요한
잠정 후보다.

## 3. 논문의 목적과 PDI의 성격

논문은 무신호 횡단보도에서 관찰되는 보행자-차량 상호작용의 위험 정도를 연속값으로
평가하기 위해 다음 두 수준의 지표를 제안한다.

- `DPD (Degree of Pedestrian Danger)`: 개별 상호작용의 위험 정도, 0~1
- `PDI (Pedestrian Danger Index)`: 한 지점에서 관찰된 모든 상호작용의 평균 DPD,
  백분율

PDI는 사고 예측모형이 아니라 관찰된 상호작용을 이용한 대리안전지표다. 논문의 DPD
모형은 폴란드 2개 조사 지점의 영상자료와 A1, B1, B2 사례에 대한 전문가·학생
설문평가를 이용해 보정되었다. 한국 현장에 그대로 이전할 수 있는 보정계수로 간주하지
않는다.

## 4. 상호작용의 범위와 분류

### 4.1 상호작용 성립 개념

논문에서 보행자-차량 상호작용은 대체로 다음 조건을 갖는다.

1. 보행자 또는 보행자 집단과 차량이 같은 상호작용 구역에 존재한다.
2. 양자의 궤적이 교차한다.
3. 서로의 존재가 이동 의사결정에 영향을 줄 가능성이 있다.

상호작용 관찰범위는 카메라 시야, 접근속도, 도로구조, 운전자 반응구간을 고려해 지점별로
정의하고 검증한다. 별도 검증 없이 특정 거리 기준을 한국 현장에 그대로 적용하지 않는다.

### 4.2 핵심 시점과 거리

- \(t_m\): 차량 전면이 차량에 가까운 보행자 윤곽 가장자리와 정렬되는 통과시점
- \(S_m\): 통과시점의 보행자-차량 윤곽 간 통과거리(m)
- \(V_m\): 통과시점의 차량속도(m/s)
- \(V_x\): 보행자가 횡단보도에 진입한 시점의 차량속도(m/s)
- \(a_5\): 횡단보도 직전 5m 구간의 최대 차량 감속도(m/s²); 감속은 음수

논문은 보행자를 이동 중인 0.75m × 0.75m 평면 객체로, 차량을 실제 또는 차종별 대표
폭을 가진 직사각형으로 모델링한다. 따라서 \(S_m\)은 중심점 간 거리가 아니라 객체
윤곽을 고려한 여유거리다.

### 4.3 사건 유형

| 유형 | 통과 관계와 상태 | 위험 처리 |
|---|---|---|
| A0 | 차량이 먼저 벗어나는 A형 중 A1·충돌이 아닌 안전분류 | DPD = 0 |
| A1 | 차량축이 보행자보다 앞서 통과하고 \(t_m\)에 양자가 횡단보도에 있음 | 잠재 위험 |
| B0 | 차량이 나중에 벗어나는 B형 중 B1·B2·충돌이 아닌 안전분류 | DPD = 0 |
| B1 | 차량축이 보행자 뒤에서 통과하고 보행자가 아직 횡단보도에 있을 때 차량 진입 | 잠재 위험 |
| B2 | 차량축이 보행자 뒤에서 통과하며 감속 후 보행자가 벗어난 뒤 차량 진입 | 잠재 위험 |
| 충돌 | \(S_m\leq0\) | 충돌 사건 |

A0·B0를 단순히 차량 정지 여부 하나로 판정하지 않는다. 선후관계, 통과거리,
횡단보도 점유상태를 함께 사건 규칙으로 명시해야 한다. 이 분류와 DPD 모형은 직진차량이
횡단보도를 통과하는 상황을 중심으로 보정되었으므로, 회전교차로의 회전차량에 계수를 직접
적용하지 않는다.

## 5. DPD 및 PDI 수식

### 5.1 A1형

\[
DPD_{A1}=\frac{1}{1+\exp(1.196S_m-0.075V_m-0.923)}
\]

통과거리 \(S_m\)이 작고 차량속도 \(V_m\)이 높을수록 위험도가 증가한다.

### 5.2 B1형

\[
DPD_{B1}=\frac{1}{1+\exp(0.862S_m-0.052V_m)}
\]

A1형과 마찬가지로 통과거리가 작고 통과속도가 높을수록 위험도가 증가한다.

### 5.3 B2형 프로젝트 수정식

`GPT_Round`의 B2 개념시험에는 다음 수정식을 사용한다.

\[
\boxed{DPD_{B2}=\frac{1}{1+\exp(0.561a_5+2.713)}}
\]

여기서 \(a_5\)는 감속 시 음수다. 강한 감속일수록 더 작은 음수가 되어
\(DPD_{B2}\)가 증가한다.

| \(a_5\) (m/s²) | 수정식의 \(DPD_{B2}\) 근사값 |
|---:|---:|
| 0 | 0.062 |
| -2 | 0.169 |
| -5 | 0.523 |
| -8 | 0.855 |
| -10 | 0.948 |

이 계수 배치는 프로젝트가 논문의 식 (4), 모형 계수 배치 및 위험곡선의 정합성을 검토해
채택한 수정식이다. 출판사의 공식 정오표라고 표현하지 않는다. 향후 구현에서는
`formula_version = project_corrected_b2_v1`을 저장하고 다음 단위시험을 둔다.

- \(DPD_{B2}(-10)>DPD_{B2}(-5)>DPD_{B2}(0)\)
- 모든 결과가 0과 1 사이인지 확인
- \(a_5=-5\)에서 결과가 약 0.523인지 확인
- 감속도의 절댓값을 양수로 저장했다면 수식 입력 전에 음수 가속도로 변환

### 5.4 지점 PDI

\[
PDI=\frac{\sum DPD_{A1}+\sum DPD_{B1}+\sum DPD_{B2}}
{N_{IAB}}\times100\%
\]

\(N_{IAB}\)는 A0, A1, B0, B1, B2를 모두 포함한 지점의 전체 상호작용 수다.
A0와 B0는 분모에 포함하지만 DPD가 0이므로 분자에는 기여하지 않는다. 전체 분모가
확보되지 않으면 이 식을 계산하지 않는다.

## 6. 정식 PDI 적용조건

정식 PDI를 계산하려면 최소한 다음 조건을 충족해야 한다.

1. 보행자 및 차량의 완전하고 안정적인 궤적
2. 횡단보도와 차량 접근구간의 검증된 실세계 좌표변환
3. \(S_m\)의 윤곽 기반 실거리 산정
4. \(V_m,V_x,a_5\)의 검증된 산정
5. A0/A1/B0/B1/B2의 일관된 분류
6. 모든 상호작용을 포함하는 신뢰성 있는 분모 \(N_{IAB}\)
7. 분석기간과 시간대의 대표성

논문은 12일 연속자료를 바탕으로 3~12일 표본을 비교했고, 평균 PDI의 표준오차가 5%
미만이 되도록 최소 4일 조사를 권고했다. 논문 연구에서는 속도를 레이저 장비로 검증했고
횡단보도 부근 속도오차는 1km/h 이내, 위치오차는 0.1m 이내였다. 이 값은
`GPT_Round`가 현재 달성한 정확도가 아니다.

## 7. 약 29.31분 영상자료의 적용 한계

현재 8개 영상은 객체 검출·추적과 사건 산출 절차의 시험에는 사용할 수 있지만 정식 PDI
조사로 볼 수 없다.

- 최소 4일 권고기간에 크게 미달한다.
- 첨두·비첨두, 요일, 조도, 날씨의 대표성을 확보하지 못한다.
- 유형별 사건 수가 적거나 특정 유형이 없을 수 있다.
- 전체 상호작용 분모가 작거나 현재 자동 파이프라인에서 누락될 수 있다.
- 궤적·속도·감속도·통과거리 오차가 논문 수준으로 검증되지 않았다.
- 폴란드 자료와 설문으로 보정된 계수의 한국 현장 외적 타당성이 확인되지 않았다.
- 현행 자료의 회전차량에는 DPD 계수를 직접 적용할 수 없다.

따라서 현재 자료에서 계산하는 시험값에는 지점 `PDI`라는 확정 명칭을 사용하지 않는다.
조건을 충족한 개별 사건에만 `provisional_dpd` 또는
`PDI-concept screening value`로 표시하고, 지점 안전등급이나 지점 간 우열 판정에는
사용하지 않는다.

## 8. PDI 개념 반영형 간이분석 절차

### 8.1 목적

- 현행 검출·추적 결과로 보행자-차량 상호작용 후보를 재현할 수 있는지 확인
- A/B 선후관계와 A0/A1/B0/B1/B2 자동분류 가능성 확인
- \(S_m,V_m,V_x,a_5\) 또는 명확한 대리변수의 산출 가능성 확인
- 정식 PDI를 위해 필요한 추가 자료와 보정 식별

### 8.2 단계

1. **분석 가능성 검사**
   - 횡단보도, 차량 접근구간, 정지선 및 차로 정의
   - Homography와 거리·속도 검증상태 기록
   - 보행자와 관련 차량의 유효 궤적이 모두 확보된 사건만 후보화
2. **상호작용 후보 생성**
   - 보행자 crossing event마다 접근차량 연결
   - 궤적 교차 가능성, 시간 중첩 및 접근방향으로 무관차량 제외
   - 필터 전 후보와 제외사유 보존
3. **선후관계와 사건상태 산출**
   - 차량 선행이면 A, 보행자 선행이면 B로 구분
   - 차량 정지, 보행자 점유, 차량 진입시점 산출
   - 자동 유형과 판정근거 저장
4. **간이 위험특성 산출**
   - 실세계 좌표가 검증되면 \(S_m,V_m,V_x,a_5\) 산출
   - 검증되지 않으면 reference-pixel 최소거리, 프레임 통과시차, 픽셀 속도변화율을
     별도 대리변수명으로 저장
   - 잠정 PET/TTC, 최소거리, 감속행태 및 양보 여부 병행 제시
5. **수정식 시험 적용**
   - A1/B1/B2가 수동검토로 확인되고 실세계 변수 품질이 확보된 사건에만
     `provisional_dpd` 계산
   - B2에는 `project_corrected_b2_v1` 사용
   - 전체 분모가 불완전하면 지점 PDI 미계산
6. **수동검증**
   - 8개 영상의 모든 보행자 횡단과 관련 차량 판독
   - 후보 재현율, 유형 일치율, 변수 오차 및 제외율 보고
7. **결과보고**
   - 유형별 건수와 변수분포 우선 보고
   - 잠정 DPD는 개별 사건 시험값으로만 제시
   - 표본기간, 좌표보정, 궤적 품질, 자동분류 한계를 함께 표시

위 단계의 crossing event, interaction pairing 및 자동 유형분류는 아직 구현되지 않았다.

### 8.3 목표 최소 출력항목

| 필드 | 설명 |
|---|---|
| `interaction_id` | 보행자-차량 상호작용 식별자 |
| `pedestrian_track_id`, `vehicle_track_id` | 양측 궤적 ID |
| `interaction_type_auto` | 자동분류 A0/A1/B0/B1/B2/미분류 |
| `interaction_type_reviewed` | 수동검토 확정유형 |
| `tm_s` | 통과시점 |
| `sm_m` | 윤곽 기반 통과거리; 미검증 시 null |
| `vm_mps`, `vx_mps` | 통과 및 보행자 진입시 차량속도 |
| `a5_mps2` | 5m 접근구간 최대 감속도, 감속 음수 |
| `pet_s`, `ttc_s` | 정의와 검증상태를 표시한 병행 잠정지표 |
| `min_distance_m` | 실세계 최소거리; 미검증 시 null |
| `min_distance_reference_px` | 기준영상 픽셀 대리변수 |
| `yielding_state` | 양보·정지·비양보 상태 |
| `provisional_dpd` | 조건을 충족한 사건의 시험 DPD |
| `formula_version` | 수식 버전 |
| `coordinate_system`, `unit` | 좌표계와 단위 |
| `quality_flags` | 누락, 보간, 좌표·속도 검증상태 |
| `exclusion_reason` | 계산 제외사유 |

이 표는 목표 스키마다. 현재 `roundabout.schema.ConflictEvent`와 `events.json`이 이 필드를
제공한다고 해석하지 않는다.

## 9. 구현 원칙

1. PDI 계산보다 검출·추적·상호작용쌍 관측품질을 먼저 검증한다.
2. raw detection, raw tracker trajectory, 필터·병합 trajectory, 사건 후보 및 최종
   사건을 별도로 보존한다.
3. source pixel, reference pixel, world coordinate를 혼용하지 않는다.
4. \(a_5\)의 부호와 단위를 설정·스키마·시험에 명시한다.
5. B2 수식은 `project_corrected_b2_v1` 하나로 명확히 버전 관리한다.
6. \(N_{IAB}\)의 완전성이 검증되지 않으면 PDI를 산출하지 않는다.
7. 약 29.31분 결과에는 대표성 또는 지점 안전수준을 주장하지 않는다.
8. 한국 현장계수를 재보정하기 전에는 논문 DPD를 탐색적 참고값으로 취급한다.
9. 회전차량에는 기존 DPD 계수를 직접 적용하지 않는다.
10. 임계값 및 품질 게이트 변경은 근거와 전후 결과를 기록하고 승인받는다.

## 10. 향후 정식 적용 보완과제

- 최소 4일 이상이며 주요 시간대를 포함하는 대표 영상 확보
- 국내 무신호 횡단보도의 A0/A1/B0/B1/B2 분류 적합성 검토
- 윤곽 기반 \(S_m\) 산정과 현장 실측 검증
- 차량속도 및 감속도의 독립 장비 검증
- 한국 전문가와 이용자를 대상으로 한 위험도 평가 및 계수 재보정
- 아파트 단지, 학교 캠퍼스, 이면도로, 공단 등 환경별 이질성 검토
- 회전차량, 이륜차, 자전거·PM 및 보행자 집단의 별도 모형 검토
- PET, TTC, 최소거리, 양보행태와 DPD 간 수렴·판별 타당성 검증
- 시설개선 전후 동일 조건 반복조사를 통한 민감도 검증

## 11. 현재 적용 결론

PDI는 무신호 횡단보도에서 통과거리, 차량속도 및 감속행태를 하나의 상호작용 위험값으로
결합한다는 점에서 `GPT_Round`의 장기 분석체계에 유용하다. 다만 현재 약 29.31분의
영상 묶음에서는 정식 PDI를 산출할 수 없다.

현 단계에서는 A/B 선후관계와 A0/A1/B0/B1/B2 분류 개념을 향후 사건분석 설계에
반영하고, PDI 입력변수의 산출 가능성과 품질을 시험한다. 조건을 충족한 일부 사건에 한해
B2 프로젝트 수정식을 포함한 잠정 DPD를 계산한다. 그 결과는 정식 PDI나 지점
안전등급이 아니라 후속 분석 설계를 위한 탐색적 결과로만 사용한다.
