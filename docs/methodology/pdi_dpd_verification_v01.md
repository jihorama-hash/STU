## 1. 결론 요약

1. **식(4)의 계수 2개가 전치되어 있다.** 논문 표기 `DPD_B2 = 1/(1+e^(2.713·a₅+0.561))`는 논문 자신의 Figure 7·Figure 8·Table 3과 모순되며, 올바른 형태는 **`DPD_B2 = 1/(1+e^(0.561·a₅+2.713))`** 이다. 근거는 §2.3에 4개 제시하며, 그중 하나는 반박 불가능하다.
2. 식(2)·식(3)·식(5)는 **오류 없음**. 식(5)는 Table 3 수치로 소수 셋째 자리까지 재현된다.
3. 이 논문의 진짜 기여는 PDI라는 이름이 아니라 **① 상충을 이진(위험/안전)이 아닌 연속(0~1)으로 바꾼 것**, **② 분모를 위험 상충이 아니라 전체 상호작용으로 잡은 것**, **③ TTC/PET를 전혀 쓰지 않고 관측 3변수만으로 모든 상호작용에 값을 부여한 것** 세 가지다. 셋 모두 본 프로젝트가 01번 문서에서 공백(C-2)으로 지목한 지점을 정면으로 겨냥한다.
4. 다만 **DPD는 설문으로 보정된 "인지위험(perceived risk)" 모형이지 상해위험 모형이 아니다.** 폴란드 계수를 그대로 한국에 쓰는 것은 방법론적으로 성립하지 않는다. 한국형 PoC는 **계수 재보정을 명시적 과업으로 포함**해야 하며, 그것이 본 과제의 학술적 기여가 된다.
5. 한국 적용 시 손봐야 할 최대 급소는 **식(4)의 구조**다. 감속도 a₅ 단독 모형은 "일찍 부드럽게 감속한 안전 운전"과 "아예 감속하지 않은 위험 통과"를 **둘 다 a₅≈0 → DPD≈0.06으로 동일 처리**한다. 2022.7.12 이후 일시정지 의무가 있는 한국에서 이 구조는 그대로 쓸 수 없다. (§5.3)

## 2. 식(4) 오타 검증

### 2.1 논문의 DPD 함수 3종 (원문 표기)

| 유형 | 정의 | 식 | 변수 |
|---|---|---|---|
| A1 | 차량축이 보행자 **앞**, 통과 시점에 보행자·차량 모두 횡단보도상 | 식(2) `DPD_A1 = 1/(1+e^(1.196·S_m − 0.075·V_m − 0.923))` | S_m [m], V_m [m/s] |
| B1 | 차량축이 보행자 **뒤**, 보행자가 아직 횡단보도상일 때 차량 진입 | 식(3) `DPD_B1 = 1/(1+e^(0.862·S_m − 0.052·V_m))` | S_m, V_m |
| B2 | 차량이 감속하여, 보행자가 횡단을 마친 뒤 진입 | 식(4) `DPD_B2 = 1/(1+e^(2.713·a₅+0.561))` ← **오타** | a₅ [m/s²] |

- `S_m` : 통과 시점(t_m, 차량 전면이 보행자 외형의 가까운 가장자리와 일치하는 순간)의 **이격거리**
- `V_m` : 통과 시점의 **차량 속도**. S_m=0이면 충돌하게 되는 속도
- `a₅` : 횡단보도 직전 상류 **5 m 구간의 최대 감속도**. 감속이므로 **음수**
- `S_m ≤ 0` 이면 상호작용이 아니라 **충돌(collision)**

### 2.3 식(4)는 전치되어 있다 — 근거 4건

**근거 ①(결정적) 치역 모순.** 원문 표기식은 a₅ ≤ 0 구간에서 치역이 **[0.363, 1.000]** 이다. 즉 DPD_B2가 0.363보다 작아지는 것이 원리상 불가능하다. 그런데 논문이 보고한 값은 다음과 같다.

| 출처 | 보고값 | 원문식 하한 0.363과 비교 |
|---|---|---|
| 본문 (보정표본 n=19) 평균 | 0.262 | **불가능** |
| 본문 (보정표본 n=19) 중앙값 | 0.200 | **불가능** |
| Figure 8, Warsaw_POW 유형평균 | 0.051 | **불가능** |
| Figure 8, Wrocław_CEN 유형평균 | 0.064 | **불가능** |
| Table 3, ΣDPD_B2 / n = 201.67 / 3954 | 0.051 | **불가능** |

네 개의 독립적인 보고값이 모두 원문식의 하한 아래에 있다. 이는 반박의 여지가 없다.

**근거 ② Figure 7 곡선 형상.** Fig.7은 a₅ = −10에서 DPD≈0.95, a₅ = 0에서 DPD≈0.03, 변곡점(DPD=0.5)이 a₅ ≈ −5인 완만한 S자다.

| a₅ [m/s²] | 원문 표기식 | **전치 수정식** | Fig.7 육안 |
|---|---|---|---|
| 0 | 0.363 | **0.062** | ~0.03 |
| −2 | 0.992 | **0.169** | ~0.17 |
| −4 | 1.000 | **0.385** | ~0.40 |
| −5 | 1.000 | **0.523** | ~0.50 |
| −6 | 1.000 | **0.658** | ~0.62 |
| −8 | 1.000 | **0.855** | ~0.85 |
| −10 | 1.000 | **0.948** | ~0.95 |
| **변곡점** | a₅ = **−0.21** | a₅ = **−4.84** | a₅ ≈ **−5** |

원문 표기식은 a₅ = −1에서 이미 0.896, −2에서 0.992로 포화되어 Fig.7과 전혀 다른 계단함수가 된다.

**근거 ③ Table 2 모형 정의와의 대응.** Table 2의 m_5는 `DPD = 1/(1+e^(b2·X2+b0))`, X2 = a₅ 이다. 즉 **a₅에 곱해지는 것이 b2, 상수항이 b0**이다. 식(4)를 이 틀에 넣으면 b2 = 2.713, b0 = 0.561이 되는데, ①②에 비추어 실제 보정값은 **b2 = 0.561, b0 = 2.713** 이다. 조판 과정에서 두 값의 위치가 바뀐 전형적 형태다.

**근거 ④ 역산의 물리적 타당성.** 수정식으로 보고값을 역산하면 감속도가 실측 가능한 범위에 정확히 들어온다.

|---|---|---|
| 0.262 (보정표본 평균) | −2.99 m/s² | 보통 수준의 제동 |
| 0.200 (보정표본 중앙값) | −2.36 m/s² | 보통 수준의 제동 |
| 0.051 (Warsaw 전체 평균) | +0.38 m/s² | 대다수 B2는 사실상 감속 없음 |
| 0.064 (Wrocław 전체 평균) | −0.05 m/s² | 동상 |

### 2.5 식(5) 검증 — 오류 없음

```
PDI = (ΣDPD_A1 + ΣDPD_B1 + ΣDPD_B2) / NI_AB × 100 [%]
NI_AB = A0 + A1 + B0 + B1 + B2 (안전 상호작용 포함, DPD=0으로 계상)
```

| 지점 | ΣDPD (A1/B1/B2) | NI_AB | 재계산 | 논문 |
|---|---|---|---|---|
| Warsaw_POW | 36.23 / 189.53 / 201.67 | 7,071 | **6.045 %** | 6.05 % |
| Wrocław_CEN | 116.15 / 67.04 / 177.17 | 9,027 | **3.992 %** | 3.99 % |

유형별 평균도 Figure 8과 완전 일치한다(Warsaw A1 0.136 / B1 0.180 / B2 0.051, Wrocław 0.110 / 0.102 / 0.064). **식(5)와 Table 3은 신뢰할 수 있다.**

부수적으로 확인된 사실: 안전 상호작용(A0+B0) 비율이 Warsaw 25.4 %, Wrocław 50.4 %다. PDI 차이(6.05 % vs 3.99 %)의 상당 부분이 **DPD 값 자체보다 분모 구성의 차이**에서 온다. 이는 §4.2의 설계 판단에 직접 영향을 준다.

## 3. 이 논문의 핵심 개념 — 무엇을 가져올 것인가

### 3.1 개념 해부

**(1) 상호작용 분류 알고리즘 (Figure 4).** 통과 시점 t_m에 ① 차량축이 보행자 앞인가 뒤인가(A/B), ② 보행자가 아직 보도에 있었는가 / 차량이 보행자 진입 전에 정지했는가(A0/B0 = 안전), ③ 이격거리 S_m의 부호(≤0이면 충돌)로 5개 유형을 확정한다. **판정 트리가 전부 관측량으로만 구성되어 있어 재현성이 높다.**

**(2) 연속 위험도 DPD.** 선행 DEI 지표(식 1)는 "위험 상호작용 건수 / 전체 건수 × 100 %"로, 위험/안전 경계를 임계값으로 자의적으로 잘랐다. PDI는 그 경계를 없애고 **각 상호작용에 0~1의 연속값**을 준다. 이것이 DEI → PDI의 실질적 진보이며, 본 프로젝트가 v0.2 §5.1에서 SSM 임계값(PET 3s/1.5s 등)의 근거등급을 B·C로 낮게 매길 수밖에 없었던 문제를 우회한다.

**(3) TTC/PET를 쓰지 않는다.** 입력은 S_m, V_m, a₅ 세 개뿐이다. 충돌코스 성립 여부와 무관하게 **모든 상호작용에 값이 생긴다.** 01번 문서 C-2에서 "PET·TTC는 궤적이 교차해야 산출되므로 무신호에서 가장 위험한 상황이 지표에 안 잡힌다"고 지적한 공백에 대한 직접적 해답이다.

**(4) 분모가 전체 상호작용이다.** v0.2 §2.0에서 "조우와 상충은 층위가 다르다, 분모를 상충으로 잡으면 준수율이 왜곡된다"고 정리한 원칙과 정확히 같은 설계다. **우리 지표체계와 PDI는 분모 철학이 일치한다.** 이식이 매끄러운 결정적 이유다.

### 3.2 우리 데이터와의 적합성 — 오히려 유리하다

| 항목 | 원 논문 | 본 프로젝트 | 평가 |
|---|---|---|---|
| 촬영 | 7 m 텔레스코픽 폴, 광각+협각 2대, 경사 시점 | **UAV 수직정사(nadir) 고정호버링** | **유리.** S_m은 평면상 거리이며 nadir는 폐색·투영왜곡이 없어 직접 계측 가능 |
| 검지·추적 | YOLO 이전 세대. 보행자 추적을 자체 알고리즘으로 구현, 궤적 90 %만 완전 | 최신 검지기 + 궤적 추출 완료 | **유리** |
| 위치 정확도 | 차량 궤적 평균 위치오차 10 cm 미만, 보행자·차량 측위오차 0.1 m 이내 | v0.2 V-B 기준은 RMSE < 0.3 m | **불리 — 기준 상향 필요** (§6.2) |
| 관측시간 | 지점당 12일 / 2일 | 30분 단일 세션 | **결정적으로 불리** (§6.1) |
| 시선·자세 정보 | 불필요 (S_m, V_m, a₅만 사용) | nadir라 취득 불가 | **무관 — PDI는 영향 없음** |

v0.2에서 nadir 촬영의 구조적 한계로 명시한 P-9(좌우 주시)·P-10(스마트폰)은 **PDI 산출에 전혀 필요하지 않다.** 즉 우리 데이터의 약점이 이 지표에서는 문제가 되지 않는다. 반대로 강점(평면 거리 정확도)은 그대로 살아난다. **PDI는 우리 데이터 형식에 가장 잘 맞는 지표다.**

## 4. 한국 이식 — 3층 구분

### 4.1 이식 가능 / 재보정 필수 / 신규 개발

| 구분 | 항목 | 판단 근거 |
|---|---|---|
| **그대로 이식** | Figure 4 분류 알고리즘, 3변수(S_m·V_m·a₅) 정의, 통과시점 t_m 정의, 충돌 판정 S_m ≤ 0, 식(5) 집계 구조, 로지스틱 함수형 | 물리적 관측 정의이며 국가·문화에 종속되지 않음 |
| **재보정 필수** | 식(2)(3)(4)의 계수 6개 전부 | 설문 기반 **인지위험** 모형 (§4.2) |
| **신규 개발** | PM·자전거 클래스, 어린이보호구역 분기, 군집(group-pedestrian) 계수 규칙, 보행 억제 플래그, 일시정지 준수 분기 | 원 논문에 없음 |
| **적용 불가** | 회전 차량 상호작용 | 저자가 명시적으로 배제. 단지 내 교차부에는 별도 개발 필요 |

### 4.2 계수를 그대로 쓸 수 없는 이유 — 근거 3건

**(1) DPD는 설문으로 만든 인지위험 모형이다.** 응답자 130~136명에게 영상 클립을 보여주고 위험도를 1~10으로 평정하게 한 뒤, 그 평정치를 0~1로 변환해 비선형회귀로 계수를 적합했다. **응답자 구성은 전문가 약 10 %, 나머지는 학생이다.** 즉 계수는 "폴란드 학생 다수가 이 장면을 얼마나 위험하다고 느끼는가"를 인코딩한 값이다. 논문 스스로 목적을 "predictive analyses가 아니라 site assessments"라고 못 박고 있다.

**(2) 조사 시점이 보행자 우선권 도입 이전이다.** 저자는 결론부에서 "조사는 2021년 이전, 즉 폴란드 도로교통법이 횡단보도 진입 의사가 있는 보행자에게 우선권을 부여하도록 개정되기 전에 수행되었으며, 그 결과 상호작용 유형의 비율이 바뀌었을 것이므로 새로운 조사가 필요하다"고 명시했다. 한국은 **2022.7.12부터 무신호 횡단보도에서 일시정지 의무**가 시행 중이다. 01번 문서 C-1에서 정리한 "양보 → 일시정지" 전환이 바로 이 지점이다. 규범이 다르면 같은 장면에 대한 위험 평정도 달라진다.

**(3) 차량 제원이 다르다.** S_m은 차량 외형 기준으로 산출되며, 논문은 폴란드 실측 차폭(승용·경차 평균 1.76 m·중앙값 1.77 m, 화물·버스 평균 2.49 m)을 사용했다. 보행자 모형도 Neufert 기준 0.75 × 0.75 m 사각형이다. 한국 차종 구성과 보행자 체격으로 재설정해야 S_m 정의가 일관된다.

## 5. 한국형 간이 판단식 — 3-Tier 설계

요청하신 "간이적인 판단식(절차)"을 다음 3계층으로 제안한다. **핵심 판단: 새로운 대체식을 발명하지 말고, 원식을 그대로 쓰되 이용 방식을 계층화하라.** 대체식을 만들면 원 논문의 문헌적 근거를 스스로 버리게 된다.

### 5.1 Tier 0 — P-DPD 직접 적용 (지금 즉시 가능)

폴란드 계수를 **그대로** 적용한 참조 산출. 30분 영상으로 오늘 실행할 수 있다.

```
입력  : 궤적 (완료됨)
절차  : ① t_m 판정 → ② A/B 및 A0/B0/A1/B1/B2 분류(Fig.4)
        → ③ S_m, V_m, a₅ 산출 → ④ 식(2)(3)(4-수정) 적용
        → ⑤ 식(5)로 P-PDI 산출
출력  : 유형별 건수, DPD 분포(히스토그램), 유형별 평균 DPD, P-PDI [%]
```

**허용**: 파이프라인 검증, 분포 형상 확인, 지점 간·개선 전후 **상대 비교**
**금지**: 절대값의 안전등급 해석, 폴란드 지점(6.05 % / 3.99 %)과의 직접 비교 — 계수가 폴란드 인지척도이므로 값의 절대적 의미가 한국에 없다. 리포트에 **"P-PDI(폴란드 계수 기준 참조값)"** 로 명칭까지 고정할 것.

### 5.4 반드시 손봐야 할 구조 — 식(4)의 결함

**이것이 한국 적용의 최대 급소다.**

논문은 B2 모형에서 `V_x`(보행자가 횡단보도에 진입한 순간의 차량 속도)가 "대부분의 경우 유의하지 않다"는 이유로 탈락시키고, 감속도 a₅ 단독의 m_5를 채택했다. 그 결과:

| 상황 | a₅ | 원 모형 DPD_B2 |
|---|---|---|
| 멀리서 미리 알아채고 부드럽게 감속·정지 후 통과 (**모범 운전**) | ≈ 0 | **0.06** |
| 보행자를 보고도 감속 없이 뒤로 스쳐 통과 (**위험 통과**) | ≈ 0 | **0.06** |
| 뒤늦게 발견하고 급제동 | −5 | 0.52 |

**모범 운전과 위험 통과가 같은 값을 받는다.** 폴란드 구법(보행자 우선권 없음) 하에서는 "감속하지 않고 지나감"이 정상 거동이었으므로 V_x가 비유의했을 개연성이 크다. 그러나 **한국은 2022.7.12 이후 일시정지가 의무**이므로, 감속 없이 통과하는 것 자체가 법 위반이자 위험 신호다.

> **권고**: K-DPD의 B2는 **m_1 형태(2변수: V_x, a₅)를 우선 후보로 재검토**하고, V_x의 유의성을 한국 데이터로 다시 판정한다. 유의하지 않게 나오더라도, **정지 여부 이진변수(일시정지 준수)를 추가한 확장모형**을 병행 적합할 것을 권한다. 이 한 가지 수정이 본 과제가 원 논문 대비 갖는 가장 명확한 방법론적 진보가 될 수 있다.

### 5.5 보행 억제 플래그는 그대로 유지한다

PDI도 **상호작용이 있어야 값이 생긴다.** 보행자가 무서워 건너지 못하면 NI_AB가 줄어 PDI가 오히려 좋아 보인다. v0.2 §5.3의 판정 규칙을 **PDI와 병렬로 반드시 유지**한다.

> 상충 0건 + 대기시간 상위 + gap 거부 다수 → "안전"이 아니라 **보행 억제(suppression)**

최종 산출은 항상 **`K-PDI [%] + [보행 억제] 플래그 + L1 적법성 결격 여부`** 3종 병기로 낸다. 단일 숫자로 통합하지 않는다.

## 7. 비판적 검토 — 채택 시 리포트에 반드시 명시할 한계 6가지

1. **인지위험 ≠ 상해위험.** DPD는 설문 평정을 회귀한 값이다. 사고·상해 결과와의 외적 타당도는 논문에서 검증되지 않았다. "DPD 0.5"는 "사망확률 50 %"가 전혀 아니다. 리포트에 이 문장을 고정 수록할 것.
2. **보정 표본이 작다.** A1 27건, B1 26건, B2 19건. 계수의 신뢰구간이 넓을 것이나 논문은 이를 제시하지 않았다. K-DPD 재보정 시 **계수 신뢰구간을 반드시 함께 보고**한다.
3. **식(4)의 구조적 결함** (§5.4). 모범 운전과 무감속 위험 통과가 동일 값을 받는다.
4. **회전 차량 미적용.** 저자가 명시적으로 배제했다. 단지·캠퍼스 내부 교차부에는 그대로 쓸 수 없으며, 적용 시 별도 모형 개발과 별도 설문이 필요하다.
5. **보행 억제 미포착** (§5.5).
6. **PDI 차이의 상당 부분이 분모 구성 차이에서 온다.** Warsaw와 Wrocław의 PDI 격차(6.05 % vs 3.99 %)는 안전 상호작용(A0+B0) 비율 차이(25.4 % vs 50.4 %)와 강하게 연동된다. **PDI를 보고할 때는 반드시 ① NI_AB, ② 유형 구성비, ③ 유형별 평균 DPD를 함께 낸다.** 단일 백분율만 제시하면 오독된다.

## 부록 A. 채택 확정식

```python
import math

def DPD_A1(Sm, Vm):
    """차량축이 보행자 앞. Sm[m] 이격거리, Vm[m/s] 통과시점 속도."""
    return 1.0 / (1.0 + math.exp(1.196*Sm - 0.075*Vm - 0.923))      # 원문 식(2)

def DPD_B1(Sm, Vm):
    """차량축이 보행자 뒤, 보행자 횡단 중 차량 진입."""
    return 1.0 / (1.0 + math.exp(0.862*Sm - 0.052*Vm))              # 원문 식(3)

def DPD_B2(a5):
    """보행자 횡단 완료 후 진입. a5[m/s^2] 상류 5m 최대 감속도(음수).
    주의: 원문 식(4)는 계수 2개가 전치되어 있음. 본 문서 §2.3 근거로 수정."""
    return 1.0 / (1.0 + math.exp(0.561*a5 + 2.713))                 # 식(4) 수정판

def PDI(sum_A1, sum_B1, sum_B2, NI_AB):
    """NI_AB = A0+A1+B0+B1+B2 (안전 상호작용 포함)."""
    return (sum_A1 + sum_B1 + sum_B2) / NI_AB * 100.0               # 원문 식(5)
```
