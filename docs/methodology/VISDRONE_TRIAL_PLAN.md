# VisDrone 도메인 적응 시험 계획서

작성시각: 2026-07-30 15:13 KST  
대상 장비: NVIDIA GeForce RTX 5060 Ti 16GB  
시험 지위: 모델 후보 비교 실험. 품질 게이트 통과 전 전체 영상 분석에 사용하지 않는다.

## 1. 목적

현재 YOLO11m+SAHI 기준선에서 확인된 다음 문제를 VisDrone 도메인 적응으로 개선할 수 있는지
검증한다.

- 소형 보행자의 짧은 검출과 궤적 분절
- 수목·그림자 구간의 보행자 누락
- 드론 부감 시점에서의 클래스 혼동
- 노면표시를 차량으로 장시간 추적하는 고정 오탐

VisDrone은 드론 촬영 소형 객체에 특화된 데이터셋이다. 공식 Ultralytics 설정 기준으로
검출 데이터는 학습 6,471장, 검증 548장, test-dev 1,610장이며 10개 클래스를 사용한다.

- 공식 데이터 저장소: <https://github.com/VisDrone/VisDrone-Dataset>
- Ultralytics 데이터 설명·학습 방법:
  <https://docs.ultralytics.com/datasets/detect/visdrone>

## 2. 핵심 원칙

1. 출처·라이선스·클래스 정의가 불분명한 공개 가중치는 사용하지 않는다.
2. 공식 VisDrone 데이터와 현재 공식 YOLO11m 가중치로 직접 미세조정한다.
3. 원본 YOLO11m 기준선 결과를 덮어쓰지 않는다.
4. DJI_0482의 동일한 150–210초 구간과 동일한 SAHI·ByteTrack 조건으로 비교한다.
5. 자동 통계만으로 합격 처리하지 않고 동일 표본을 육안검증한다.
6. 1 epoch 실측시간을 얻은 뒤 전체 학습 완료시각을 다시 계산한다.
7. 라이선스가 데모의 공개·상업적 이용 범위와 맞는지 확인하기 전에는 내부 연구 시험으로 제한한다.

## 3. 클래스 매핑

원본 VisDrone 클래스와 프로젝트 표준 클래스를 다음처럼 변환한다. 원본 클래스도 결과에
별도 열로 보존한다.

| VisDrone | 프로젝트 클래스 | 처리 |
|---|---|---|
| pedestrian | person | 병합 |
| people | person | 병합하되 원본 라벨 보존 |
| bicycle | bicycle | 유지 |
| car | car | 유지 |
| van | car | `source_class=van` 보존 |
| truck | truck | 유지 |
| tricycle | tricycle | 신규 세부 클래스 |
| awning-tricycle | tricycle | 원본 라벨 보존 |
| bus | bus | 유지 |
| motor | motorcycle | 이름 변환 |

`pedestrian`과 `people`을 별도 추적기로 운용하면 동일인이 두 클래스로 분절될 수 있으므로,
추적 입력 전에 `person`으로 통합한다.

## 4. 실험 구성

### V0 — 현재 기준선

- 모델: COCO 사전학습 YOLO11m
- 결과: `outputs/analysis/baseline/DJI_0482_150_210_yolo11m/`
- 처리시간: 302초
- person 트랙: 99
- person 0.5초 미만: 64.6%
- person 5초 이상: 10

### V1 — 설치·데이터 연기시험

- VisDrone 다운로드 및 YOLO 변환
- 무작위 학습 이미지·라벨 20장 육안검사
- YOLO11m, 1024px, 1 epoch
- 목적: 데이터 경로, 클래스, VRAM, epoch 시간 확인
- 이 결과로 정확도를 판단하지 않는다.

### V2 — 단기 도메인 적응

- V1을 통과했을 때만 실행
- YOLO11m COCO 가중치에서 시작
- 이미지 크기 1024
- 10 epochs
- 자동 mixed precision 사용
- batch는 VRAM 연기시험으로 결정하며 조건을 기록
- best/last 가중치와 학습 곡선 보존

V2 완료 후 DJI_0482 대표 60초를 동일 SAHI+ByteTrack 조건으로 처리한다.

### V3 — 확장 학습

V2가 다음 중 하나를 충족할 때만 총 30 epochs까지 연장한다.

- 수동 person recall이 기준선보다 5%p 이상 개선
- 그림자 문제 표본의 정상 검출이 2건 이상 증가
- 실제 person 트랙을 보존하면서 분절이 20% 이상 감소

단순 검출 수 증가나 ghost 증가만으로는 V3에 진입하지 않는다.

### V4 — 현장 소량 라벨 보완

VisDrone 모델이 드론 소형 객체는 개선하지만 노면표시 오탐이나 현장 그림자 문제를 해결하지
못할 때만 진행한다. 대표 구간에서 오류가 집중된 프레임을 라벨링하여 VisDrone+현장 혼합
미세조정을 별도 계획한다. 이번 1차 시험 범위에는 포함하지 않는다.

## 5. 비교 조건

두 모델의 비교에서는 모델 이외 조건을 고정한다.

| 항목 | 값 |
|---|---|
| 영상 | DJI_0482.MP4 |
| 구간 | 150.0–210.0초 |
| 유효 FPS | 14.985 (`frame-step=2`) |
| SAHI slice | 1024×1024, 15개/frame |
| overlap | 0.20 |
| confidence | 우선 0.15, 추가 PR 곡선은 별도 |
| NMS IoU | 0.50 |
| 추적 | 클래스별 ByteTrack |
| lost buffer | 3.0초 |
| 최소 지속시간 후보 | 0.5초 |
| 이동거리 후보 | 120px, 확정 전 수동검증 |

VisDrone 미세조정 모델의 confidence 분포가 COCO 기준선과 다를 수 있으므로 최종 판정에서는
0.10, 0.15, 0.20의 짧은 임계값 민감도 비교를 추가한다. 같은 모델의 동일 60초 전체를 세 번
추론하지 않고 검출 결과 캐시 또는 짧은 문제구간을 이용한다.

## 6. 평가 지표와 합격 게이트

### 자동 지표

- 클래스별 검출 관측점과 트랙 수
- 트랙 중위·평균 지속시간
- 0.5초 미만 트랙 비율
- 5초 이상 트랙 수
- 순이동거리 120px 미만 트랙 수
- 프레임당 처리시간과 최대 GPU 메모리

### 수동 지표

- person precision/recall
- 차량 precision/recall
- 궤적 정상/분절/ID switch/부분누락
- 수목·그림자 문제구간 recall
- 과속방지 노면표시 고정 오탐 제거 여부
- 오토바이·자전거·보행자 클래스 혼동

### 채택 기준

다음을 모두 충족해야 VisDrone 모델을 Phase B 후보로 채택한다.

1. person recall 85% 이상 또는 기준선 대비 5%p 이상 개선
2. person 궤적 정상률 70% 이상
3. person precision이 기준선보다 3%p 이상 악화되지 않음
4. 노면표시 고정 오탐이 제거되거나 공간·이동 필터로 명확히 제거 가능
5. 처리시간이 기준선의 1.5배 이내
6. 클래스 매핑과 라이선스 검토 완료

## 10. 중단 조건

- 공식 출처 또는 이용 조건을 확인할 수 없음
- 데이터 변환 후 클래스 수·라벨 범위가 공식 정의와 불일치
- 1024px 최소 batch에서도 CUDA OOM 반복
- 학습 loss가 NaN이 되거나 라벨 오류가 다수 발견
- V2가 보행자 recall을 개선하지 못하고 ghost만 증가
- 기준선 대비 person precision이 3%p 넘게 하락
- 데모 공개 범위와 모델·데이터 라이선스가 충돌

중단 시 기존 YOLO11m 기준선을 보존하고, 실패 원인과 다음 후보를 결과서에 기록한다.
