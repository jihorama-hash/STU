## 0. 이 문서의 위치와 사용 규칙

**역할 분담**

| 문서 | 담는 것 | 바뀌는 빈도 |
|---|---|---|
| 지표정의서 v0.3 | **왜** 그렇게 정의하는가 (근거·논리·한계) | 낮음 |
| **본 구현사양서** | **어떻게** 계산하는가 (입출력·의사코드·스키마) | 중간 |
| 파라미터 YAML | **어떤 값**으로 계산하는가 (상수·임계값) | 높음 |

**절대 규칙 5가지**

1. **파라미터를 코드에 하드코딩하지 않는다.** 모든 상수는 YAML 에서 읽는다. YAML 에 없는 값이 필요하면 코드에 넣지 말고 YAML 에 추가한 뒤 근거등급을 붙인다.
2. **모든 산출 파일에 provenance 를 붙인다** (§8). provenance 없는 수치는 리포트에 쓸 수 없다.
3. **Stage 1 검증 게이트를 통과하기 전에는 지표를 산출하지 않는다** (§9.1). 게이트 미통과 상태에서 산출을 강행하면 산출물에 `GATE_FAILED` 플래그를 박고 값을 `null` 로 만든다.
4. **결과가 좋아지는 방향으로 파라미터나 ROI 를 조정하지 않는다.** 변경이 필요하면 근거를 남기고 민감도 분석을 함께 낸다.
5. **표본 미달 지표는 0 이나 빈칸이 아니라 `INSUFFICIENT_SAMPLE` 사유 코드로 출력한다** (§6.3).

## 2. 영상 정합과 좌표 변환

### 2.1 영상 정합 (`39_register_frames.py`) — 최우선 실행

8클립은 **동일 호버링 위치**다(2026-08-09 확인). 이는 캘리브레이션을 단순화하지만, 동시에 **호버 표류 보정을 필수로 만든다.** 4K 로 가로 60 m 를 담으면 GSD ≈ 0.0156 m/px 이고 V-B 게이트 0.10 m 는 **6.4 px** 에 불과하다. 기체가 1 m 표류하면 64 px — 게이트 허용치의 10배다.

```
1. 기준 프레임 선정
   ref = 화질 양호 + 노면 가림 최소인 프레임 1개 (clip_id, frame 을 기록)

2. 고정 기준점 지정 (수동, 6개 이상)
   횡단보도 스트라이프 모서리 / 정지선 끝 / 맨홀 / 차선 파선 끝 / 연석 모서리
   ※ 차량·보행자·그림자는 절대 쓰지 않는다
   ※ 화면 네 귀퉁이에 고르게 분포시킨다 (한쪽에 몰리면 회전 성분이 안 잡힌다)

3. 프레임별 변환 추정
   for each frame:
       pts = track_reference_points(frame)      # ECC / ORB+RANSAC / LK 광류
       M   = estimate_transform(pts, ref_pts, model='similarity')
       # 평행이동+회전+스케일. 필요 시 'homography' 로 승격
   결측 프레임은 시간축 보간 + 이상치 median filter

4. 적용
   좌표만 역변환하는 방식을 기본으로 한다 (영상 전체 워핑은 저장용량·화질 손실)
   x_ref, y_ref = M^-1 · (x_px, y_px)
   ※ 검지·추적을 다시 돌릴 필요는 없다. 궤적 좌표만 변환하면 된다

5. 잔차 산출 (V-A2)
   residual_rmse_px  = RMSE(정합 후 기준점 - ref_pts)
   residual_rmse_m   = residual_rmse_px * scale_m_per_px
   합격 기준: residual_rmse_m < registration_residual_tol_m (YAML, 0.05 m)
   정합 전 잔차도 함께 보고한다 (개선 폭이 곧 이 작업의 근거)
```

**출력**: `registration/transforms_{clip_id}.npz` (프레임별 M), `registration/residuals.csv`, `registration/reference_frame.png`(기준점 표시)

> **진단 힌트**: 정합 전 잔차가 크게 나온다면, 지금까지 지표가 흔들린 원인이 검지·추적이 아니라 **여기**일 가능성이 높다. 정합 전후로 기존 산출물(예: 근접거리 분포)이 얼마나 달라지는지 한 번 비교해 보면 판단이 선다.

### 2.2 좌표 변환 (`42_geometry.py`)

**입력 좌표는 정합된 기준 프레임 좌표계(`x_ref`, `y_ref`)다.** 원본 화소 좌표를 직접 쓰지 않는다.

```
scale_from_optics(H, p, f):
    return (H * p) / f            # [m/px]

verify_scale(clip, refs):
    # refs: [(픽셀거리, 실측거리[m], 라벨), ...] 최소 3개
    errs = [abs(px * s - m) / m for px, m, _ in refs]
    return max(errs)              # V-A 합격 기준: < scale_error_tol (YAML)
```

- 8클립이 동일 위치이므로 **`s` 는 하나만 산출하고 ROI 도 1벌만 만든다**
- `verify_scale` 이 불합격이면 **4점 호모그래피로 전환**한다. 전환 여부를 `clips.yaml` 의 `notes` 에 기록
- 대상 횡단보도가 화면 중앙 `center_fraction`(YAML, 기본 0.60) 밖에 있으면 `distortion_risk = True` 를 표시하고, 왜곡 보정 없이 산출한 지표에 경고 플래그를 붙인다

**영역 판정 유틸**: `point_in(region, x, y)` 는 shapely 폴리곤 포함 판정. 경계선상은 포함으로 처리한다.

## 3. 전처리 (`41_preprocess_tracks.py`)

### 3.1 평활화

```
for each (clip_id, track_id):
    x_s, y_s = savgol(x_m, y_m, window=smooth_window_s * fps, polyorder=2)
    vx = d(x_s)/dt ;  vy = d(y_s)/dt ;  speed = hypot(vx, vy)
    ax = d(vx)/dt  ;  ay = d(vy)/dt
    a_tangential = (vx*ax + vy*ay) / max(speed, eps)   # 진행방향 가감속
    heading = atan2(vy, vx)
```

- 윈도우 프레임 수는 홀수로 보정. 트랙 길이가 윈도우보다 짧으면 `short_track = True` 표시 후 평활화 없이 통과
- **a₅ 에는 `a_tangential` 을 쓴다** (벡터 크기 |a| 를 쓰면 곡선 주행의 구심가속도가 섞인다)

### 3.2 트랙 클래스 확정 (지표정의서 §1.3)

```
def finalize_class(track_frames):
    score = defaultdict(float)
    for f in track_frames:
        score[f.cls_raw] += f.conf
    cls_final = argmax(score)
    flicker_ratio = mean(f.cls_raw != cls_final for f in track_frames)

    groups = {c: class_group(c) for c in set(f.cls_raw)}   # 'ped' | 'veh'
    cross_group = len(set(groups.values())) > 1

    unstable = (flicker_ratio > flicker_ratio_max) or cross_group
    return cls_final, flicker_ratio, unstable
```

산출: `track_id, cls_final, flicker_ratio, class_unstable, n_frames, duration_s, path_length_m`

`class_unstable=True` 인 트랙이 관여한 모든 상호작용에 `review_required = True` 를 전파한다.

### 3.3 군집 구성 (지표정의서 §1.6)

```
def build_groups(ped_tracks, t):
    # 시각 t 에서 조건을 만족하는 보행자쌍으로 그래프를 만들고 연결성분을 군집으로
    edges = [(i,j) for i,j in pairs(ped_tracks_at(t))
             if dist(i,j) <= group_dist_m
             and angdiff(heading_i, heading_j) <= group_angle_deg
             and abs(speed_i - speed_j) <= group_speed_diff_ms]
    comps = connected_components(edges)
    return comps

# 시간 지속 조건: 동일 구성원 집합이 group_min_duration_s 이상 유지될 때만 군집 확정
# 확정 군집에 ped_entity_id 부여. 단독 보행자도 ped_entity_id 를 갖는다(n=1)
```

**출력 필드**: `ped_entity_id, member_track_ids, n_members, formed_at, dissolved_at`

### 4.2 통과시점 t_m

```
def passing_moment(v, p):
    # 공통 시간축(프레임 교집합)에서
    for t in common_times:
        e_h  = unit(heading_v(t))
        F    = pos_v(t) + (L_v/2) * e_h                 # 차량 전면 중심
        d_long[t] = dot(pos_p(t) - F, e_h) - w_p/2      # 보행개체 근접 가장자리 기준

    # 부호가 (+) → (−) 로 바뀌는 첫 지점을 선형보간
    idx = first_sign_change_pos_to_neg(d_long)
    if idx is None:
        return None, 'NO_TM'                            # 상호작용 아님
    t_m = linear_interp_zero(d_long, idx)
    return t_m, None
```

- `L_v` 는 클래스별 차장(YAML `vehicle_length_m`)
- **모든 값은 t_m 에서 선형보간으로 산출**한다. 가장 가까운 프레임으로 반올림하지 않는다 (30 fps 에서 30 km/h 면 1프레임이 0.28 m)

### 4.3 3변수

```
def compute_metrics(v, p, t_m, cw):
    e_h = unit(heading_v(t_m)) ;  e_l = perp(e_h)
    lateral = abs(dot(pos_p(t_m) - pos_v(t_m), e_l))
    S_m = lateral - W_v/2 - w_p/2
    V_m = speed_v(t_m)

    a5_frames = [t for t in times_v if in_region(A5[dir_v], pos_v(t))]
    if len(a5_frames) < a5_min_frames:
        a5, a5_valid = None, False
    else:
        a5, a5_valid = min(a_tangential(t) for t in a5_frames), True

    collision = (S_m <= 0)
    return S_m, V_m, a5, a5_valid, collision
```

- 군집이면 `pos_p` 는 §4.4 의 A/B 판정 결과에 따라 최선두(A) 또는 최후미(B) 구성원의 위치를 쓴다. **A/B 판정을 먼저 하고 S_m 을 계산**한다
- `collision = True` 는 실제 사고이거나 측위 오차다. **반드시 `review_required = True` 를 달고 육안 확인 목록에 올린다**

### 4.4 A/B 및 유형 분류

```
def classify(v, p, t_m, cw):
    # A/B : t_m 시점에 보행개체가 차량 진행축(궤적 중심선)을 이미 통과했는가
    s = signed_dist_to_vehicle_path(pos_p(t_m), v)      # 보행 진행방향 기준 부호거리
    side = 'A' if s < 0 else 'B'    # s<0: 아직 차량 경로 도달 전 → 차량이 앞을 지남

    if side == 'A':
        if in_region(CW, pos_p(t_m)) or in_region(CW_ext, pos_p(t_m)):
            return 'A1'
        else:
            return 'A0'            # 아직 보도(SW/WZ)에 있었음 → 안전
    else:
        if vehicle_stopped_before(p_entry_time, v):     # 보행개체 차도 진입 전 정지
            return 'B0'                                  # 안전
        if pedestrian_still_on_cw(t_m, p):
            return 'B1'
        else:
            return 'B2'                                  # 횡단 완료 후 차량 진입
```

**보조 정의**
- `vehicle_stopped_before(t_entry, v)` : 보행개체가 CW 에 진입한 시각 이전에 차량이 `v ≤ v_stop` 를 `τ_stop` 이상 유지한 적이 있는가
- `pedestrian_still_on_cw(t_m, p)` : t_m 시점에 보행개체가 `CW ∪ CW_ext` 안에 있는가
- **`side` 판정의 부호 규약은 반드시 단위테스트로 고정**한다 (§11 T-3). 부호가 뒤집히면 A↔B 가 전부 바뀌어 결과가 무의미해진다

> **근거등급 B**: 원 논문 Figure 4 의 경계 조건(특히 A0 와 B0 의 구분 시점)을 원문으로 재확인하기 전까지 잠정이다. 확정 시 본 절과 지표정의서 §2.3 을 함께 개정한다.

### 4.6 DPD 산출

```python
import math

def dpd_a1(S_m, V_m):                    # 원문 식(2)
    return 1.0 / (1.0 + math.exp(1.196*S_m - 0.075*V_m - 0.923))

def dpd_b1(S_m, V_m):                    # 원문 식(3)
    return 1.0 / (1.0 + math.exp(0.862*S_m - 0.052*V_m))

def dpd_b2(a5):                          # 식(4) 수정판
    # 주의: 원문 식(4)는 계수 2개가 전치되어 있음.
    # 근거: claude/03_PDI_DPD_검증_및_한국형PoC_v01.md §2.3
    return 1.0 / (1.0 + math.exp(0.561*a5 + 2.713))

DPD_BY_TYPE = {
    'A0': lambda r: 0.0,
    'B0': lambda r: 0.0,
    'A1': lambda r: dpd_a1(r.S_m, r.V_m),
    'B1': lambda r: dpd_b1(r.S_m, r.V_m),
    'B2': lambda r: dpd_b2(r.a5) if r.a5_valid else None,
}
```

**계수는 YAML `dpd_coefficients` 에서 읽는다.** 위 코드는 기본값 예시이며, K-DPD 재보정 시 YAML 만 교체하면 되도록 구현한다.

**단위 주의**: `V_m` 은 **m/s**, `a5` 는 **m/s²** (감속은 음수). km/h 를 넣으면 값이 조용히 틀린다 — 입력 단위 assert 를 넣는다.

## 5. 조우와 준수도 (`44_encounters.py`)

### 5.1 정지판단선

```
def d_stop(v0):
    return v0 * t_pr + v0**2 / (2 * a_dec)      # t_pr, a_dec ← YAML

def encounter_check(v, p, cw):
    v0  = mean_speed(v, between=D30, and_=D20)
    Ds  = d_stop(v0)
    t0  = 차량이 CW 진입 가장자리로부터 상류 Ds 지점을 통과한 시각
    if t0 is None: return False, None
    at_wz_or_cw = in_region(WZ, pos_p(t0)) or in_region(CW, pos_p(t0))
    return at_wz_or_cw, {'t0': t0, 'D_stop': Ds, 'v0': v0}
```

- **민감도 병행 산출**: `t_pr = 2.5 s`(AASHTO) 와 `1.5 s` 두 값으로 각각 조우 건수를 세어 함께 보고한다
- **횡단 의사 없음 배제**: WZ 체류 중 연석 방향 접근속도 < `intent_speed_ms` 가 `intent_duration_s` 이상 지속 → 조우에서 제외, `excluded_no_intent = True`. 이 판정의 **오분류율을 Stage 2 육안 검토에서 반드시 보고**한다

### 5.2 종속 정지

```
dependent_stop = 같은 차로 선행 차량이 t0 이전에 CW 상류에서 정지 상태였고,
                 본 차량이 그 후미에서 정지한 경우
```
→ 준수도 분모·분자에서 제외. 상호작용으로는 정상 계수.

### 5.3 준수도 판정

```
def compliance(v, cw):
    seg = 차량 궤적 중 SL 상류 ~ CW 진입 전 구간
    if exists t in seg: speed(t) <= v_stop  for duration >= tau_stop:
        return 'STOP'
    if min(speed in seg) <= v_yield_max and 보행개체가 먼저 CW 를 통과:
        return 'YIELD'
    return 'NO_YIELD'
```

산출: `SR = STOP / N_E1`, `YR = YIELD / N_E1`, `NR = 1 − SR − YR`
분모 `N_E1` 에서 `dependent_stop` 과 `event_class == 'E-2x'` 는 제외.

**v_stop 민감도**: 0.2 / 0.3 / 0.5 m/s 세 값의 SR 을 모두 산출해 변동폭을 보고한다 (V-E4).

## 6. 지표 산출 (`45_indicators.py`)

### 6.1 PDI / JDI

```
base = interactions[(event_class=='I') & (~turning)]
NI   = len(base)
PDI  = base.dpd.sum() / NI * 100          # a5_valid=False 인 B2 는 §6.2 규칙

jay  = interactions[(event_class=='E-2x') & (~turning)]
JDI  = jay.dpd.sum() / len(jay) * 100
```

**PDI 출력 시 항상 함께 낸다 (지표정의서 §5.1)**
- `NI` (분모)
- 유형 구성비 `n_A0, n_A1, n_B0, n_B1, n_B2` 와 각 비율
- 유형별 평균 DPD `mean_dpd_A1, mean_dpd_B1, mean_dpd_B2`
- 안전 상호작용 비율 `(n_A0 + n_B0) / NI`

**출력 명칭 강제**: 컬럼명·리포트 표기 모두 `P_PDI_pct` / "P-PDI (폴란드 계수 기준 참조값)". `PDI` 라는 단독 명칭을 쓰지 않는다.

### 6.2 결측 처리

| 상황 | 처리 |
|---|---|
| B2 인데 `a5_valid = False` | DPD 산출 불가. **분모 NI 에는 포함**하되 분자에서 제외하고, `n_B2_invalid` 를 별도 보고. 비율이 5 % 를 넘으면 경고 |
| `collision = True` | DPD 산출하지 않음. 별도 목록으로 보고 + 육안 확인 필수 |
| `class_unstable = True` | 산출은 하되 `review_required` 표시. 확정 전 결과는 잠정 |
| `turning = True` | PDI·JDI 집계 제외. 준수도·노출에는 포함 |

suppression_flag = (

| `reviewer`, `reviewed_at` | 수동 | |

**판독 지침 (서식 첫 시트에 수록)**
1. **먼저 영상을 끝까지 한 번 훑어 상호작용을 전부 기록**한다. 자동 검출 표식이 없어도 차량과 보행개체가 스치면 행을 추가한다 (`MANUAL_ADDED`)
2. 그 다음 자동 검출 행을 하나씩 확인해 `human_type` 을 채운다
3. 검지 문제(박스 없음·ID 변경·클래스 오류)는 발견 즉시 `detection_issue` 에 기록한다. 이것이 Stage 1 의 표본 검지율을 사건 단위로 보완한다
4. 애매하면 `confidence = 애매` 로 두고 넘어간다. 억지로 판정하지 않는다
5. **회전부는 이번 회차 제외**

### 7.3 집계 스크립트

`46_validation.py` 가 `review_sheet_*.xlsx` 를 읽어 산출:

```
V-F  유형 일치율     = mean(auto_type == human_type)  [AUTO 행만]
     Cohen's κ 병기
V-G  상호작용 회수율 = AUTO 행 수 / (AUTO + MANUAL_ADDED 행 수)
     단, human_type == 'NOT_INTERACTION' 인 AUTO 행은 분자에서 제외
     오검출률       = NOT_INTERACTION 행 수 / AUTO 행 수
검지 이슈 집계       = detection_issue 유형별 건수 / 총 행 수
```

gate = {

**T-1 자동 진단 (전수, 게이트 아님)** — `track_health.csv` 로 출력

| 지표 | 정의 | 경고 임계 |
|---|---|---|
| `n_tracks` | 클립별 트랙 수 | — |
| `frag_ratio` | 수명 < 1 s 인 트랙 비율 | > 0.30 |
| `gap_ratio` | 트랙 내 프레임 공백 프레임 수 / 총 프레임 | > 0.10 |

| `id_switch_candidates` | 서로 다른 track_id 가 시공간적으로 이어지는 후보 쌍 수 | > 0.1 건/트랙 |
| `overlap_dup_rate` | 동일 위치·시각에 2개 이상 트랙이 겹치는 비율 | > 0.05 |

**V-B 표본 라벨링 절차**: 8클립에서 균등 무작위로 100프레임 추출 → 각 프레임의 모든 객체를 사람이 라벨 → 자동 검출과 헝가리안 매칭(IoU ≥ 0.3) → `CW` 구역 내 객체에 대해 중심좌표 RMSE, 검지율, 오검지율 산출.

| T-6 | `finalize_class` | conf 가중 다수결이 프레임 수 다수결과 다른 사례에서 conf 쪽 채택 |
| T-7 | `build_groups` | 3인 사슬(1-2, 2-3 연결, 1-3 미연결)이 1개 군집으로 |
| T-8 | 단위 | V_m 에 km/h 를 넣으면 assert 실패 |
