### 0.3 세 가지 원칙

**원칙 1 — 30분 영상은 진단 결과를 내는 데이터가 아니라 진단 절차를 검증하는 데이터다.**
`×`와 `△`(표본 미달 시) 지표는 결과값을 리포트에 쓰지 말고 "본 관측으로 판단 불가"로 **명시 출력**해야 한다. 이 원칙을 파이프라인에 강제로 심어두지 않으면, 프로토타입이 그대로 실무에 나갔을 때 과소표본 결과가 확정 진단처럼 읽힌다.

**원칙 2 (v0.3 신설) — 위험은 이진(위험/안전)이 아니라 연속(0~1)으로 다룬다.**
v0.2까지는 PET < 3 s 같은 임계값으로 상충 여부를 잘랐다. 이 방식은 두 가지 문제를 낳는다. ① 임계값의 근거등급이 B·C를 넘지 못한다(§5.2). ② 임계 바깥의 사건이 전부 버려져 **분모가 사라진다**. v0.3부터는 **모든 차량–보행자 상호작용을 열거하고 각각에 0~1의 연속 위험도를 부여**한다(§5.1). 임계값을 없앤 자리에 함수를 넣는 것이 이 개정의 핵심이다.

이 전환의 직접적 효과: 인도를 따라 3~4 m 떨어져 지나가는 보행자–차량 쌍은 종전 방식에서 "ROI 동시점유 → PET=0 → 상충(오탐)"으로 잡혔지만, 연속 위험도에서는 DPD ≈ 0.03~0.10을 받아 **버릴 필요 없이 자동으로 무게가 0에 수렴**한다. **오탐 제거를 위해 ROI 경계나 각도 필터를 손대는 것은 금지한다**(§2.6).

**원칙 3 (v0.3 신설) — 하나의 숫자로 합치지 않는다.**
준수도·상호작용 위험도·보행 억제·법정 결격은 층위가 다른 정보다. 가중합으로 종합점수를 만드는 것은 현 단계에서 근거가 없으며 **금지**한다(§5.5, §8).

## 1. 좌표계·전처리 규약 (모든 지표의 공통 입력)

### 1.1 좌표 변환

수직정사 호버링이므로 4점 호모그래피 대신 **스케일 계수 s [m/px]** 로 근사할 수 있다.

```
s = (H × p) / f
  H: 지면 대비 비행고도 [m], p: 센서 화소 피치 [m/px], f: 초점거리 [m]
```

**확정 사실 (2026-08-09 사용자 확인)**: 8클립은 **모두 동일한 호버링 위치의 영상**이다. 따라서 `hover_group` 은 하나이며, **스케일 계수 s 와 공간 기준요소(ROI) 를 한 벌만 만들어 8클립에 공통 적용**한다. 캘리브레이션 부담이 크게 줄어든다.

**스케일 검증 V-A**: 영상 내 실측 가능한 기준거리 3개 이상 — 횡단보도 얼룩말무늬 1주기(국내 표준 폭 45 cm + 간격 45 cm), 차선 폭, 정지선 길이 — 을 화소로 측정해 s 로 환산하고 실측치와 대조한다. **오차 3 % 이상이면 스케일 근사를 버리고 4점 호모그래피로 전환**한다.

**영상 정합(registration) 검증 V-A2 — 동일 위치이기 때문에 오히려 반드시 필요한 항목**

"같은 위치"는 카메라가 고정되었다는 뜻이 아니다. 고정호버링이라도 GPS·바람에 의해 **기체가 수십 cm~수 m 표류(drift)** 하고 고도도 미세하게 변한다. 화면이 통째로 흔들리면 정지한 객체의 좌표까지 함께 움직이며, 이 흔들림은 그대로 S_m 에 실린다.

숫자로 보면 심각하다. 4K(가로 3840 px)로 가로 60 m 를 담으면 GSD ≈ 0.0156 m/px 이고, **V-B 게이트인 위치 RMSE 0.10 m 는 겨우 6.4 px** 다. 기체가 1 m 표류하면 64 px, 즉 **게이트 허용치의 10배**가 된다. 정합을 하지 않으면 검지·추적이 아무리 정확해도 Stage 1 을 통과할 수 없다.

> **처방 — 동일 위치라는 조건을 오히려 강점으로 쓴다.** 8클립이 같은 장면이므로 **하나의 기준 프레임(reference frame)에 전 프레임을 정합**할 수 있다.
>
> 1. 기준 프레임을 1개 선정 (화질이 가장 좋고 가림이 적은 프레임)
> 2. 노면에 고정된 특징점 6개 이상을 기준점으로 지정 — 횡단보도 스트라이프 모서리, 정지선 끝, 맨홀, 차선 파선 끝, 연석 모서리. **차량·보행자·그림자는 쓰지 않는다**
> 3. 프레임마다 기준점을 추적해 **유사변환(평행이동+회전+스케일)** 또는 호모그래피를 추정하고, 전 프레임을 기준 프레임 좌표계로 워핑(또는 좌표만 역변환)
> 4. **잔차(residual) 를 기록**: 정합 후 기준점의 기준 프레임 대비 잔차 RMSE
>
> **V-A2 합격 기준: 정합 후 기준점 잔차 RMSE < 0.05 m** (V-B 게이트 0.10 m 의 절반. 정합 오차가 궤적 오차 예산의 절반을 넘으면 안 된다) — 근거등급 **C**
>
> 정합 전후의 잔차를 함께 보고한다. **정합 전 잔차가 크게 나온다면 그것이 지금까지 지표가 흔들린 실제 원인일 가능성이 높다.**

렌즈 왜곡(배럴)이 화면 주변부에서 크므로, 대상 횡단보도가 화면 중앙 60 % 이내에 있는지 확인한다. 벗어난 횡단보도는 **왜곡 보정 후에만 지표를 산출**하고, 보정하지 않았다면 해당 지점 지표를 "판단 불가"로 출력한다. 3개 횡단보도 중 화면 가장자리에 걸린 것이 있는지 먼저 확인할 것.

**DJI_0483 원본 확보 — 편집 편향 해소 (2026-08-11)**

DJI_0483 은 한때 `_Cut` 편집본("문제 구간 제거", 원본 소실)만 존재해 선택 편향 우려가 있었으나, **원본이 확보되어 이 문제는 해소되었다.**

**처리 원칙**

1. **원본을 canonical 로 삼는다.** `_Cut` 은 지표 산출에서 배제하되 **삭제하지 않고 보관**한다 — 대조 근거이자 아래 검증의 입력이다.
2. **원본 무결성을 먼저 확인**한다(§7.1 T-2). 원본이 나머지 7클립과 동일한 촬영 세션·동일 호버 위치·동일 인코딩 설정인지, `_Cut` 이 원본의 진부분집합인지 확인하기 전에는 교체하지 않는다.
3. **제거 구간을 특정**한다. 원본과 `_Cut` 을 프레임 매칭해 제거된 시간 구간을 초 단위로 확정하고 `clips.yaml` 에 기록한다.

**제거 구간은 폐기물이 아니라 검증 자산이다**

사용자가 "문제 구간"이라 판단해 잘라낸 구간은, 그 판단이 맞다면 **드론 표류·화면 가림·고도 변경이 실제로 발생한 구간**이다. 즉 우리가 페이즈 1 정합으로 잡아내야 하는 바로 그 현상의 표본이다.

> **활용**: 제거 구간을 **정합 알고리즘의 최난도 테스트 케이스**로 쓴다. 이 구간에서 정합 잔차가 기준(0.05 m) 이내로 내려오면 알고리즘이 실제 표류를 잡아낸다는 강한 증거가 된다. 반대로 여기서만 실패하면 정합 모델을 similarity → homography 로 올리거나 해당 구간을 관측 불가로 처리한다.

또한 제거 구간의 성격 자체가 진단 정보다 — **화면 가림의 원인이 대규모 보행 군집이었다면 그것은 교시 첨두**이며, 그 구간을 되살림으로써 X-1(횡단량)·X-5(군집 규모)의 과소평가가 함께 해소된다.

**V-E6 재정의**: "포함/제외 두 벌 산출"에서 **"원본 전체 vs `_Cut` 범위 두 벌 산출"** 로 바꾼다. 두 값의 차이는 이제 리포트 한계가 아니라 **원본을 확보하지 않았다면 감수했을 오차의 크기**를 보여주는 방법론적 근거가 된다.

**클립 시간축 규약**: 각 클립의 촬영 개시 절대시각과 실촬영 길이를 기록하고, **클립 간 공백시간은 관측시간 합계에서 제외**한다. 시간당 환산 지표(X-1·X-2·X-4)의 분모는 공백을 뺀 실관측시간이다.

**클립 경계 트랙 연결**: 동일 위치이므로 기술적으로는 연결이 가능하지만, **하지 않는다.** 클립 사이에 시간 공백이 있으면 그 사이에 다른 차량이 지나갔을 수 있어 잘못된 연결이 상호작용을 위조한다. 다만 **클립이 연속 녹화를 잘라낸 것이고 경계에서 공백이 0 인 경우에만** 예외적으로 연결을 허용하며, 이때는 연결 사실을 `track_joined_at_boundary = True` 로 기록하고 해당 트랙이 관여한 상호작용에 `review_required` 를 단다.

### 1.2 궤적 평활화

원시 궤적의 화소 지터가 속도·가속도에 증폭되어 들어간다. 특히 **a₅(감속도)는 DPD_B2의 유일한 입력**이므로 평활화 방식이 결과를 직접 좌우한다. 방법과 파라미터를 반드시 고정하고 기록한다.

- 권장: Savitzky–Golay 필터, 다항차수 2, 윈도우 0.5 s (30 fps 기준 15프레임) — **근거등급 C**
- 속도 v(t) = |dp/dt|, 가속도 a(t) = dv/dt 는 평활화된 궤적에서 미분
- **필수 민감도 분석**: 윈도우 0.3 / 0.5 / 1.0 s 세 값으로 a₅와 DPD_B2를 재산출해 편차를 보고한다(V-E2). 감속도는 평활화에 가장 민감한 양이다.
- 대안(칼만 평활화)을 쓸 경우 프로세스 노이즈 설정값을 함께 기록

### 1.3 객체 분류 체계와 **트랙 단위 클래스 확정** (v0.3 신설)

| 클래스 코드 | 내용 | 대표 차폭 W_v [m] | 비고 |
|---|---|---:|---|
| `car` | 승용차 | 1.80 | 국내 중형 세단 기준 |
| `car_light` | 경차 | 1.60 | |
| `bus` | 승합·셔틀버스 | 2.50 | 정차 거동이 일반 차량과 다름, 별도 집계 |
| `truck` | 화물 | 2.35 | |
| `motorcycle` | 이륜차 | 0.80 | 배달 차량, 캠퍼스 진입 빈번 |
| `bicycle` | 자전거 | 0.60 | 이중 지위(아래 참조) |
| `pm` | 전동킥보드 | 0.60 | 이중 지위 |
| `pedestrian` | 보행자 | (보행자 치수 w_p 적용) | |

> **차폭 값의 지위**: 근거등급 **C**. 국내 차종 구성 실측치가 아니라 대표 제원이다. **S_m은 차폭에 직접 종속**되므로(§2.2), YAML에서 한 곳으로 관리하고 민감도 분석 대상으로 둔다. 원 논문(폴란드)은 승용 1.76 m, 화물·버스 2.49 m를 실측으로 사용했다.

**보행자 치수 w_p**: 기본 0.75 m(Neufert, 원 논문 채택값). 문헌에 0.6×0.5, 0.4×0.4 등 다양한 값이 존재하므로 **0.40 / 0.50 / 0.75 m 세 값으로 민감도 분석 필수**(V-E1). 근거등급 **B**.

**트랙 단위 클래스 확정 규칙 (v0.3 신설, 필수)**

프레임 단위 클래스를 그대로 쓰면 안 된다. 실제 데이터에서 하나의 물리적 대상이 같은 track_id 안에서 `car → motorcycle → person` 으로 진동하는 사례가 확인되었다. S_m은 차폭에 종속되므로, 이 진동은 그대로 **S_m을 0.7 m 이상 흔든다**.

```
1. 트랙 t의 전 프레임에 대해 클래스별 검출신뢰도 합 Σconf(c) 를 구한다
2. argmax_c Σconf(c) 를 트랙의 확정 클래스 class_final 로 한다
3. flicker_ratio = (class_final 이 아닌 프레임 수) / (전체 프레임 수) 를 기록
4. 다음 중 하나라도 해당하면 class_unstable = True 로 표시하고 수동 검수 큐에 넣는다
   - flicker_ratio > 0.20
   - 보행자군(pedestrian/bicycle/pm) ↔ 차량군(car/bus/truck/motorcycle) 간 전환이 1회 이상 발생
5. class_unstable 트랙은 지표 산출에 포함하되, 해당 트랙이 관여한 상호작용에
   review_required = True 플래그를 달아 육안 확정 대상으로 만든다
```

또한 같은 궤적 위에서 다수 track_id가 파생되는 **트랙 단편화**를 별도로 진단한다(§7 T-1). 단편화가 심하면 상호작용이 중복 계수되어 분모 NI가 부풀려진다.

### 1.4 PM·자전거의 이중 지위

PM·자전거는 "차마"이면서 횡단보도에서는 내려서 끌고 가야 하는 이중 지위에 있다. 다음 규칙으로 처리한다.

- **탑승 상태로 차도를 주행 중** → 차량군으로 취급, 상호작용의 차량측이 될 수 있음
- **탑승 상태로 횡단보도를 통과** → 보행자측으로 취급하되 `mounted = True` 로 표시. 별도 항목(X-3)으로 보고
- **끌고 걷는 경우** → 보행자로 취급 (연직 시점에서 판별이 어려우므로, 속도 임계 1.8 m/s 이하 + 자세 미판별을 근거로 잠정 분류하고 **오분류율을 육안 검증에서 보고**)

### 1.5 공간 기준요소 (v0.3 정밀화)

영상 위에 다음 요소를 수동 디지타이징하고 실좌표로 저장한다. **v0.2의 단일 `CW` 폴리곤을 세분한다** — 종전 "횡단보도 ROI"가 스트라이프보다 넓게 잡혀 인도 통행자까지 포함한 것이 오탐의 주요 원인이었기 때문이다.

| 코드 | 내용 | 정의 |
|---|---|---|
| `CW` | **횡단보도 노면표시 영역** | 얼룩말무늬 외곽선 폴리곤. **엄격하게 표시 실체에만 맞춘다.** 여유폭을 주지 않는다 |
| `CW_ext` | 횡단 통행 영역 | CW를 진행방향 좌우로 각 1.0 m 확장. 표시를 살짝 벗어나 건너는 통행을 "횡단"으로 인정하는 범위 (**C**) |
| `WZ` | 보행자 대기구역 | 연석 가장자리에서 후방 2.0 m 이내의 보도 영역 (**C**) |
| `SW` | 인도(보도) 영역 | **v0.3 신설.** 인도 통행과 횡단 대기를 구분하기 위해 필요 |
| `RW` | 차도 영역 | **v0.3 신설.** 무단횡단(E-2x) 판정 기준. CW·CW_ext 밖의 차도 |
| `SL` | 정지선 | 없으면 CW 가장자리를 대체 기준으로 하고 "정지선 없음"을 L1-4 결격으로 기록 |
| `D20`,`D30` | 차량 접근부 상류 20 m·30 m 기준선 (양방향) | 접근속도·감속 프로파일 산출용 |
| `A5` | 감속도 산출구간 | CW 진입 가장자리(또는 SL) 상류 **5 m** 구간. a₅ 산출 전용 |
| `TURN` | 회전부 | **PDI 적용 제외 영역**(§5.6) |

> **ROI 경계는 튜닝 대상이 아니다.** CW는 노면표시라는 물리적 실체가 있고, 그것에 맞추는 것이 유일한 정답이다. 오탐이 많다고 CW를 좁히면 지표가 아니라 손잡이를 돌리는 것이 되어 재현성이 사라진다. 인도 통행자 배제는 **경계가 아니라 사건 정의(§2)와 S_m(§2.2)이 담당**한다.

### 1.6 군집(group-pedestrian) 정의 (v0.3 신설)

원 논문은 "같은 방향으로 이동하는 2인 이상의 보행자 집합"을 **1개의 개체**로 취급하며, 바르샤바 관측에서 그룹 진입이 전체 보행자 진입의 평균 21.4 %를 차지했다. **군집을 1건으로 셀지 n건으로 셀지가 분모 NI를 직접 바꾼다.** 캠퍼스는 교시 단위 pulse로 군집 비율이 도심보다 높을 것이므로, 이 정의가 우리 지점에서는 더 크게 결과를 좌우한다.

```
군집 성립 조건 (모두 만족, 지속 ≥ 1.0 s)
  - 상호 중심간 거리 ≤ 2.0 m                 (근거등급 C, 민감도 1.5 / 2.0 / 3.0)
  - 진행방향 각도차 ≤ 30°
  - 속도차 ≤ 0.3 m/s
  - 모두 pedestrian 또는 mounted=False 인 bicycle/pm
```

- 군집은 하나의 `ped_entity_id` 를 갖고, **상호작용 계수에서 1건**으로 센다.
- 군집의 S_m 기준점: 차량이 **앞**을 지나면(A 유형) **최선두** 보행자, **뒤**를 지나면(B 유형) **최후미** 보행자.
- 군집 규모 n은 별도 필드로 보존해 노출량 지표(X-1·X-5)에서는 인원수로 집계한다. **위험도 지표는 개체 단위, 노출량 지표는 인원 단위** — 두 분모를 혼동하지 않는다.
- 군집 여부가 결과를 바꾸는 경우가 있으므로, **군집 미적용(전원 개별 계수) 결과를 병행 산출해 차이를 보고**한다.

## 2. 사건 정의 — v0.3 전면 개정

### 2.0 세 개의 층위

v0.2는 조우(E-1)와 상충(E-2) 두 층을 정의했다. v0.3은 그 아래에 **상호작용(Interaction)** 을 열거 단위로 새로 놓는다.

```
[층위 0] 상호작용 I  ── 열거 단위. 차량 1대 × 보행개체 1개의 '스침' 사건 전부
   │                    · 위험 여부와 무관하게 모두 센다 → 분모 NI 가 된다
   │                    · 각각 유형(A0/A1/B0/B1/B2)과 연속 위험도 DPD 를 갖는다
   │
   ├─[층위 1] 조우 E-1  ── 법적 정지 의무가 발생한 상호작용의 부분집합
   │                       · 정지판단선 통과 시점에 보행자가 WZ 또는 CW 에 존재
   │                       · 준수도 지표(V-1~V-4)의 분모
   │
   └─[층위 2] 상충 E-2  ── 근접지표가 임계 이내인 상호작용 (보조 태그)
                           · PET·RTTC 산출 대상. v0.3에서는 주지표가 아님(§5.2)

[별도] E-2x 무단횡단 기인 상호작용 ── CW·CW_ext 밖(RW)에서 발생
                           · 준수율 분모·분자 어디에도 넣지 않는다
                           · 별도 지수로 집계(§5.4)
```

**왜 층위 0을 새로 두는가.** 상충만 세면 분모가 사라진다. 운전자가 멀찍이서 미리 정지하면 두 궤적이 근접하지 않아 상충이 발생하지 않는데, **이것이 가장 바람직한 행동**이다. 상충 건수를 분모로 쓰면 이 모범 사례가 통째로 집계에서 빠지고, 잘 지키는 지점일수록 결과가 왜곡된다. 상호작용을 전수 열거하면 모범 사례가 DPD ≈ 0으로 분모에 정상 포함된다.

**부수 효과 — '오탐' 개념의 소멸.** 종전 상충 검출기는 인도 평행 통행을 상충으로 잡아 정탐률을 떨어뜨렸다. 전수 열거 체계에서 그 사건은 **오탐이 아니라 DPD ≈ 0.03의 저위험 상호작용**으로 정상 계수된다. 검증의 대상도 "상충을 맞게 찾았는가"에서 **"유형 분류와 3변수(S_m·V_m·a₅)를 맞게 계산했는가"** 로 바뀐다(§7).

| | 분모 | 분자 | 층위 |
|---|---|---|---|
| 준수도 V-1~V-4 | **조우 E-1 건수** | 정지·양보·미양보 각각 | 1 |
| **PDI (주지표)** | **상호작용 NI 전체** | ΣDPD | 0 |
| 상충 S-1~S-4 (보조) | (비율 아님) | 상충 건수·PET 분포 | 2 |
| 무단횡단 지수 | E-2x 건수 | ΣDPD of E-2x | 별도 |

### 2.1 상호작용 I 의 성립 조건

> 차량 트랙 v 와 보행개체 p 가 있고, 다음을 모두 만족하면 1건의 상호작용으로 계수한다.
> 1. p 가 관측 구간 중 **CW_ext 또는 WZ 또는 RW** 에 존재한 적이 있다 (횡단 의사 또는 차도 노출)
> 2. v 가 해당 횡단보도의 **접근–통과 구간(D30 ~ CW 하류 10 m)** 을 통과한다
> 3. **통과시점 t_m 이 정의된다** (§2.2) — 즉 차량이 p 를 앞지르거나 지나치는 순간이 존재
> 4. t_m 이 p 의 트랙 존재 구간 안에 있다

3번이 결정적 필터다. **인도를 따라 차량과 같은 방향으로 나란히 걷는 보행자는 t_m 이 성립하지 않거나 성립해도 S_m 이 크다.** 각도 필터가 하던 일을 기하 정의가 대신한다.

`TURN`(회전부)에서 발생한 상호작용은 `turning = True` 로 표시하고 **PDI 집계에서 제외**한다(§5.6).

### 2.2 통과시점 t_m 과 3변수 (v0.3 신설 — 가장 중요한 정의)

차량 로컬 좌표계를 쓴다. 시각 t 에서 차량 진행방향 단위벡터를 **e_h(t)**, 그에 수직인 횡방향 단위벡터를 **e_l(t)**, 차량 중심을 C_v(t), 차량 전면 중심을 F(t) = C_v(t) + (L_v/2)·e_h(t) 라 한다.

**t_m — 통과시점 (moment of passing)**

> 차량 전면이 보행개체 외형의 **가까운 가장자리**와 일치하는 순간.

```
d_long(t) = (P(t) − F(t)) · e_h(t) − w_p/2
   보행개체가 차량 전면보다 앞(진행방향)에 있으면 양수

t_m = d_long(t) 가 (+) → (−) 로 부호를 바꾸는 첫 시각
      (선형보간으로 프레임 사이 시각까지 산출. 프레임 해상도에 갇히지 않는다)
```

d_long 이 관측 구간 내내 부호를 바꾸지 않으면 **t_m 미정의 → 상호작용 아님**.

**S_m — 통과시점 이격거리 [m]**

```
S_m = |(P(t_m) − C_v(t_m)) · e_l(t_m)| − W_v/2 − w_p/2
```

- W_v 는 §1.3의 확정 클래스별 차폭, w_p 는 보행자 치수
- **S_m ≤ 0 이면 상호작용이 아니라 충돌(collision)** 로 분류하고 별도 보고. 우리 데이터에서 충돌이 나오면 그것은 실제 사고이거나 **측위 오차**다 — 반드시 육안 확인한다
- 군집은 §1.6의 기준 보행자를 P 로 사용

**V_m — 통과시점 차량속도 [m/s]**: `V_m = |v_v(t_m)|` . S_m = 0 이면 충돌하게 되는 속도라는 물리적 의미를 갖는다.

**a₅ — 상류 5 m 최대 감속도 [m/s²]**

```
a₅ = min{ a_v(t) : v 가 A5 구간(CW 진입 가장자리 또는 SL 상류 5 m) 내에 있는 t }
     감속이므로 음수. 감속이 전혀 없으면 0 또는 양수
```

- A5 구간 통과 프레임이 3개 미만이면(고속 통과) `a5_valid = False` 로 표시하고 DPD_B2 를 산출하지 않는다
- 평활화 파라미터에 민감하므로 §1.2의 민감도 분석이 필수

### 2.3 유형 분류 A0/A1/B0/B1/B2

원 논문 Figure 4(원문 도표, "Algorithm to classify pedestrian-vehicle interactions", p.601,
`claude/Pedestrian Danger Index — a novel surrogate measure of pedestrian safety at
unsignalized crossings.pdf`)를 2026-08-14 원문 대조해 옮긴 것이다. **근거등급 B → A로 상향**
(이전 버전은 2차 요약 `claude/03_..._v01.md` §3.1을 재구성한 것이었다).

```
Was the vehicle axis in front of the pedestrian at the time of passing?
│
├─ no → Type B (차량축이 보행개체 뒤)
│   │
│   ├─ Did the vehicle stop in front of the crossing before the pedestrian
│   │  entered the crossing?
│   │   ├─ yes → B0 : Safe situation(안전). DPD = 0. 분모에는 포함
│   │   └─ no  → S_m > 0 m ?
│   │            ├─ no (S_m ≤ 0) → COLLISION (5개 유형 밖, 별도 보고)
│   │            └─ yes → Did the vehicle enter the crossing when the
│   │                      pedestrian was still on it?
│   │                       ├─ yes → B1 : Potentially dangerous(위험).
│   │                       │         → DPD_B1 = g(S_m, V_m)
│   │                       └─ no  → B2 : Potentially dangerous(위험).
│   │                                 → DPD_B2 = h(a₅)
│
└─ yes → Type A (차량축이 보행개체 앞)
    │
    ├─ Was the pedestrian on the sidewalk at the time of passing?
    │   ├─ yes → A0 : Safe situation(안전). DPD = 0. 분모에는 포함
    │   └─ no  → S_m > 0 m ?
    │            ├─ no (S_m ≤ 0) → COLLISION (5개 유형 밖, 별도 보고)
    │            └─ yes → A1 : Potentially dangerous(위험).
    │                      → DPD_A1 = f(S_m, V_m)
```

원문 도표는 A0·B0를 초록 점선 박스로 묶어 **"Safe situation (under control)"**, A1·B1·B2를
주황 점선 박스로 묶어 **"Potentially dangerous situation"**이라 직접 라벨링한다. 본문에도
동일 문장이 있다: "dividing them into safe (A0 and B0) and potentially unsafe (A1, B1, and
B2) categories." **안전/위험 구분은 원문 자체의 구분이며 이 프로젝트가 붙인 것이 아니다.**
COLLISION(S_m ≤ 0)은 A·B 양쪽에서 도달 가능한 별도 종착점이고, 5개 유형에 속하지 않는다.

**정정(2026-08-14)**: 이전 버전은 A0 조건을 "SW·WZ 에 있음"(보도 또는 대기구역)이라고 적었으나,
**원문은 "Was the pedestrian on the sidewalk" — 보도(SW)만 명시**하고 WZ는 언급하지 않는다.
WZ 포함은 이 프로젝트가 임의로 확장한 것이었다 — 원문 근거 없음. **본 개정에서 원문을 따라
SW만 남긴다.** WZ에 있는 보행개체를 A0에 포함시킬지는 별도 근거등급(C)의 확장 결정으로
다시 논의해야 하며, 지금은 유형 판정에서 빠진다. §2.4(조우 E-1)의 WZ∪CW 판정은 이 조건과
별개 개념이므로 혼동하지 않는다.

**미해소**: `구현사양서_v01.md` L352("아직 보도(SW/WZ)에 있었음 → 안전")·L597 의사코드가
이전(WZ 포함) 정의를 그대로 쓰고 있다 — 이번 개정과 어긋난다. 구현사양서는 이번 세션에서
손대지 않았다. 다음 세션에서 함께 정정할 것.

**A/B 판정 구현**: t_m 시점에 보행개체가 자신의 횡단 진행방향 상에서 차량 진행축(차량 궤적 중심선)을 이미 통과했는가로 판정한다. 통과 전이면 A(차량이 앞을 지남), 통과 후면 B. 판정 근거값(보행개체–차량축 간 부호거리)을 이벤트 로그에 남긴다.

### 2.4 조우 E-1 — 준수도 지표의 분모

> 차량이 **정지판단선**을 통과하는 시점 t₀ 에, 보행개체가 `WZ` 또는 `CW` 내에 존재하면 1건의 조우로 계수한다.

**정지판단선**은 차량이 그 지점에서 인지·반응 후 정상 제동으로 횡단보도 앞에 정지할 수 있는 최소 거리다.

```
D_stop = v₀ · t_pr + v₀² / (2a)
  v₀   : 접근속도 [m/s] (D30~D20 구간 평균)
  t_pr : 인지반응시간 = 2.5 s   (AASHTO 정지시거 설계값) — 근거등급 A
  a    : 감속도 = 3.4 m/s²      (AASHTO 정지시거 설계값) — 근거등급 A
```

*AASHTO 값은 설계 기준(보수적 하한)이므로 실제 회피 가능성보다 관대하게 나온다. 조우 판정을 엄격히 하려면 t_pr = 1.5 s 를 병행 산출해 민감도를 본다 — 근거등급 C.*

> **정지판단선을 넣은 이유**: 물리적으로 정지가 불가능했던 차량을 미양보로 잘못 계수하지 않기 위해서다. 보행자가 연석에 도착한 순간 차량이 이미 5 m 앞에 와 있었다면 그 운전자는 설 수 없었고, 이를 위반으로 세면 진단 결과의 신뢰를 잃는다. 반대로 이 조건이 없으면 준수율이 실제보다 낮게 나온다.

**분모를 흐리는 사례 처리 규칙**
- 보행개체가 WZ 에 있으나 명백히 횡단 의사가 없는 경우(벤치 착석, 정류장 대기, 통화하며 정지) → 조우에서 제외. 단 **연직 시점에서는 의사 판별이 어려우므로 판별 규칙을 별도 정의하고 육안 검수로 오분류율을 보고**한다. 잠정 규칙: WZ 체류 중 연석 방향 접근속도 < 0.2 m/s 가 3 s 이상 지속 → 횡단 의사 없음 (**C**)
- 선행 차량이 이미 정지해 후행 차량이 정지한 경우 → **종속 정지**로 표시하고 준수율 산정에서 분리
- 보행개체가 이미 횡단을 마친 뒤 차량이 진입 → 조우 아님 (단 상호작용 B2 로는 계수됨)

### 2.5 E-2x — 무단횡단 기인 상호작용

보행개체가 `CW_ext` 밖의 차도(`RW`)에 있는 상태에서 성립한 상호작용.

- **준수율(V-1~V-4)의 분모·분자 어디에도 넣지 않는다.** 운전자 준수도 문제가 아니라 보행자 노출·시설 배치 문제이기 때문이다
- **PDI 본체 집계(NI)에서도 분리**하고, 동일한 DPD 함수로 별도 지수를 만든다(§5.4)
- E-2x 가 많다면 이는 운전자 계도 사안이 아니라 **횡단보도 위치·개수의 적정성 문제**다 (1차 조사 A-8: 무단횡단 경험자의 51.6 %가 사유를 "횡단보도가 멀어서"로 응답)

**종속 정지에 뒤이은 상충**: 선행 차량이 정지해 시야가 가려진 상태에서 인접 차로 차량과 보행자 간에 발생한 상황(multiple-threat). 조우 판정은 성립하되 준수도 산정에서 '종속' 플래그로 분리하고, 상호작용으로는 정상 계수한다.

### 2.6 금지 사항 (v0.3 신설)

다음은 **하지 않는다**. 각각 이유가 있다.

| 금지 | 이유 |
|---|---|
| 오탐을 줄이기 위해 `CW` 폴리곤을 좁히거나 넓히는 것 | CW 는 노면표시라는 물리적 실체에 맞추는 것이 유일한 정답. 손대는 순간 재현성과 지점 간 비교가능성이 사라진다 |
| 교차각 상한 필터(예: 140° 초과 배제)로 인도 통행을 거르는 것 | **차도를 따라 차량 쪽으로 걸어오는 무단횡단자가 정확히 그 각도대**이며 이는 실제 위험 사건이다. 각도로는 구분되지 않고 **횡방향 이격거리 S_m 으로만 구분된다** |
| 임계값을 결과가 좋아지는 쪽으로 조정하는 것 | 파라미터는 YAML 단일 출처에서 근거등급과 함께 관리하고, 변경 시 민감도 분석 결과를 함께 보고한다 |
| 준수도·PDI·억제 플래그를 가중합해 종합점수를 내는 것 | 가중치의 근거가 없다 (§8) |

### 2.7 판정 순서 (파이프라인 구현용)

```
0. 전처리: 클립별 스케일 검증 → 평활화 → 트랙 클래스 확정 → 군집 구성
1. 각 (차량 트랙 v, 보행개체 p) 쌍에 대해 t_m 산출
      t_m 미정의 → 상호작용 아님, 폐기 (사유 로그)
2. S_m, V_m, a₅ 산출.  S_m ≤ 0 → [충돌] 별도 보고 + 육안 확인 필수
3. p 의 위치로 영역 판정
      RW (CW_ext 밖 차도) → [E-2x]  → 6으로
      CW / CW_ext / WZ    → [상호작용 I] → 4로
4. A/B 판정 → A0/A1/B0/B1/B2 유형 확정 → DPD 산출
5. 조우 판정: v 의 D_stop 통과 시각 t₀ 에 p 가 WZ∪CW 에 존재?
      예 → [E-1 조우]. 종속 정지 여부 판정 → 준수도 V-1/V-2/V-3 판정
      아니오 → 조우 아님. 자유주행 집단(V-5·V-7)으로 분류
6. 보조 태그: PET·RTTC 산출 가능하면 산출, 임계 이내면 conflict 플래그
7. 회전부 발생 → turning = True (PDI 집계 제외)
8. 이벤트 로그 1행 기록 (구현사양서 §5 스키마)
```

각 사건에 `event_id`, `분류코드`, `종속플래그`, `review_required`, `판정근거값(t₀, D_stop, t_m, S_m, V_m, a₅, PET)` 을 남겨 **사후 재검증이 가능하도록** 한다. 진단 서비스에서는 이 로그가 곧 결과의 근거자료가 된다.

영상만으로는 채울 수 없다. **현장 실사·도면 병행 필수**이며, 진단 서비스에서는 체크리스트 서식으로 처리한다.

| L1-1 | 대상 도로가 도로교통법상 '도로'에 해당하는가 | Y/N/보류 | 도로교통법 제2조 제1호 | × |
| L1-2 | 어린이·노인·장애인 보호구역 해당 여부 | Y/N | 보호구역 규칙 | × |
| L1-3 | 횡단보도 표시 상태(도색 마모, 규격) | 적합/부적합 | 시행규칙 제11조 | ○ |

> **L1-1의 무게**: 캠퍼스 내부도로는 사유지이나, 도로교통법 제2조 제1호는 "현실적으로 불특정 다수의 사람 또는 차마가 통행할 수 있도록 공개된 장소로서 안전하고 원활한 교통을 확보할 필요가 있는 장소"를 도로로 포함한다. 개방형 캠퍼스는 통상 이에 해당하나 **개별 사안 판단**이므로, 진단서에는 판정 근거(출입통제 유무, 외부차량 통행 실태)를 함께 적는다. 이 항목이 '해당 없음'으로 판정되면 제27조 일시정지 의무 자체가 적용되지 않아 **L2 준수도 지표가 법적 의미를 잃는다** — 진단 논리의 최상단 분기다.

**L1은 어느 하나라도 부적합이면 즉시 시정 대상**으로 처리하고, L2·L3 결과와 무관하게 리포트 최상단에 표시한다. 실무에서 가장 강한 개선 근거는 "위험해 보인다"가 아니라 "법정 기준 미달"이다.

## 4. L2 — 노출·행태·준수도 지표

### 4.1 차량 준수도

법적 기준선: 도로교통법상 **"일시정지"는 바퀴를 일시적으로 완전히 정지시키는 것**, **"서행"은 즉시 정지시킬 수 있는 느린 속도로 진행하는 것**으로 정의된다(제2조). 즉 **법은 정지 지속시간을 요구하지 않고 '완전 정지' 사실만 요구**한다. 아래의 지속시간 임계는 순전히 계측 신뢰성을 위한 것이지 법적 기준이 아니며, 리포트에도 그렇게 표기한다.

| ID | 지표 | 정의 | 임계 | 근거 | 30분 |
|---|---|---|---|---|---|
| **V-1** | 완전정지율 SR | 조우 사건 중, 차량이 `SL` 상류~`CW` 진입 전 구간에서 `v ≤ v_stop` 를 `t ≥ τ_stop` 동안 유지한 비율 | v_stop = 0.3 m/s, τ_stop = 0.5 s | **C** | △ |
| **V-2** | 감속양보율 YR | 완전정지는 아니나 최소속도 `v_min ≤ 2.0 m/s` 이며 보행자가 먼저 통과한 비율 | v_min = 2.0 m/s | **C** | △ |
| **V-3** | 미양보율 NR | `1 − SR − YR` | — | — | △ |
| — | *(분모 공통)* | **V-1~V-4의 분모는 모두 조우(E-1) 건수.** 상호작용 NI 나 상충 건수를 분모로 쓰지 않는다. '종속' 플래그 사건과 E-2x 는 분모에서 제외 | — | — | — |
| **V-4** | 정지선 침범율 | 정지 차량 중 정지위치가 `SL` 하류인 비율, 평균 침범거리 [m] | — | — | △ |
| **V-5** | 접근속도 v85 | `D30`→`D20` 구간 통과속도의 85 백분위수. **조우 없는 자유주행 차량으로 별도 산출** | 캠퍼스 제한속도 대비 | — | ○ |
| **V-6** | 최소통과속도 분포 | `CW` 전후 ±10 m 구간 내 최저속도의 분포 | — | — | ○ |

> **v_stop = 0.3 m/s 의 근거**: 문헌 표준값이 없다. 궤적 지터로 인한 겉보기 속도 수준에 근거한 잠정값이므로, **0.2 / 0.3 / 0.5 m/s 세 값으로 민감도 분석을 수행하고 SR 변동폭을 리포트에 함께 기재**한다. 이 값 하나로 준수율 결론이 뒤집힐 수 있으므로 절대 단일값으로 확정 보고하지 않는다.

> **V-7이 실제로는 가장 설득력 있는 그림이다.** 조우가 있을 때와 없을 때의 감속 프로파일이 겹친다면 "운전자가 보행자를 보고도 반응하지 않는다"는 뜻이고, 이것은 표본이 적어도 시각적으로 강력한 증거가 된다. 30분 데이터의 한계 안에서 낼 수 있는 최선의 결과물이므로 우선 산출을 권한다.

## 5. L3 — 상호작용 위험도 (v0.3 전면 개정)

### 5.1 주지표 — DPD / PDI

`claude/03_PDI_DPD_검증_및_한국형PoC_v01.md` 의 검증 결과를 채택한다. **식(4)는 원문에 계수 전치 오타가 있으며, 본 프로젝트는 수정식을 쓴다.**

```
DPD_A1(S_m, V_m) = 1 / (1 + e^( 1.196·S_m − 0.075·V_m − 0.923))    원문 식(2)
DPD_B1(S_m, V_m) = 1 / (1 + e^( 0.862·S_m − 0.052·V_m))            원문 식(3)
DPD_B2(a₅)       = 1 / (1 + e^( 0.561·a₅  + 2.713))                 식(4) 수정판
DPD_A0 = DPD_B0  = 0

PDI [%] = (ΣDPD_A1 + ΣDPD_B1 + ΣDPD_B2) / NI × 100
          NI = A0 + A1 + B0 + B1 + B2   (안전 상호작용 포함)
          S_m [m], V_m [m/s], a₅ [m/s²] (감속은 음수)
```

|---|---|---|---|---|
| **D-1** | 유형 구성비 | A0/A1/B0/B1/B2 건수와 비율 | **B**(Fig.4 재확인 필요) | ○ |
| **D-2** | S_m 분포 | 통과시점 이격거리 [m] | **A**(정의는 명확, 치수 가정은 B) | ○ |

> **D-6의 명칭을 강제한다.** 리포트에는 반드시 **"P-PDI (폴란드 계수 기준 참조값)"** 로 표기한다. 계수가 폴란드 응답자(전문가 약 10 %, 나머지 학생)의 **인지위험** 평정을 회귀한 값이므로, 절대값의 안전등급 해석과 폴란드 지점(Warsaw 6.05 % / Wrocław 3.99 %)과의 직접 비교는 **금지**한다. 허용되는 것은 파이프라인 검증, 분포 형상 확인, 우리 지점 3개소 간·개선 전후의 **상대 비교**뿐이다.

> **DPD 는 인지위험이지 상해위험이 아니다.** "DPD 0.5"는 "사망확률 50 %"가 전혀 아니다. 이 문장을 리포트에 고정 수록한다.

**PDI 보고 시 필수 병기 3종**: ① NI(분모), ② 유형 구성비(D-1), ③ 유형별 평균 DPD. 원 논문에서 Warsaw–Wrocław 의 PDI 격차(6.05 % vs 3.99 %)가 **DPD 값 자체보다 안전 상호작용(A0+B0) 비율 차이(25.4 % vs 50.4 %)에서 상당 부분 발생**했다. 단일 백분율만 제시하면 반드시 오독된다.

**식(4)의 구조적 결함을 리포트에 명시한다.** a₅ 단독 모형은 "멀리서 미리 부드럽게 감속·정지 후 통과(모범 운전, a₅≈0)"와 "감속 없이 뒤로 스쳐 통과(위험 통과, a₅≈0)"에 **똑같이 DPD=0.06 을 부여**한다. 폴란드 구법(보행자 우선권 없음) 하에서는 무감속 통과가 정상 거동이었으나, **한국은 2022.7.12 이후 일시정지가 의무**다. 따라서 B2 상호작용은 DPD_B2 와 함께 **V-1 완전정지 여부를 반드시 병기**하고, K-DPD 재보정 시 정지 이진변수를 포함한 확장모형을 적합한다.

### 5.2 보조지표 — PET·RTTC·DRAC (v0.3에서 강등)

| ID | 지표 | 정의 | 임계 | 근거 | 지위 |
|---|---|---|---|---|---|
| S-1 | PET | 선행 이용자가 잠재충돌지점을 벗어난 시각과 후행 이용자가 그 지점에 도달한 시각의 차 | 상충 < 3 s / 심각 < 1.5 s | **A / B** | 보조 |
| S-2 | RTTC_min | 두 이용자가 현재 속도를 유지할 때 잠재충돌지점 도달시각의 차의 최소값 | < 3 s | **A** (Chen et al. 2017) | 보조 |

**왜 강등하는가 — 세 가지 구조적 결함**

1. **PET 는 단일값이라 상충의 전개 과정을 담지 못하고, 차량이 급감속해 거의 멈춘 경우 PET 가 커져 실제 위험을 과소평가**한다 (Chen et al. 2017; Sheng et al. 2025). 즉 *운전자가 잘 대응한 위험한 상황*이 *안전한 상황*으로 기록된다.
2. **TTC 는 충돌코스가 성립해야만 존재**하므로, 보행자–차량처럼 진로가 유연한 조합에서는 대부분의 위험 상황에서 값이 생기지 않는다 (Sheng et al. 2025).
3. **잠재충돌지점의 정의가 불안정하다.** 2D 평면에서 궤적 교차점을 잡으면 인도 평행 통행처럼 실제로는 횡방향으로 떨어져 있는 쌍에서도 교차점이 생기고, ROI 동시점유를 PET=0 으로 기록하게 된다. **S_m 은 이 문제를 구조적으로 갖지 않는다** — 횡방향 이격을 직접 재기 때문이다.

**그럼에도 산출하는 이유**: ① 문헌 비교가능성(대부분의 SSM 연구가 PET 를 보고), ② DPD 와의 상관 확인이 K-DPD 재보정의 참고자료가 됨, ③ 심각 상충 사례를 육안 검토 대상으로 골라내는 스크리너로 유용. **리포트 본문이 아니라 부록에 배치**한다.

### 5.3 회피행동 기반 보조지표

Tageldin & Sayed(2016)는 상호작용이 잦은 환경에서 시간근접 지표보다 **보행자 회피행동 기반 지표 — 보폭(step length), 보조수(step frequency), walk ratio 의 급변 — 가 상충을 더 잘 식별**함을 보였다. 수직정사 30 fps 영상은 보행자 위치 진동에서 보조 리듬을 추출할 여지가 있다.

→ **P-8(횡단 중 속도변동)을 회피행동 대리지표로 상시 병기**하고, 여유가 있으면 gait 파라미터 산출 가능성을 탐색한다. 성공하면 본 과제의 방법론적 기여가 된다. 우선순위는 낮다.

### 5.4 무단횡단 위험 지수 JDI (v0.3 신설)

기존 `jaywalkers.csv` 의 `vehicle_nearby` 불리언(임계 거리 기반)을 **폐기**하고, E-2x 상호작용에 동일한 DPD 함수를 적용한 연속 지수로 대체한다. 임계값 문제가 함께 사라진다.

```
JDI [%] = ΣDPD(E-2x) / N(E-2x) × 100
```

- DPD 함수는 A1/B1 을 그대로 사용(차도 상 보행자와 차량의 스침이라는 기하가 동일)
- **PDI 와 절대 합산하지 않는다.** 나란히 보고한다
- 해석 규칙: **PDI 낮음 + JDI·P-7 높음 → "운전자가 잘 지킨다"가 아니라 "보행자가 횡단보도를 이용하지 않는다"** → 개선 방향이 운전자 계도가 아니라 횡단보도 위치·개수 재검토로 바뀐다

### 5.5 보행 억제(suppression) 판정 — 단독 해석 금지 규칙

무신호 횡단보도에서 가장 위험한 상태는 **보행자가 무서워서 건너지 못하는 것**인데, 이 경우 상호작용 자체가 생기지 않아 **PDI 도 PET 도 좋아 보인다.** PDI 는 분모가 상호작용이므로, 상호작용이 줄면 지수가 오히려 개선된 것처럼 나온다.

→ **L3 결과는 단독으로 해석하지 않고, 반드시 P-1·P-3·P-4(대기시간·gap 거부·횡단 포기)와 교차 검토**한다.

> **판정 규칙**: 상호작용 밀도 하위 + 대기시간 상위 + gap 거부 다수 + 횡단 포기 발생 → "안전"이 아니라 **[보행 억제]** 플래그

이 규칙이 본 진단 서비스가 기존 SSM 도구·PDI 원 논문과 구별되는 핵심 로직이다.

**최종 산출 형식 (고정)**

```
P-PDI [%]  +  [보행 억제] 플래그  +  L1 적법성 결격 여부  +  JDI [%]
→ 4종 병기. 단일 숫자로 통합하지 않는다.
```

### 5.6 적용 제외 — 회전 차량

PDI 원저자가 **회전 차량 상호작용을 명시적으로 배제**했다. 현재 ROI 중 회전부(`TURN`)는 PDI 적용 대상이 아니다. 회전 차량은 다음과 같이 처리한다.

- 상호작용 로그에는 `turning = True` 로 기록하되 **PDI·JDI 집계에서 제외**
- 준수도(V 계열)와 노출(X 계열)에는 포함 가능 (법적 의무는 회전 차량에도 있다)
- 회전부 전용 지표는 **별도 개발 과제**로 남긴다. 임의로 직진용 계수를 적용하지 않는다

## 6. 표본 수 요구량 — 30분으로 무엇을 말할 수 있는가

### 6.1 비율 지표의 신뢰구간

비율 p 의 95 % 신뢰구간 반폭 ≈ `1.96 × √(p(1−p)/n)`. 가장 보수적인 p = 0.5 기준.

| 표본 n | 95 % CI 반폭 | 실무 해석 |
|---|---|---|
| 10 | ±31 %p | **보고 불가**. 사례 예시로만 사용 |
| 30 | ±18 %p | 경향 언급만 가능 |
| 50 | ±14 %p | 조건부 보고 |
| **100** | **±10 %p** | **최소 권장 표본** |
| 200 | ±7 %p | 안정적 |
| 385 | ±5 %p | 정밀 |

**즉시 해야 할 일**: 8클립에서 **상호작용 NI 와 조우 E-1 건수를 먼저 세어라.** 이 두 숫자가 이후 분석의 범위를 전부 결정한다.

- E-1 ≥ 100 → V-1~V-4 준수율 보고 가능
- 30 ≤ E-1 < 100 → 경향만 서술, CI 병기 필수
- E-1 < 30 → **준수율을 숫자로 내지 말 것.** 파이프라인 검증용으로만 사용

### 6.2 PDI 값은 보고할 수 없다

원 논문의 민감도 분석(SEM = s/√n) 결과는 명확하다. Warsaw 는 조사일수 **3일**, Wrocław 는 **4일**부터 평균 PDI 의 상대표준오차가 5 % 미만이 되며, **저자는 PDI 산출 시 최소 4일 조사를 권고**한다. 우리의 30분 단일 세션은 이 요건에 한참 못 미친다.

→ **D-6(P-PDI) 값은 리포트에 쓰지 않고 "본 관측으로 판단 불가"로 명시 출력**한다. 파이프라인 산출은 하되 참조값으로만 보관한다.

**30분으로 가능한 것**: 유형 분류 알고리즘 구현·검증, S_m·V_m·a₅ 산출 파이프라인 검증, 세 변수의 분포 형상 파악, 측정 정확도 검증(§7), 유형 구성비의 대략적 파악, V-7 감속 프로파일.

**심각 상충(PET < 1.5 s)은 30분으로는 사실상 0~수 건**이 예상된다. EVT 기반 사고빈도 추정은 수십 건 이상의 극단표본을 요구하므로 **본 관측으로는 불가**로 확정하고 무리하게 시도하지 않는다.

## 7. 검증 프로토콜 (v0.3 2단계 구조로 재설계)

### 7.0 설계 사유 — 두 가지를 섞지 않는다

검증에는 성격이 다른 두 가지가 섞여 있다.

- **(가) 검지·추적 품질**: 객체를 빠짐없이 정확한 위치로 잡았는가. 이것이 안 되면 그 위에 얹는 모든 지표가 무의미하다
- **(나) 사건 판정 정확도**: 잡은 궤적으로 유형과 3변수를 맞게 계산했는가

(가)를 확인하겠다고 8편을 처음부터 끝까지 보는 것은 비효율적이다. 검지율은 **표본 프레임 전수 라벨링**으로 훨씬 정확하고 빠르게 측정되고, ID 스위치·클래스 진동·트랙 단편화는 **코드로 전수 자동 진단**할 수 있다. 반대로 (나)의 **회수율(누락 상호작용)** 은 전건 육안 외에는 방법이 없다.

그래서 **Stage 1(자동 진단 + 표본 라벨링) → 게이트 → Stage 2(전건 육안)** 순서로 간다. Stage 1 을 건너뛰고 전건 육안을 먼저 하면, 검지 품질에 문제가 발견됐을 때 **전건 육안을 다시 해야 한다.** 순서가 곧 비용이다.

### 7.1 Stage 1 — 궤적 품질 게이트 (선행, 필수)

| 코드 | 검증 | 방법 | 합격 기준 | 근거 |
|---|---|---|---|---|
| **V-A** | 좌표 정확도 | 실측 기준거리 3개 이상 대비 환산 오차 (8클립 공통 s) | 오차 < 3 % (초과 시 호모그래피 전환) | **B** |
| **V-A2** | **영상 정합 (신규)** | 노면 고정 기준점 6개 이상을 전 프레임 추적, 기준 프레임 정합 후 잔차 | **잔차 RMSE < 0.05 m** (정합 전후 모두 보고) | **C** |
| **V-D** | 속도 정확도 | 구간거리·시간 기반 독립 산출과 대조 | 오차 < 1 km/h | **A** (원 논문 실적) |
| **V-B** | 궤적 위치 정확도 | 무작위 100프레임(8클립 균등 배분) 전수 수동 라벨링 | **CW 구역 내 RMSE < 0.10 m** | **A** (원 논문 10 cm 미만) |
| **V-B2** | 검지 성능 | 위 100프레임에서 검지율(recall)·오검지율 | 검지율 ≥ 0.95, 오검지율 ≤ 0.05 | **C** |
| **T-1** | 트랙 건전성 (자동, 전수) | 트랙 수·수명 분포, 단편화율, 검지 공백률, **클래스 플리커율**, ID 스위치 후보 수 | 클래스 플리커율 ≤ 0.05, 궤적당 ID 스위치 후보 ≤ 0.1건 | **C** |
| **T-2** | **원본 클립 무결성 (신규)** | 확보된 DJI_0483 원본이 나머지 7클립과 동일 세션·동일 호버 위치·동일 인코딩인가. `_Cut` 이 원본의 진부분집합인가. 원본 내부에 PTS 불연속이 없는가 | 전 항목 충족 시에만 canonical 로 채택 | **C** |

> **V-B 기준을 0.3 m → 0.10 m 로 상향한 이유**: 원 논문이 속도 10 km/h 증가 시 PDI 약 23 % 증가라고 보고했다. **속도·위치 오차가 지표를 지배한다.** 또 S_m 이 0~4 m 범위에서 DPD 를 결정하는데(표 4 참조: 20 km/h 에서 DPD 0.5 경계가 S_m = 1.12 m), 위치 오차 0.3 m 는 DPD 를 0.15 이상 흔든다. 0.3 m 기준으로는 지표가 성립하지 않는다.

**게이트 규칙**: V-A·**V-A2**·V-D·V-B 중 하나라도 불합격이면 **지표 산출을 중단하고 앞 단계로 되돌아간다.** 특히 **V-A2 불합격의 처방은 검지기 개선이 아니라 영상 정합**이다 — 원인을 잘못 짚으면 검지 모델을 아무리 바꿔도 게이트를 통과하지 못한다. T-1 불합격은 중단 사유는 아니나, 해당 트랙에 `review_required` 를 달아 Stage 2 에서 우선 확인한다.

### 7.2 Stage 2 — 8편 전건 육안 검토 (Stage 1 통과 후 1회)

**목적을 재정의한다.** 종전 육안 검토는 "알고리즘이 찍어준 시각으로 점프해 그 장면만 판정"하는 방식이었고, 그래서 회수율이 사실상 미검증 상태로 남았다. Stage 2 는 다음 세 가지를 동시에 얻는다.

1. **상호작용 인벤토리** — 자동 검출 여부와 무관하게, 영상에 나타난 모든 차량–보행개체 스침 사건을 사람이 기록. 이것이 회수율의 진짜 분모가 된다
2. **검지 누락 표시** — 화면에 있으나 박스가 없는 객체, ID 가 바뀐 지점, 클래스가 틀린 객체를 시각으로 기록. Stage 1 의 표본 기반 검지율을 사건 단위로 보완
3. **유형·변수 대조** — 자동 산출된 유형(A0/A1/B0/B1/B2)과 육안 판정을 대조

| 코드 | 검증 | 합격 기준 |
|---|---|---|
| **V-F** | 유형 분류 일치도 | 자동 유형 vs 육안 유형 일치율 ≥ 0.90 (Cohen's κ 병기) |
| **V-G** | 상호작용 회수율 | 육안 인벤토리 대비 자동 검출 비율 ≥ 0.90 |
| **V-C** | 3변수 정확도 | 표본 20건 프레임 단위 실측 대조: S_m 오차 < 0.15 m, V_m 오차 < 1 km/h, PET 오차 < 0.2 s |

**리뷰용 오버레이 영상 사양 (필수)** — 이것 없이는 육안 검토가 성립하지 않는다.

- 각 객체에 `track_id` + 확정 클래스 + 순간속도 [km/h] 표시
- `CW` / `CW_ext` / `WZ` / `SW` / `RW` / `A5` / `SL` 경계선 상시 표시
- 프레임번호와 클립 내 타임코드 burn-in (판독 서식에 그대로 옮겨 적을 수 있게)
- `class_unstable=True` 트랙은 색상 구분
- 자동 검출된 상호작용은 t_m 시점에 표식 + `event_id` 표시
- 원본 해상도 유지 (다운스케일하면 작은 객체 누락을 사람이 못 본다)

**판독 서식** 컬럼은 구현사양서 §7 에 정의한다. 핵심은 종전 서식과 달리 **행의 단위가 "알고리즘 후보"가 아니라 "사람이 본 상호작용"** 이라는 점이다.

**작업량 추정**: 8클립 합계 30분. 0.5~1배속 재생 + 사건마다 일시정지 기록으로 실소요 2~3시간 규모. 회전부는 이번 회차 제외(§5.6).

### 7.3 민감도 분석 (필수 산출)

| 코드 | 대상 | 후보값 | 보고 형식 |
|---|---|---|---|
| V-E1 | 보행자 치수 w_p | 0.40 / 0.50 / 0.75 m | DPD·PDI 재산출, 편차 |

## 8. 산출물과 보고 규약

### 8.1 등급화는 하지 않는다 (현 단계)

v0.2 §8 은 준수도 40 % / 보행행태 25 % / 상충 35 % 가중합안을 잠정 제시했으나, **가중치의 근거가 없다.** v0.3 은 이를 **보류**하고, 지표별 원값과 판정을 나열하는 방식만 허용한다. 가중치 확정은 복수 지점 데이터가 쌓인 뒤에 할 일이다.

```
리포트 최상단 : L1 결격 항목 (있으면 [즉시 시정 대상])
본문          : V 계열 준수도 (표본 충족 시) / P 계열 행태 / X 계열 노출
              : D 계열 — 유형 구성비, S_m·V_m·a₅ 분포, DPD 분포
              : [보행 억제] 플래그 판정
              : JDI 및 P-7
부록          : S 계열(PET·RTTC), 민감도 분석, 검증 결과, 이벤트 로그 요약
판단 불가     : D-6(P-PDI) 값, 심각 상충 빈도, EVT 추정 — 명시적으로 "판단 불가" 출력
```

### 8.2 "판단 불가"의 강제 출력

표본 미달·검증 미통과 지표는 **빈칸이나 0 이 아니라 "판단 불가(사유)"** 로 출력한다. 파이프라인이 이를 자동으로 판정하도록 구현한다. 사유 코드는 구현사양서 §6 에 정의한다.

### 8.3 추적성(provenance) 규약 (v0.3 신설 — 필수)

Day4 검토에서 동일 대상에 대해 33.3 % 와 12.5 % 두 수치가 존재하고 전자의 근거를 재현할 수 없는 사례가 확인되었다. 이는 개별 실수가 아니라 **절차의 결함**이다. 진단 서비스가 되려면 리포트의 모든 숫자가 역추적 가능해야 한다.

**모든 산출 파일의 헤더 또는 동반 메타 파일에 다음을 기록한다.**

| 필드 | 내용 |
|---|---|
| `run_id` | 실행 고유 ID (타임스탬프 기반) |
| `script` | 산출 스크립트 파일명 |
| `code_version` | git commit SHA (또는 스크립트 파일 해시) |
| `params_hash` | 사용한 파라미터 YAML 의 해시 |
| `input_files` | 입력 파일명 + 각 파일의 SHA-256 |
| `executed_at` | 실행 절대시각 |
| `spec_version` | 본 정의서 버전 (v0.3) |

**규칙**: provenance 가 없는 수치는 **리포트에 쓰지 않는다.** 과거 보고서의 수치와 불일치가 발생하면, 재현 가능한 쪽을 canonical 로 삼고 불일치 사실과 원인 추정을 기록으로 남긴다.
