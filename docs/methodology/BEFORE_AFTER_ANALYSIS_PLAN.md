# 정문 교차로 개선 전후 분석 항목

- 작성: Aside 초안 / 승인: 사용자 / 작성일: 2026-11-02
- 대상: 정문 교차로(개선안 도면 A4 "정문 인근 3")
- 시공안: (개선안) 3지교차로. 대안1(우회전 전용), 대안2(회전교차로)는 채택되지 않음

## 1. 개선 내용 (도면 기준)

| 구분 | 개선 전 | 개선 후 |
|---|---|---|
| 교차로 형태 | 4지 회전교차로, 중앙 교통섬(수목) | 3지 교차로. 중앙섬·수목 제거, 서측 접근로 폐쇄 후 남북축 보도로 전환 |
| 접근로 | 남서(정문 방향), 북동, 동측, 서측 | 남서, 북동, 동측 |
| 횡단보도 | 3곳(남서·동·북서) | 재배치. 정지선, 횡단보행자 대기공간, "보행자 주의" 노면표시 |
| 기하구조 | | 가각부 R=18m 보도 설치, 중앙선·유도선·진행방향 노면표시 |
| 속도 관리 | 교내 20km/h 표지 | 보행자 우선도로 기점·종점, 남서 접근로(A3) 과속방지턱·도막형 포장, 정문(A2) 고원식 횡단보도 |
| 시거 | 중앙섬 수목 | 수목 제거 |

준공도로 실제 시공 내용을 확인한 뒤 이 표를 갱신한다.

## 2. 비교 단위

- **교차로 전체**와 **공통 접근로(남서·북동·동측)** 단위로 비교한다. 서측 접근로와 북서 횡단보도는 "폐쇄된 시설"로
  개선 전 값만 보고한다.
- 건수는 노출량으로 나눈 **비율**로 비교한다(진입 차량 100대당, 횡단 보행자 100명당).
- 모든 비율에 95% 신뢰구간을 붙인다. 표본이 부족하면 사유 코드(`INSUFFICIENT_SAMPLE`)로 보고한다.
- 결과는 정문 교차로 단독 효과가 아니라 **개선 패키지 전체의 효과**로 해석한다(대조 지점 없음).

## 3. 분석 항목

| 분류 | 지표 | 정의 | 확인하려는 효과 | 우선순위 |
|---|---|---|---|---|
| 노출 | 방향별 차량 교통량 | 접근로·이동류(직진·좌·우회전)별 대수, 15분 단위 | 서측 폐쇄 후 교통 재배분 | 1 |
| 노출 | 횡단보도별 보행량 | 횡단 보행자 수, 15분 단위 | 보행 수요 변화 | 1 |
| 속도 | 접근 속도 | 횡단보도 상류 구간의 평균·85% 속도(km/h) | 속도 저감(보행자 우선도로, 과속방지턱) | 1 |
| 속도 | 20km/h 준수율 | 상류 구간 최고속도 ≤ 20km/h인 차량 비율 | 제한속도 준수 | 1 |

| 상충 | 차량-차량 상충 | 합류·교차(좌회전) 상충 PET | 3지 교차로의 좌회전 교차 상충 발생 여부 | 2 |
| 보행 경로 | 횡단보도 이용률 | 교차로 구역 횡단 중 횡단보도 안에서 건넌 비율, 무단횡단 비율 | 횡단보도 재배치·남북축 보도 효과 | 1 |

## 4. 측정 조건

- 속도·거리·PET는 **미터 환산이 검증된 뒤**에만 산출한다. 개선 전은 현황도와 개선 후 현장 실측(공통 시설물)으로,
  개선 후는 현장 실측으로 접근로별 스케일을 정한다.
- 개선 전후 모두 **같은 버전의 파이프라인과 같은 설정**을 쓴다. 각각 블라인드 GT로 검출·추적 정확도를 확인하고,
  정확도 차이가 결과에 미치는 영향을 함께 보고한다.
- 자동 산출 사건은 사람 검토를 거친 것만 확정 결과로 쓴다.
- 대표점(발점) 정의는 미터 환산 단계에서 정하고 개선 전후 같은 규칙을 적용한다.
