## 목적

COCO 사전학습 YOLO11m을 이 현장 드론 영상 100장(학습 85, 검증 15)으로 1차 미세조정한다. R01 GT v2에서
현재 모델(COCO)과 나란히 채점해 미세조정 효과를 확인한다. 발주처 제출 일정 때문에 라벨 범위를 분석 영역으로
줄인 1차 시험이며, 70% 달성 여부의 최종 판단은 2차 이후로 미룬다. 추적(ByteTrack) 파라미터와 homography는
이 TASK에 포함하지 않는다.

## 운영 규칙

- A. 분할 설정은 `configs/`의 새 파일에 프레임 범위로 저장하고, 체크포인트 1 승인 후에는 바꾸지 않는다(PROJECT_RULES §4).
  테스트 구간(DJI_0486, DJI_0482 130~210초, 경계 여유) 프레임은 학습 데이터 생성 코드가 읽지 못하게 막고 테스트로 확인한다.
- B. 학습 입력 단위는 추론과 같은 1024×1024 타일(겹침 0.2, `configs/evaluation_detection_v2.yaml`)이다. 라벨은 4K 원본 좌표로
  저장하고 타일로 자른다. 다각형과 겹치지 않는 타일은 학습에서 뺀다. 타일 경계에서 잘린 박스의 유지 기준과 근거는 Codex가 제안한다.
  유지하지 않는 부분은 무시영역으로 처리한다.
- C. 무시영역과 다각형 밖은 학습 타일에서 회색으로 칠한다. 라벨된 박스 영역은 칠하지 않는다.
- D. 초벌 박스는 현재 YOLO11m을 낮은 confidence(제안 0.05)로 돌려 다각형 안 박스만 만든다. 사람이 규칙에 맞게 고친다.
  행마다 `label_source`(model_draft/manual)와 `revision_action`을 기록한다. 모델이 이륜차 운전자를 person으로 따로 낸 경우가
  많으므로 도구에서 "합치기"(person + motorcycle/bicycle → 하나의 이륜차 박스)를 쉽게 한다.
- E. 클래스 인덱스: 기존 평가 호환표를 바꾸지 않는 방안을 우선한다. COCO 80 인덱스 유지와 6개 클래스 헤드(평가 때 COCO ID로
  되돌림)를 비교해 체크포인트 1에서 권장안과 함께 보고한다.
- F. 학습 설정(epoch, batch, 증강, 조기 종료)은 Codex가 제안한다. 1 epoch 연기시험으로 시간과 최대 VRAM을 잰 뒤 본 학습 시간을
  다시 추정한다. 장비: RTX 5060 Ti 16GB(이 PC에서 학습은 처음).
- G. 운영 confidence는 R01이나 DJI_0486으로 고르지 않는다. 평가는 TASK-007·008과 같은 conf 0.15·0.25로 한다.
- H. 새 가중치는 `models/`에 새 이름으로 저장하고 SHA-256을 기록한다. `configs/baseline.json`은 수정하지 않는다.
- I. 학습 라벨은 GT가 아니다. `data/ground_truth/`가 아닌 별도 경로(예: `data/training_labels/`)에 두고, GT v1·v2 파일은 읽기만 한다.

## 범위

### 1단계: 기준선·분할·프레임·도구 (체크포인트 1까지)

1. 현재 모델의 차도 횡단 보행자 재현율(D-1): TASK-008 재채점에 쓴 기존 TASK-007 A 검출 결과를 GT v2로 다시 집계한다
   (GPU 실행 없음). conf 0.15·0.25, IoU 0.5·0.3. 해당 객체 수와 anchor 수, 경계 사례(발점이 마스크 경계 근처) 몇 개를 함께 보고한다.
2. 분할 설정 파일(위 표)을 만들고 클립별 학습·검증·제외 프레임 범위와 합계(초, 장)를 보고한다.
3. 분석 영역 다각형(D-3)을 클립별로 만들고 대표 프레임 오버레이를 저장한다.
4. 학습 85장, 검증 15장 프레임 목록을 만든다(D-5). 어려운 장면 선정 근거(자동/수동)를 기록한다.
5. 학습 라벨 모드: GT v2 재검토 도구를 확장해 프레임 단위로 여러 객체를 추가·삭제·수정하고, 클래스 선택, 무시영역, 속성, 이륜차 합치기를
   지원한다. 다각형 밖은 화면에서 어둡게 표시한다. 테스트 구간 프레임은 열리지 않게 한다.
6. 선정 프레임의 초벌 박스를 만든다(운영 규칙 D).
7. 테스트(`unittest.TestCase`, pytest): 테스트 구간 차단, 다각형 마스킹, 라벨 저장 형식, 합치기.
8. **체크포인트 1**: 1~7 결과, 클래스 인덱스 방안(E), 도구 실행 명령(WSL 저장소 루트)과 정상 화면 설명, 초벌 박스 통계를 보고하고 대기한다.
