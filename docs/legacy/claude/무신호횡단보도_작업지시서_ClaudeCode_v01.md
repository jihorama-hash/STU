## 0. 시작 전에 — Claude Code 에게 먼저 알릴 것

```
이 작업은 기존 Phase B 파이프라인(PET 상충 검출)의 연장이 아니라 분석 프레임 전환이다.

바뀐 것:
  - 열거 단위가 "PET 상충"에서 "차량-보행자 상호작용 전수"로 바뀐다
  - 주지표가 PET/RTTC 에서 DPD/PDI(연속 위험도 0~1)로 바뀐다
  - "오탐"이라는 개념이 대부분 사라진다. 저위험 상호작용은 DPD≈0.03 으로
    정상 계수되며, 버리지 않는다

금지 사항:
  - 오탐을 줄이려고 ROI 를 좁히거나 각도 필터를 넣지 말 것
  - 파라미터를 코드에 하드코딩하지 말 것 (전부 YAML)
  - 게이트 미통과 상태에서 지표를 산출하지 말 것
  - 결과가 좋아지는 방향으로 임계값을 조정하지 말 것

체크포인트에서는 반드시 멈추고 결과를 보고할 것. 끝까지 밀어붙이지 말 것.
```

## 페이즈 1 — 영상 정합 V-A2 **(최우선 게이트)**

**이것을 건너뛰면 이후 전부 재작업이 된다.** 4K/가로 60 m 기준 GSD ≈ 0.0156 m/px 에서 위치 게이트 0.10 m 는 6.4 px 다. 기체가 1 m 표류하면 64 px — 허용치의 10배.

| # | 작업 | 주체 |
|---|---|---|
| 1-1 | 기준 프레임 후보 3개 자동 선정(선명도·가림 최소) 후 이미지로 제시 | CC → 사용자 승인 |
| 1-2 | 노면 고정 특징점 후보 자동 검출 → 표시한 이미지 제시. 스트라이프 모서리·정지선 끝·맨홀·연석 모서리 우선, **차량·보행자·그림자 배제**, 화면 네 귀퉁이에 고르게 분포 | CC → 사용자 승인 |
| 1-3 | 프레임별 유사변환(평행이동+회전+스케일) 추정. ECC 또는 ORB+RANSAC. 결측은 시간축 보간 + median 이상치 제거 | CC |
| 1-4 | **궤적 좌표만 역변환** → `x_ref`, `y_ref` 생성. 검지·추적 재실행 불필요 | CC |
| 1-5 | 잔차 산출. **정합 전 / 정합 후 둘 다** | CC |

합격: 정합 후 기준점 잔차 RMSE < **0.05 m**
산출: `registration/transforms_{clip}.npz`, `registration/residuals.csv`, `registration/reference_frame.png`

**추가 진단 (권장)**: 정합 전후로 기존 산출물(근접거리 분포 등)이 얼마나 달라지는지 비교한다. 크게 달라진다면 지금까지 지표가 흔들린 원인이 검지·추적이 아니라 여기였다는 뜻이다.

**■ 체크포인트 B** — 정합 전/후 잔차와 표류 궤적을 보고하고 멈춘다. **여기서 이후 계획이 갈린다.**

## 페이즈 3 — 공간 기준요소 디지타이징

**동일 위치이므로 1벌만 만든다.** 기준 프레임(정합 좌표계) 위에 그린다.

| 요소 | 지침 |
|---|---|
| `CW` | 얼룩말무늬 외곽선에 **엄격히**. 여유폭 금지 |
| `CW_ext` | CW 를 보행 진행방향 좌우로 각 1.0 m 확장 (자동 생성 가능) |
| `WZ` | 연석선에서 후방 2.0 m 이내 보도 영역. 양측 각각 |
| `SW` / `RW` | 인도 / 차도. E-2x 판정 기준 |
| `SL` | 정지선. 없으면 `has_stop_line: false` + L1-4 결격 기록 |
| `A5` | 진행방향별 CW 진입 가장자리(또는 SL) 상류 5 m |
| `D20` / `D30` | 접근부 상류 20 m·30 m 기준선, 양방향 |
| `TURN` | 기존 회전부 ROI 를 이관 |

**작업 방식**: Claude Code 가 대화형 디지타이징 도구(간단한 HTML/Canvas 또는 matplotlib ginput)를 만들고, 사용자가 클릭. 완료 후 오버레이 미리보기 이미지를 반드시 확인한다.

## 첫 지시 (그대로 붙여넣기)

```
첨부한 3개 문서(지표정의서 v0.3, 구현사양서 v0.1, 파라미터 YAML)를 먼저 읽어라.
이번 작업은 기존 PET 상충 검출 프레임에서 "상호작용 전수 분류" 프레임으로의
전환이다. 구현사양서 부록의 기존 코드 처리 방침을 확인할 것.

오늘은 작업지시서의 페이즈 0 과 페이즈 1 만 수행한다.

페이즈 0:
  - 8개 영상에 ffprobe 를 돌려 fps/해상도/duration/생성시각을 뽑고
  - DJI .SRT 또는 .LRF 동반 파일이 있는지 확인해서 있으면 프레임별
    GPS·상대고도를 파싱하고
  - 생성시각과 duration 으로 클립 간 공백을 계산해 clips.yaml 을 작성하라
  - 기존 스크립트·산출물을 구현사양서 부록 기준으로 폐기/재사용/재작성 분류해
    MIGRATION_PLAN.md 로 정리하라
  → 여기서 멈추고 총 실관측시간, 클립 간 공백, .SRT 유무,
    (있다면) GPS 로 본 호버 표류량을 보고하라

그 결과를 확인한 뒤 페이즈 1(영상 정합)로 넘어간다.

ROI 를 새로 그리거나 지표를 산출하는 작업은 아직 하지 마라.
```
