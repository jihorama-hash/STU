## 다음 예정 작업 (우선순위 순)

1. **[최우선] 횡단보도 전건 육안 재검토 (8편, 약 30분 분량)**
   지금까지의 판정은 전부 "알고리즘 후보 지점만 확인"한 것이라 회수율이 미검증 상태.
   `runs/before_l_mt09/combined_interim/combined_annotated.mp4`(8편 이어붙인 리뷰용
   영상) 또는 개별 영상을 처음부터 끝까지 보면서, 알고리즘이 표시하지 않은 지점의
   실제상충도 찾아 기존 xlsx 서식의 "추가" 행으로 기록. 회전부는 이번엔 생략(나중에
   필요하면 추가).

2. **횡단보도 ROI 경계 조정 검토 (특히 crosswalk_southwest)**
   오탐 패턴 분석 결과 southwest가 물량(15건)은 가장 많은데 정밀도(13.3%)는 가장
   낮음 — 오탐 대부분이 "동시체류+PET=0+교차각 140~173도"(인도를 따라 걷는 궤적).
   `calib/rois_split_preview.jpg`를 보면서 ROI가 스트라이프보다 넓게 잡혀있는지,
   아니면 로직(각도 필터) 쪽 문제인지 판단 필요.

3. **무단횡단 위험 지표를 상충률과 결합하는 방식 결정**
   현재 `risk_table_by_roi.csv`(PET 상충률)와 `jaywalk_crosswalk_risk_summary.csv`
   (무단횡단자-차량 근접 위험)가 별개 표로 존재. 별도 지표로 나란히 보고할지,
   횡단보도별 종합 위험 점수 하나로 합칠지(가중합 등) 방법론 결정 필요 — 이후
   `27_make_interim_outputs.py` 반영 여부가 여기 달림.

4. **(보류) 전건 육안 재검토를 회전부까지 확장할지 결정**
   1번을 횡단보도만으로 마친 뒴 필요성 재평가.

5. **(참고, 조치 불필요) DJI_0486 지난주 보고서 수치(33.3%) 불일치**
   최종본(`_Com.xlsx`) 기준 재계산 시 12.5%로 다름 — 근거 자료가 남아있지 않아 원인
   재현 불가. 이후로는 xlsx 실데이터 기준 수치(12.5%)를 canonical로 사용 중이므로
   추가 조치는 불필요하지만, 향후 비슷한 수치 재확인 시 "초안 vs 최종본" 차이를 의심할 것.

6. **정탐률 게이트 재평가**
   1~3번이 끝나 "확정 상충 리스트"(자동검출 중 실제상충 + 전건 재검토로 찾은 누락분)가
   나오면, 이 리스트를 기준으로 최종 리포트용 상충 수치를 재산정. 이 시점부터는 알고리즘
   정탐률 자체는 게이트로 쓰지 않고(하이브리드 접근의 취지), 확정 리스트만 신뢰.
