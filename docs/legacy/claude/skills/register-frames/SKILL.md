# 페이즈 1 — 영상 정합 V-A2 (최우선 게이트)

근거: `docs/무신호횡단보도_작업지시서_ClaudeCode_v01.md` 페이즈 1 및 §1-6, `docs/무신호횡단보도_구현사양서_v01.md` §2.1

**이것을 건너뛰면 이후 전부 재작업이 된다.** 8클립이 동일 위치라는 것은 카메라가 고정됐다는 뜻이 아니다. 고정호버링이어도 GPS·바람으로 기체가 표류한다. 4K/가로 60 m 기준 GSD ≈ 0.0156 m/px 에서 위치 게이트 0.10 m 는 **6.4 px** 다. 1 m 표류하면 64 px — 허용치의 10배.

## 작업

### 1-1. 기준 프레임 선정

선명도(Laplacian variance)와 노면 가림(정지 차량·보행자 밀도)을 점수화해 **후보 3개를 이미지로 제시**하고 사용자 승인을 받는다. 승인된 것을 `clips.yaml` 의 `site.registration_ref` 에 기록.

### 1-2. 고정 기준점 지정

노면 고정 특징점 후보를 자동 검출(Shi-Tomasi / ORB)한 뒤, **차량·보행자·그림자 영역을 배제**하고 화면 네 귀퉁이에 고르게 분포하도록 6개 이상을 고른다. 표시한 이미지를 제시하고 사용자 승인을 받는다.

우선순위: 횡단보도 스트라이프 모서리 > 정지선 끝 > 맨홀 > 차선 파선 끝 > 연석 모서리

**한쪽에 몰리면 회전 성분이 잡히지 않는다.** 배치를 반드시 육안 확인시킬 것.

### 1-3. 프레임별 변환 추정

```
model = similarity (평행이동 + 회전 + 스케일)   # 필요 시 homography 로 승격
방법  = ECC 또는 ORB + RANSAC 또는 LK 광류
결측 프레임 → 시간축 선형보간, 이상치 → median filter
```

→ `registration/transforms_{clip_id}.npz`

### 1-4. 좌표 역변환

**궤적 좌표만 역변환한다.** 영상 전체 워핑은 저장용량·화질 손실이 크고 불필요하다. **검지·추적을 다시 돌릴 필요도 없다.**

```
x_ref, y_ref = M^-1 · (x_px, y_px)
```

### 1-5. 잔차 산출

정합 **전과 후를 모두** 산출한다.

```
drift(t) = mean_i( p_i(t) − p_i(ref) )                  # 전역 평행이동
resid(t) = RMSE_i( p_i(t) − p_i(ref) − drift(t) )       # 회전·스케일 잔여
```

합격: 정합 후 잔차 RMSE < `registration.residual_tol_m` (YAML, 0.05 m)

### 1-6. 오차 분해 진단 — (a)~(e) 전부 수행

**(a) 표류량 시계열** — 클립별 dx·dy [px, m] 그래프, RMSE/P95/max, 회전각·스케일 시계열

**(b) 크기 판정** — GSD 는 페이즈 2 실측값으로 대체하되, 미확정이면 잠정 0.0156 m/px

| 정합 전 RMSE | 해석 | 조치 |
|---|---|---|
| < 0.05 m | 표류 무시 가능 | **정합 불필요.** 원인은 다른 데 있다 |
| 0.05 ~ 0.15 m | 게이트를 단독으로 소진 | 정합 수행 |
| 0.15 ~ 0.50 m | 지배적 오차원 | 정합 필수 + 기존 산출물 재산출 |
| > 0.50 m | 기하 부분 신뢰 불가 | Day3~4 결론까지 재검토 |

**(c) 시간 구조 판독**

| 패턴 | 원인 | 오염되는 것 |
|---|---|---|
| 저주파 드리프트 | GPS 위치 유지 오차 | 위치·ROI 판정·S_m. 속도는 영향 작음 |
| 고주파 진동 1~3 Hz | 바람 | 속도·가속도. **a₅ 와 V_m 직격** |
| 클립 경계 계단 | 클립별 호버 위치 차이 | 클립 간 비교. Day4 "영상별 정탐률 0~100 % 편차" |
| 회전(yaw drift) | 짐벌 방위 표류 | 화면 가장자리일수록 큼. **southwest 만 나쁜 이유일 수 있음** |

FFT 또는 주기도로 저주파/고주파 성분을 분리해 보고할 것.

**(d) 대조 검증 — 여기가 실제로 답을 내는 부분**

정합 전/후 좌표로 기존 산출물을 각각 재산출해 비교한다. 표적을 명시한다.

| 표적 | 판독 |
|---|---|
| Day4 §3 **PET=0 · 동시체류 9건** | 정합 후 횡방향 이격이 3 m 이상이면 원래 떨어져 있던 쌍 |
| Day4 §3 **교차각 140~173° 4건** | 사라지면 표류 기인 / 남으면 ROI·정의 기인 |
| **crosswalk_southwest 오탐 15건** | southwest 만 유독 나쁘면 (c) 회전 성분과 대조 |
| `jaywalkers.csv` 근접거리 분포 | 분포가 통째로 이동하면 표류가 지배적 |

```
정합 후에도 오탐 그대로 → 원인은 ROI·사건 정의 (v0.3 전환이 해법)
정합 후 오탐 사라짐      → 원인은 호버 표류 (기하 문제)
일부만 사라짐            → 공존. 각각의 기여 건수를 표로
```

**과대해석 금지**: 이 진단은 원인을 하나로 지목하지 않는다. **기하 오차와 그 외를 분리**할 뿐이다. 두 문제는 공존할 가능성이 높다.

**(e) 독립 교차검증** — `.SRT` 가 있으면 GPS 표류량(페이즈 0 산출)과 이미지 기반 표류량을 겹쳐 그린다. 두 방법은 완전히 독립이므로 서로를 검증한다. 형상이 어긋나면 기준점 선정을 다시 본다.
