# 체크포인트 보고

페이즈를 끝냈을 때 호출한다. **다음 페이즈로 넘어가기 전에 반드시 거친다.**

## 1. 체크포인트별 필수 보고 항목

| CP | 페이즈 | 반드시 담을 것 |
|---|---|---|
| **A** | 0 메타 추출 | 총 실관측시간, 클립별 duration·fps, 클립 간 공백, VFR 여부, `.SRT` 유무와 GPS 표류량(RMSE/P95/max), 마이그레이션 분류 건수, 여전히 빈 메타 항목 |
| **B** | 1 정합 | 정합 **전/후** 잔차(RMSE·P95·max), 크기 판정표 결과, 시간 구조(저주파/고주파/계단/회전), 대조 검증 4표적 결과, GPS 교차검증 일치 여부 |
| **C** | 2~3 캘리브 | 스케일 오차, 기준거리별 편차, ROI 검산 결과, 화면 중앙 60 % 이탈 지점 유무 |
| **D** | 4~5 게이트 | V-A/V-A2/V-D/V-B/V-B2 판정표, T-1 경고 항목, **불합격 시 원인 진단과 되돌아갈 단계** |
| **E** | 6~7 상호작용 | NI, 유형 구성비, 안전 상호작용 비율, E-1 건수(t_pr 2.5/1.5), E-2x, 충돌, review_required, 제외 사유 분포, group on/off NI 차이, **표본 판정 결과** |

## 2. 보고서 서식

```markdown
# 체크포인트 {A~E} — 페이즈 {n} 완료 보고

## 결과 요약
(3줄 이내. 숫자 중심)

## 상세
(위 표의 필수 항목 전부. 표와 그림으로)

## 판단이 필요한 지점
(사용자 결정이 필요한 것. 없으면 "없음")

## 다음 페이즈로 넘어가도 되는가
- [ ] 게이트/합격 기준 충족
- [ ] 산출물에 provenance 부착 완료
- [ ] 미해결 항목을 문서에 기록

## 미해결·이월
```

→ `runs/checkpoints/CP{X}_phase{n}_{YYYYMMDD}.md`

## 3. CLAUDE.md 갱신

"현재 상태" 블록을 갱신한다.

```
현재 페이즈 : {n+1} ({이름})
다음 체크포인트 : {다음}
게이트 상태 : {Stage 1 미실행 / 통과 / 불합격(사유)}
```

## 4. 원칙

- **숫자를 요약하지 말고 그대로 낸다.** "대체로 양호" 같은 표현 금지
- **합격/불합격을 명확히 판정한다.** 애매하면 불합격으로 본다
- 예상과 다른 결과가 나왔으면 **숨기지 말고 먼저 쓴다.** Day4 의 33.3 % vs 12.5 % 같은 불일치는 그 자리에서 기록해야 재현 가능하다
- 보고 후 **멈춘다.** 사용자 확인 없이 다음 페이즈로 넘어가지 않는다
