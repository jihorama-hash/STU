## 1. PoC 원칙 — 표본 부족은 실패가 아니다

이 프로젝트는 PoC다. 30분 영상은 결과가 아니라 **절차 검증용 데이터**다.

**성공 기준**
```
✔ 파이프라인이 정합 → 검지 → 분류 → CEI → IP → 리포트까지 끝까지 돈다
✔ CEI 가 표본 문제 없이 산출된다 (분모가 통과 차량이므로 원래 견고함)
✔ IP 가 표본 부족 시 폐기가 아니라 "방향성 참고 + CI 병기"로 격하되어 출력된다
✔ 무엇이 부족한지가 리포트에 명확히 남아 다음 관측 설계의 근거가 된다
```

**성공 기준이 아닌 것**
```
✘ 절대적으로 정확한 위험 등급
✘ A0/B0 경계의 논문 수준 완전한 정합
✘ 통계적으로 흠 없는 서열 확정
```

**실행 지침**
- NI < 100 이어도 IP 산출을 폐기하지 마라. "방향성 참고" 등급으로 낮춰 CI와 함께 출력하라.
- `INSUFFICIENT_SAMPLE` 판정이 여러 지표에서 나오는 것은 파이프라인 실패가 아니라 정상적인 PoC 산출물이다.
- 부트스트랩 서열 확률(지표정의서 §8.4)은 "가능하면 산출"이지 필수 관문이 아니다. 시간이 부족하면 생략하고 그 사실을 리포트에 명시하라.
- 원문 재확인(§10 미해결 항목, 예: PDI Figure 4)은 PoC 완주의 선결 조건이 아니다. 병기·각주 처리로 충분하다.

## 2. A0/B0 분리 보고 — 합산 금지

A0(차량이 먼저 통과, 시간이 비껴감)와 B0(차량이 정지·양보해서 보행자가 먼저 건넘)는 **결과만 같고 메커니즘이 정반대**다. A0는 "운 좋게 안 겹침", B0는 "운전자가 규범을 지킴"이다. 법적 의미도 다르다 — 대기 중인 보행자를 두고 차가 먼저 지나간 A0는 도로교통법 제27조 1항 위반 가능성이 있다.

```
금지: IP 리포트에서 "A0+B0 = 안전 X%" 로 합산 표기
필수: A0 %, B0 % 를 항상 분리 표기 (CI 각각 병기)
필수: B0 비율은 V-1(완전정지율)과 교차 검증
      → 두 수치가 크게 어긋나면 조우 판정 로직 또는 유형 분류 로직 중
        하나에 오류가 있다는 신호로 간주하고 경고를 출력하라
보류: A0/B0 경계 조건의 원문 Figure 4 재확인은 이번 PoC 필수 관문 아님(§1)
```

## 3. 조우(E-1) 판정에 모호 등급 신설 — 준수율 구간 보고

### 3.1 배경

연직(수직정사) 시점에서는 보행자가 WZ/CW에 **위치**했는지는 정확히 판별 가능하지만, 그 사람이 **횡단 의사**가 있었는지는 판별 불가하다(벤치 착석·통화·단순 보행과 구분 안 됨). 이는 알고리즘 개선으로 해결될 문제가 아니라 촬영 방식의 구조적 한계다.

**CEI는 보행자 궤적을 아예 쓰지 않으므로 이 문제의 영향을 받지 않는다. IP·준수율(secondary)만 영향을 받는다.** 따라서 이 절의 작업이 primary 경로(CEI·억제 패널)를 막는 관문이 되어서는 안 된다.

### 3.2 3분류 신설 (기존 이분법 대체)

```
E-1_confirmed : WZ 정지 후 실제 횡단으로 이어짐 → 의심 없음
E-1_ambiguous : WZ 내 정지 있었으나 미횡단 → 대기인지 아닌지 불명
E-1_excluded  : 평행 이동 등 명백히 비대기 패턴
```

준수율은 단일값이 아니라 **구간**으로 보고한다.

```
정지율 하한 = 정지 차량 수 / (confirmed + ambiguous)   ← ambiguous 를 전부 조우로 간주
정지율 상한 = 정지 차량 수 / confirmed                  ← ambiguous 를 전부 제외

리포트 표기 예: "정지율 34~48% (표본 모호성 반영 구간)"
```

이 구간 보고 방식은 **V-1~V-4 전체(완전정지율·감속양보율·미양보율·정지선침범율)에 동일하게 적용**한다.

### 3.3 파라미터 초안 — 파라미터 YAML에 신규 블록으로 추가

**중요: 이 블록은 파라미터_v02.yaml에 존재하지 않는다(확인 완료). 아래 초안을 그대로 신규 추가하라.**

```yaml
encounter_ambiguity:            # 신규 — 2026-08-13 지시문 반영
  enabled: true
  confirmed_rule: "WZ 정지 → CW 진입(실제 횡단)으로 이어짐"
  ambiguous_rule: >
    WZ 내 속도 ≈ 0 (v_stop 이하)로 min_dwell_s 이상 체류했으나
    이후 CW 진입 없이 WZ 이탈
  excluded_rule: >
    WZ 통과 시 연석과 평행한 이동 벡터(heading이 연석 방향과
    threshold_deg 이내), 정지 없음
  min_dwell_s: {value: 2.0, unit: s, evidence: C, note: "잠정값. 민감도 분석 대상"}
  threshold_deg: {value: 30.0, evidence: C}
  note: "Stage 2 육안 검토에서 confirmed/ambiguous 자동판정 대 사람판정 오분류율을 반드시 함께 보고"
```

`v_stop`은 기존 YAML의 정의를 재사용하라. 새로 정의하지 마라.

### 3.4 Stage 2 육안 검토

ambiguous로 분류된 사례의 **자동판정 대 사람판정 오분류율을 별도 집계**하여 리포트 부록에 실어라. **새로운 작업을 추가하는 것이 아니라 기존 육안 검토 항목에 이 집계를 끼워 넣는 것이다.**

## 4. 상충 확인 체크리스트 — 실행 전 필수

이번 지시문이 기존 파라미터 YAML과 상충하지 않는지 아래를 확인하라. 다섯 항목 모두 **파라미터_v02.yaml에 실재함이 확인되었다.** 값이 다르거나 항목이 없으면 작업을 멈추고 보고하라.

```
[ ] indicator_hierarchy.primary = [cei, suppression_panel]
        ← 변경 없음. §3의 조우 세분화는 secondary 에만 영향
[ ] interaction_profile(IP) 는 secondary 유지
        ← 변경 없음. §1~§3 반영해 출력 형식만 변경
[ ] cei.t_r = 1.0s  /  encounter.perception_reaction_s = 2.5s
        ← 목적이 다른 별개 파라미터다. 혼동 금지 원칙 변경 없음
[ ] reporting.forbid_single_composite_score: true
        ← 변경 없음
[ ] reporting.forbid_point_estimate_ranking: true
        ← 변경 없음. §3의 구간 보고는 이 원칙의 연장이다
```

## 5. 지표 명칭 — 리포트 표기 시 반드시 병기

```
PSD<1 통과율 (CEI) [%]
```

`PSD`(Proportion of Stopping Distance)는 Allen, Shin & Cooper(1978)의 기성 SSM이고 임계값 1도 그들의 정의다. `CEI`(Counterfactual Exposure Index)는 본 과제에서 만든 집계 명칭으로 기존 문헌의 지표명이 아니다. **제목·요약에 CEI 를 단독으로 쓰지 마라.**
