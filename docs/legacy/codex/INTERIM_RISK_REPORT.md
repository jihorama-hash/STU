# 중간 위험도 분석 보고서 — 횡단보도 진입/진출 분리 상충 분석

작성일: 2026-07-10
지위: **스크리닝(예비) 분석.** RTX 시스템 도입 전, 파일럿 데이터(3fps, 0482만 10fps)를
후처리 개선만으로 재분석한 결과다. 절대 건수가 아닌 **상대 비교(순위·비율)**로 해석할 것.
본분석(Phase B, 15fps + 검출 개선 + 실세계 좌표)에서 전량 대체된다.

## 1. 분석 개요

### 1.1 파일럿 대비 개선 사항

| 항목 | 파일럿 | 본 중간분석 |
|---|---|---|
| 횡단보도 ROI | 전체 1개 폴리곤 | **진입측/진출측 분리** (안전지대 중앙 기준, 3개소×2) |
| 상충 짝짓기 | 같은 폴리곤 통과 전부 | **이동방향 교차각 필터** (차량-차량 추종 배제, 평행이동 의사보행자 배제, 정지·유령 배제) |
| 보행자-차량 동시체류 | 누락(PET<0 제외) | **overlap 상충(PET=0)으로 포착** |
| 영상 간 좌표 | 미보정(40~180px 어긋남) | **첫 프레임 homography 정합 보정** |
| 위험 지표 | 가중 점수(risk_score) | **상충 발생율** (건/보행자100진입, 건/차량100진입, 건/시간) |
| 무단횡단 | 미집계 | **차도 마스크 기반 별도 집계** |

## 3. 주요 발견

1. **보행자 위험의 1·2위는 횡단보도가 아니라 회전부 진입부다.**
   진입 남측·서측의 pv 발생율(21.8, 14.0)이 모든 횡단보도(≤5.3)를 압도한다.
   이 상충의 상대 보행자는 대부분 **무단횡단자**다(0482에서만 56명 확인) —
   무단횡단 관리(펜스·유도)가 횡단보도 개선만큼 중요하다는 뜻.
2. **횡단보도 중에서는 SW·동측의 '진입측'이 보행자 상충 우세** (5.3, 4.9 vs 진출측 4.4, 1.2).
   단, SW **진출측은 차량-차량 상충 최다**(6.1) — 회전부에서 나온 차량의 가속·합류
   구간과 겹치는 위치 특성. 진출측 차량-보행자 위험은 진출 차량이 적은 시간대
   표본 특성일 수 있어 개선 후 재검증 필요.
3. **NW횡단보도는 보행량(334명)이 가장 많지만 상충은 최소** — 차량 통행 자체가
   적어서(26대)다. 현 상태 유지가 합리적.
4. 히트맵상 고위험점 2곳: **동측횡단보도 진입측**(지상검증의 실제상충 다발 지점과
   일치), **회전부 진입 남측의 서쪽 구간**(SW횡단보도 인접 무단횡단 경로).

## 5. 한계 (해석 시 필수 유의)

1. **3fps 과소검출**: 보행자-차량 상충의 약 65%가 누락되는 조건(Phase A 실측).
   0482(10fps) 외 7편의 상충·무단횡단 건수는 하한값이다.
2. **정탐률 21%**: 여전히 유지 이벤트 5건 중 4건은 실제 상충이 아닐 수 있다.
   순위 비교용이지 절대 빈도가 아니다.
3. **분모(진입수) 인플레**: 궤적 분절로 같은 사람·차가 중복 집계될 수 있다.
   분자·분모가 같은 방향으로 부풀므로 비율의 순위는 비교적 안정적이다.
4. **TTC·속도 미반영**: 시간 근접(PET)만 반영. 접근 속도 기반 심각도는 Phase B에서.
5. **추돌형(동일방향) 차량 상충 제외**: 교차각 필터의 의도된 트레이드오프.
6. 무단횡단 수는 궤적 분절로 중복, 3fps에서 과소 — **0482 수치(5분에 56명)를
   대표값으로, 나머지는 참고로만.**

## 6. Phase B에서 대체·보완될 항목

- 15fps 전량 재검출(누락 회수) + 수목·그림자 미세조정 모델(#32·#52형 회수)
- GCP 실세계 좌표 → 발생율의 물리 단위화, 개선 전·후 직접 비교
- TTC/DRAC 기반 심각도, 추돌형 상충 복원
- 본 보고서의 분할 ROI 체계(`calib/rois_split.json`)와 발생율 지표 정의는
  Phase B에 그대로 승계
