## 2. 오늘(2026-07-30) 작업 계획

### 2.1 오늘의 목표와 완료 기준

오늘의 핵심 목표는 **DJI_0482를 대표 영상으로 사용해 검출 모델 상향의 효과를 정량 비교하고,
후속 상충 분석에 사용할 궤적·ROI·필터 조건을 확정하는 것**이다. GPU 환경은 작업 시작 전에
다시 확인했으며 정상이다(`nvidia-smi`, PyTorch CUDA 인식 모두 통과).

오늘 완료로 판정하려면 아래 산출물이 있어야 한다.

1. `yolo11m` 기준선과 대형 모델 후보의 DJI_0482 동일 조건 비교표
2. 그림자 문제 구간과 완전 횡단 사례를 포함한 궤적 육안검증 결과
3. 채택 모델 또는 다음 단계로 넘어가야 하는 근거가 기록된 판정
4. 0.5초 미만 궤적 필터 적용 전·후 통계와 보존된 출력
5. 회전부 진입/순환/진출 ROI 초안과 미리보기
6. 방향 교차각 기반 상충 로직의 현행 코드 점검 결과 및 최소 1편 시험 결과

### 2.2 작업 1 — 비교 조건과 기준선 고정

모델 외 조건이 결과에 섞이지 않도록 DJI_0482에 대해 아래 조건을 고정한다.

- 입력 영상: `record/before/DJI_0482.MP4`
- 파이프라인: `src/29_sahi_bytetrack_pipeline.py`
- 처리 간격: `--frame-step 2`(약 15fps)
- 슬라이스: 1024×1024, overlap 0.20
- 검출 임계값: confidence 0.15, NMS IoU 0.50
- 추적 가림 허용: 3.0초
- 기준 출력: `runs/before/DJI_0482/`

비교 지표는 전체 검출 수, 클래스별 검출 수, 트랙 수, 평균/중앙 트랙 지속시간, 0.5초 미만
트랙 비율, 완전 횡단 ID 유지 여부, 그림자 구간 누락·ghost 수, 처리시간 및 최대 GPU 메모리다.
기준 출력은 덮어쓰지 않고 모델별 별도 디렉터리에 저장한다.

### 2.3 작업 2 — 대형 모델 단계 비교 (최우선)

1. `yolo11l` 가중치를 확보하고 DJI_0482를 동일 조건으로 처리한다.
2. `yolo11m`과 `yolo11l`의 정량 지표 및 동일 장면 오버레이를 비교한다.
3. `yolo11l`이 그림자 구간 recall 또는 궤적 연속성을 의미 있게 개선하면 우선 채택한다.
4. 개선이 불충분하고 시간·VRAM 여유가 있을 때만 `yolo11x`를 같은 방식으로 시험한다.

판정은 단순히 ghost 비율이 낮아졌다는 이유만으로 내리지 않는다. 정상 보행자 검출까지
줄어드는 경우는 개선으로 인정하지 않으며, 같은 표본을 육안 판정해 **궤적 정상률 70% 이상**
여부를 확인한다. 대형 모델이 개선되지 않으면 8편 전체 재처리는 하지 않는다.

### 2.4 작업 3 — 조건부 VisDrone 모델 검토

`yolo11l/x`가 게이트에 미달할 때만 진행한다. 공개 가중치의 출처, 라이선스, 클래스 매핑을
먼저 검증하고 COCO 클래스와 무리하게 혼용하지 않는다. 호환 가능한 가중치가 확인되면
DJI_0482의 짧은 문제 구간으로 사전시험한 뒤 전체 대표 영상을 처리한다. 출처나 클래스 정의가
불명확하면 오늘 실행하지 않고 후보 조사 결과만 남긴다.

### 2.5 작업 4 — 최소 지속시간 필터 확정

현행 코드에는 이미 최소 지속시간 옵션이 있다.

- `src/25_compute_pet_directional.py`: 기본 0.3초
- `src/06_compute_pet_m0615.py`: 최소 지속시간 옵션 제공
- `src/20_make_pedestrian_trajectory_overlay.py`: 오버레이 필터 옵션 제공

따라서 새 필터를 중복 구현하지 않고 Phase B 기준을 **0.5초**로 통일할 수 있는지 영향도를
평가한다. 필터 적용 전·후 클래스별 트랙 수와 제거율을 기록하고, 완전 횡단·정상 짧은 통행이
제거되지 않는지 표본 검증한다. 원본 `tracks_pixel.csv`는 보존하며 필터는 후처리 단계에서
적용한다.

### 2.6 작업 5 — 회전부 ROI 3분할

현재 `calib/rois_split.json`은 세 횡단보도를 진입/진출로 분리했지만 회전부 2개 ROI는
분할되지 않았다. 회전부 차량 흐름을 **진입/순환/진출**로 나누는 폴리곤을 추가하고,
기준 프레임에 겹쳐 그린 미리보기로 아래를 확인한다.

- 폴리곤 간 불필요한 중첩 또는 공백
- 실제 차량 궤적과 방향 라벨의 일치
- 기존 횡단보도 ROI 보존
- 8편 정합 좌표계에서 공통 사용 가능 여부

자동 작도 결과만으로 확정하지 않고 미리보기와 대표 궤적을 함께 확인한 후
`calib/rois_split.json`을 갱신한다.

### 2.7 작업 6 — 경로 교차 기반 상충 로직 점검·보완

`src/25_compute_pet_directional.py`에는 이미 방향 교차각 기반 필터 초안(기본 20°)이 있으므로
처음부터 다시 작성하지 않는다. 새 ROI 구조와 0.5초 필터를 입력으로 사용할 수 있는지
점검하고 DJI_0482 한 편으로 시험한다.

검증 항목은 다음과 같다.

- 같은 방향 차량-차량 쌍이 추종으로 제외되는지
- 보행자-차량의 실제 교차 경로가 보존되는지
- PET ≤1.5초 후보가 원본 프레임에서 실제 상충인지
- 이벤트 중복 병합이 동일 사건을 여러 건으로 세지 않는지
- 출력에 ROI, track ID, PET, 교차각, 시각이 추적 가능하게 남는지

시험 결과가 타당할 때만 8편 전량 상충 분석으로 확대한다.

### 2.8 작업 7 — 지상검증 이관

자동 분석 후보와 오버레이를 `survey/지상검증_수동조사표_v2.xlsx`의 판정 단위에 맞춰
정리한다. 자동 수치만으로 게이트 통과를 선언하지 않으며, 정탐률·재현율 판정은 수동조사
결과가 입력된 뒤 확정한다.

## 3. 실행 순서와 의사결정 게이트

```text
환경 확인(완료)
  → 비교 조건 고정
  → yolo11l 대표 영상 시험
      ├─ 정상률 ≥70%, recall 개선: 모델 후보 채택
      └─ 미달: yolo11x 또는 검증된 VisDrone 후보를 조건부 시험
  → 0.5초 필터 영향 평가
  → 회전부 ROI 3분할
  → 방향 교차 상충 로직 DJI_0482 시험
      ├─ 정탐률 ≥70%: 8편 확대 준비
      └─ 미달: 임계값 조정 또는 육안확정 하이브리드 유지
  → 지상검증 자료 이관 및 오늘 결과 기록
```

오늘은 모델 또는 로직이 게이트를 통과하기 전에 8편 전체를 다시 처리하지 않는다. 대표 영상
한 편에서 실패 원인을 좁힌 뒤 확대하는 것을 원칙으로 한다.

## 5. 위험요인과 중단 조건

- 모델 가중치의 출처·라이선스·클래스 매핑이 확인되지 않으면 사용하지 않는다.
- 출력 경로가 기존 `runs/before/DJI_0482/`와 같으면 실행을 중단해 기준선 덮어쓰기를 막는다.
- 대형 모델에서 CUDA OOM이 발생하면 이미지 크기나 슬라이스 조건을 바꾸어 직접 비교성을
  훼손하지 않고, 우선 `yolo11l`로 되돌린다.
- 정상 보행자까지 줄어 ghost 비율만 개선된 경우 모델 개선으로 판정하지 않는다.
- ROI 육안검증 또는 상충 지상검증이 끝나지 않으면 “확정” 대신 “잠정”으로 표시한다.
