## 1. 프로젝트 개요 — 왜 이 분석을 하는가

### 1.1 배경

대상지는 **보행자 안전이 절대적으로 요구되는 단지(캠퍼스) 내 회전교차로**다.
해당 지점은 향후 **개선 공사가 계획**되어 있으며, 본 프로젝트의 목적은:

1. **개선 전** 교통안전 문제점과 그 강도를 정량적으로 조사하고,
2. 개선 공사 후 **동일 지점을 재촬영·재분석**하여,
3. **개선 전·후 상충(conflict) 위험의 변화를 객관적으로 입증**하는 것이다.

측정 대상은 사고가 아니라 **상충(교통류 간의 위험한 근접 사건)**이다. 사고는 드물어
단기간 관측으로 비교할 수 없으므로, 국제적으로 통용되는 대리안전지표(Surrogate Safety
Measures)인 **PET**(Post-Encroachment Time: 같은 공간을 두 객체가 통과한 시간 차)와
**TTC**(Time-to-Collision: 현재 속도 유지 시 충돌까지의 시간)를 사용한다.

관심 상충은 두 가지다.
- **보행자–차량 상충** (최우선: 횡단보도와 무단횡단 지점)
- **차량–차량 상충** (회전부 진입·순환·진출 간)

보도 위 보행자의 이동은 분석 대상이 아니다(차도상 이동만 대상).

### 1.2 방법 개요

드론으로 교차로 상공을 정지비행(호버링)하며 4K 영상을 촬영하고, Vision AI로
① 객체 검출(보행자·차량) → ② 추적(개체별 궤적 생성) → ③ 상충영역(ROI) 통과 분석 →
④ PET/TTC 산정 → ⑤ 위험도 지도·통계 산출의 순서로 처리한다.

### 1.3 지금까지의 경과

- 2026년 6월: 개선 전 영상 8편(DJI_0481~0488, 각 약 5분, 3840×2160 29.97fps) 촬영
  및 **파일럿 분석**(3fps 저샘플링) 완료.
- 2026년 7월: 파일럿 결과의 신뢰도를 실측 검증(**Phase A**)한 결과, 본분석 전에
  개선해야 할 문제들이 정량적으로 확인됨(2장). 본 문서는 그 개선을 반영한
  **본분석(Phase B) 실행 계획서**다.

## 2. 파일럿(Phase A)이 남긴 교훈 — 무엇을 바꿔야 하는가

Phase A에서 프레임 정합 실측, 샘플링 민감도 실험, **지상검증(수동조사)**을 수행했다.
지상검증은 DJI_0482 영상에 대해 자동분석 결과를 사람이 영상과 대조한 것이다.
그 결과가 본분석 설계의 근거이므로 반드시 이해하고 시작할 것.

### 2.1 실측으로 확인된 문제

| # | 문제 | 실측치 | 원인 |
|---|---|---|---|
| P1 | 자동 검출 상충의 대부분이 가짜 | 52건 중 실제상충 6건(**정탐률 12%**) | 오탐 44% + 단순통과 44% |
| P2 | 알고리즘 critical 판정 무효 | critical 5건 중 실제상충 **0건** | 픽셀 TTC 기반 규칙이 실위험과 무관 |
| P3 | 위험 순위 역전 | 자동 1위 entry_south는 실제상충 0건, 실제 핫스팟은 crosswalk_east(4건) | 회전부의 **같은 방향 순차 통행**이 상충으로 오짝지어짐 |
| P4 | 저샘플링의 상충 누락 | 3fps는 10fps 대비 보행자-차량 상충 **65% 누락**, 실제상충 6건 중 3건은 10fps에서만 검출 | 프레임 간격이 보행자 ROI 통과보다 김 |
| P5 | 보행자 궤적 품질 저조 | 정상률 **25%**(20개 중 5개), 분절 8·부분누락 6·ID스위치 1 | **수목·그림자 가림**이 지배적 + 단순(그리디 IoU) 추적기 |
| P6 | 분류 오류 | 이륜차→person 오분류, 보행자 4명→1개 ID 병합 | 범용 COCO 모델의 드론 부감 시점 한계 |
| P7 | 프레임 어긋남 | 영상 간 40~180px, 영상 내 드리프트 45~190px, 0488 말미는 기체 이동 | 호버링 드리프트 + 편집 없이 전량 사용 |

### 2.2 본분석의 4대 개선축 (본 계획서의 뼈대)

| 축 | 파일럿 방식 | 본분석 방식 | 근거 |
|---|---|---|---|
| **상충 정의** | ROI 폴리곤 5개, 폴리곤 내 모든 객체쌍을 상충 후보로 | **방향별 ROI 분리**(횡단보도 상행/하행, 회전부 진입/순환/진출) + **경로 교차 기반 짝짓기** | P1, P3 |
| **샘플링** | 3fps (frame-step 10) | **15fps (frame-step 2)** | P4 |
| **검출 모델** | 범용 yolo11m (COCO) | **단계적 개선: 대형 모델 → VisDrone 공개 가중치 → (미달 시에만) 현장 라벨 미세조정** | P5, P6 |
| **추적기** | 그리디 IoU 매칭 | **Kalman 기반(ByteTrack/OC-SORT)**, 가림 구간 관성 통과 | P5 |

추가 개선: 프레임 정합 전처리(P7), GCP 기반 실세계 좌표계(개선 전·후 비교의 전제),
안정 호버 구간 선별 편집(P7), critical 규칙 재설계 후 지상검증으로 재확인(P2).

> **주의: 파일럿의 정량 결과(ROI 순위, 상충 건수, per-1000 비율)는 보고서에 인용하지
> 말 것.** 정탐률 12%가 확인된 수치다. 파일럿의 가치는 방법론 확정에 있다.

## 5. 촬영 표준절차(SOP) — 개선 후 촬영 지침

개선 전·후 비교의 성패는 **촬영 조건의 재현**에 달려 있다.

1. **위치 재현**: 개선 전 촬영의 호버 지점·고도·헤딩을 드론 앱 웨이포인트로 저장해
   동일하게 재현한다. 첫 프레임을 개선 전 기준 프레임과 겹쳐 화각을 현장에서 확인.
2. **시간대 매칭**: 개선 전 영상과 **같은 요일·같은 시간대**(±30분)로 촬영.
   등·하교(출퇴근) 첨두를 반드시 포함.
3. **관측량**: 상충은 희소사건이다. 회당 5분×8편(약 40분)은 경향 파악 수준이므로,
   본분석은 **시간대별 최소 30분×3개 시간대(오전첨두·낮·오후첨두), 2일 이상**을
   권장 기준으로 한다(배터리 교체로 분할 촬영 허용 — 어차피 5분 블록으로 자른다).
4. **환경 조건**: 그림자가 긴 이른 아침·늦은 오후는 피하거나, 개선 전과 동일 시각으로
   맞춘다. 풍속 5m/s 이상이면 연기(드리프트 과다). 우천·직후 노면 반사 회피.
5. **촬영 설정**: 4K(3840×2160) 고정, **가능하면 60fps**(TTC 정밀도 향상 + 다운샘플 여유),
   짐벌 -90°(직하방), 노출 고정(자동노출 변동은 검출 안정성 저해).
6. **촬영 로그 필수**: 조사표의 `1_촬영로그` 시트를 촬영 당일 기입
   (일시·고도·날씨·풍속·그림자 방향·특이사항).

## 6. 영상 전처리 표준절차(SOP)

원본 → 분석 투입본(`edited\`)을 만드는 과정. **모든 단계는 스크립트로 수행**하고
수작업 편집은 금지(재현성).

### 6.1 안정 호버 구간 선별 (트리밍)

- 이륙·착륙·기체 회전·짐벌 조정 구간 제거.
- 판정 기준: 연속 프레임 간 특징점 이동량(중앙값)이 **프레임당 2px 이하**인 구간만 채택.
  파일럿의 DJI_0488 말미(기체 이동 구간이 분석에 섞임)가 이 단계로 걸러진다.
- 무손실 트림: `ffmpeg -ss <시작> -to <끝> -i in.MP4 -c copy out.MP4`

### 6.2 프레임 정합 (Registration)

- 현장별 **기준 프레임**을 하나 지정(개선 전·후 각각).
- 각 프레임을 ORB(6000 특징점)+RANSAC homography로 기준 프레임에 정합.
  파일럿 실측: 미정합 시 영상 간 40~180px, 영상 내 45~190px 어긋남 → 정합 후 잔차
  **RMSE 5px 이하**가 합격 기준. 기존 `src\21_measure_frame_alignment.py`가 측정 코드 기반.
- 도로는 평면이므로 homography 근사가 유효하다. 정합은 검출 좌표에 행렬을 적용하는
  방식(영상 재인코딩 불필요)을 기본으로 한다.

### 6.3 GCP 기반 실세계 좌표계 (개선 전·후 비교의 전제)

개선 공사로 도로 기하가 바뀌므로 픽셀 좌표계는 전·후 비교에 쓸 수 없다.

1. **공사 후에도 보존될 지물 4점 이상** 선정: 건물 모서리, 맨홀, 옹벽 끝단, 가로등 기초 등
   (노면표시·연석은 공사로 변경될 수 있으므로 제외).
2. 각 점의 실세계 좌표 확보: 현장 실측(줄자/GNSS) 또는 국토정보플랫폼 정사영상에서 판독.
3. 기준 프레임 픽셀좌표 ↔ 실세계좌표 homography 산출 → `calib\gcp_homography.json` 저장(git 추적).
4. 이후 모든 궤적·이벤트 좌표는 **미터 단위**로 변환. 속도는 m/s, PET·TTC는 물리량이 된다.
5. 검증: GCP 외 검증점 2개 이상에서 변환 오차 **0.3m 이하** 확인.

### 6.4 분석 범위 크롭

- 교차로 분석 범위만 포함하는 크롭 창을 정의(`calib\crop.json`).
  4K 전체 15슬라이스 → 크롭 후 8슬라이스 수준으로 SAHI 연산 30~50% 절감.
- **보도 마스킹은 검출 단계에서 하지 않는다.** 횡단 시작 직전 보도 대기자를 놓치면
  진입 타이밍이 왜곡된다. 보도 보행자 제외는 **후처리(궤적 필터)**에서 차도 마스크로 수행.

### 6.5 분석 단위 표준화

- 전처리 완료본을 **5분 블록**으로 분할, 블록별 메타데이터(일시·시간대 구분) 기록.
- 전·후 비교는 이 블록을 최소 단위로 시간대 매칭한다(9장).

## 7. 분석 파이프라인 — 단계별 상세

```
[전처리 완료 영상]
  → (1) 검출: SAHI + 미세조정 YOLO, 15fps
  → (2) 추적: ByteTrack/OC-SORT (Kalman)
  → (3) 좌표 변환: 정합 + GCP → 실세계(m)
  → (4) 궤적 필터: 차도 마스크, 최소 지속시간
  → (5) 상충 분석: 방향별 ROI + 경로 교차 짝짓기 → PET/TTC
  → (6) 위험도 산정·시각화: 지도(히트맵), ROI 통계
  → (7) 지상검증 → 합격 시 확정, 불합격 시 해당 단계 보완 후 재실행
```

### (1) 검출 — SAHI + 미세조정 YOLO, 15fps

- **샘플링: frame-step 2 (29.97fps → 약 15fps).** 근거: 3fps는 보행자-차량 상충 65%
  누락(P4). 10fps에서도 실제상충의 절반은 10fps에서 처음 잡혔으므로 안전 여유를 두어 15fps.
- SAHI 파라미터(파일럿 검증값 유지): slice 1024×1024, overlap 0.20, conf 0.15,
  classwise NMS 병합.
- **검출 개선 — 단계적·조건부 접근 (P5·P6 대응)**:
  각 단계 후 8장 지상검증 게이트(궤적 정상률 ≥70%, 상충 정탐률 ≥70%)를 측정하고,
  **통과하면 다음 단계로 넘어가지 않는다.**
  - **1단계 (라벨링·학습 불필요)**: 15fps + ByteTrack 조합을 전제로, 기본 모델을
    yolo11m → yolo11l/x로 상향하고 conf 임계를 재조정해 평가.
    그늘 구간 끊김의 상당수는 Kalman 추적기의 관성 통과로 회수되므로
    이 단계만으로 게이트를 통과할 가능성이 충분함.
  - **2단계 (라벨링·학습 불필요)**: 공개 배포된 VisDrone 사전학습 가중치를 내려받아
    동일 게이트로 평가. VisDrone은 보행자/이륜차 탑승자를 별도 클래스로 구분하므로
    이륜차 오분류(P6) 완화 효과 기대.
  - **3단계 (1·2단계 게이트 미달 시에만)**: 현장 라벨 미세조정.
    현재 모델로 자동 사전라벨 생성 → 사람은 틀린 박스만 수정(300~500프레임, 반나절 수준,
    ①수목·그림자 아래 보행자 ②이륜차 ③군집 보행자 집중) → imgsz 1024,
    batch 8~16, 약 100 epoch 학습(RTX 5060 Ti에서 수 시간). 3단계로도 미달이면
    해당 구역을 "관측 한계 구역"으로 명시하는 12장 대응으로 전환하고 재검토.
  - 단계와 무관한 합격 기준: 검증셋 보행자 recall 0.85 이상, 이륜차/보행자 혼동 5% 이하.
  - **개선 전·후 비교 유의**: 어느 단계에서 확정하든 **전·후 분석에 동일 모델·동일
    파라미터를 사용**해야 비교가 성립한다(검출 편향이 양쪽에 동일하게 걸려 상쇄).
- 산출: `detections_pixel.csv` (frame_id, time_sec, class, conf, bbox, foot point)

### (2) 추적 — Kalman 기반

- supervision 라이브러리의 **ByteTrack**을 1차 채택(OC-SORT 대안).
  파일럿의 그리디 IoU 추적기는 폐기(정상률 25%의 주요 원인).
- 핵심 설정: `track_buffer`를 **가림 3초 관성 유지**가 가능하도록 설정(15fps 기준 45프레임).
  수목·그림자 아래에서 검출이 끊겨도 Kalman 예측으로 ID를 유지시키는 것이 목적.
- 합격 기준(지상검증으로 측정): 횡단 보행자 궤적 **정상률 70% 이상**(파일럿 25%),
  ROI 통과 궤적의 분절 평균 1.5조각 이하.
- 산출: `tracks_pixel.csv` → (3)을 거쳐 `tracks_world.csv`(m 단위)

### (3)~(4) 좌표 변환·궤적 필터

- 6.2 정합 행렬 + 6.3 GCP 행렬을 궤적 좌표에 적용.
- 차도 마스크(`calib\roadway_mask.json`) 밖에서만 존재한 궤적(보도 전용 보행자) 제거.
- 최소 지속시간 0.5초(15fps에서 8점) 미만의 단발 궤적 제거.

### (5) 상충 분석 — 파일럿과 가장 크게 달라지는 단계

**① 방향별 ROI 재정의 (P3 대응)**

| 파일럿 ROI | 본분석 ROI |
|---|---|
| crosswalk_northwest (1개) | NW횡단 **상행 / 하행** 접근별 2~4개 (횡단보도+양측 차로 접근부) |
| crosswalk_southwest (1개) | 동일 방식 분리 |
| crosswalk_east (1개) | 동일 방식 분리 — **파일럿 실측 유일 핫스팟, 우선 검증 대상** |
| roundabout_entry_west/south (2개) | 접근로별 **진입 / 순환 / 진출** 구분 |

ROI는 개선 전·후 각각의 기준 프레임에 작도하되, **실세계 좌표로 저장**(`calib\rois_world.json`)
하여 전·후 동일 기준으로 비교한다.

**② 경로 교차 기반 상충 짝짓기 (P1·P3 대응)**

파일럿은 "같은 폴리곤을 통과한 모든 이종 객체쌍"을 상충 후보로 삼아, 회전부를
순차 통행하는 같은 방향 차량들이 대량 오짝지어졌다(entry_south 20건 전원 비상충).
본분석의 짝짓기 조건:

1. 두 궤적이 같은 상충영역을 통과하고,
2. **두 궤적의 경로(방향벡터)가 실제로 교차**하거나(교차각 20° 이상),
   보행자-차량처럼 유형이 다른 경우, 그리고
3. PET = 후행 진입시각 − 선행 이탈시각이 0~5초.

같은 방향(교차각 20° 미만)의 차량-차량 쌍은 추종(car-following)으로 분류해
상충에서 제외한다(추후 참고 통계로만 보존).

**③ PET/TTC 산정 (실세계 단위)**

- PET: 초 단위, 임계 —near-conflict ≤1.5s / caution ≤3.0s (문헌 표준과 직접 비교 가능해짐).
- TTC: m/s 속도 기반으로 재산정. 속도 추정은 15fps에서 0.5초 창(8점) 회귀로 안정화.
- **critical 규칙은 재설계 후 검증 전까지 보고서에 쓰지 않는다**(파일럿 정탐률 0%).
  재설계안: `PET ≤ 1.5s AND 경로교차 확인 AND (보행자-차량 또는 TTC ≤ 2.0s)` —
  이 규칙의 정탐률을 8장 지상검증으로 확인한 후에만 채택.

### (6) 위험도 산정·시각화

- ROI별 상충률 = 상충 건수 ÷ 노출(보행자 진입 × 차량 진입 정규화), 시간당 비율로 표준화.
- 지도: 실세계 좌표 기반 밀도 히트맵(정사영상 배경). 보행자-차량 / 차량-차량 **분리 작성**
  (파일럿에서 두 지표의 순위가 달라 혼란 초래한 교훈).
- 궤적도: 횡단 보행자 전 궤적 오버레이(무단횡단 경로 가시화 — 개선 설계의 직접 근거).

### (7) 파일럿 자산의 재사용/폐기 구분

| 기존 스크립트 | 처리 |
|---|---|
| 03(SAHI 검출), 21(정합 측정), 23(궤적 오버레이) | 개량 후 재사용 |
| 04(그리디 추적기) | **폐기** → ByteTrack 대체 |
| 05~06(ROI·PET) | **재작성** (방향별 ROI + 경로 교차 짝짓기) |
| 17(TTC·critical) | **재작성** (실세계 단위 + 신규 규칙) |
| 16, 18~20(통합·정규화·시각화) | 골격 재사용, 좌표계·지표 교체 |

### 8.3 합격 게이트 — 불합격 시 해당 단계로 되돌아가 보완 후 재검증

| 지표 | 파일럿 실측 | 본분석 합격 기준 |
|---|---:|---:|
| 통행량 오차 (ROI 진입수, 수동 대비) | 미측정 | ±10% 이내 |
| 횡단 보행자 궤적 정상률 | 25% | **70% 이상** |
| 상충 정탐률 (실제상충/자동검출) | 12% | **70% 이상** |
| critical 정탐률 | 0% | **60% 이상** (미달 시 critical 지표 미사용) |
| 상충 재현율 표본 점검* | — | 누락 20% 이하 |

*재현율: 수동 판독자가 영상 10분에서 직접 찾은 실제 상충 목록과 자동 검출을 대조.

## 9. 개선 전·후 비교 분석 설계

1. **블록 매칭**: 개선 전·후 5분 블록을 같은 요일·시간대끼리 짝지어 비교
   (예: 화요일 오전첨두 전 6블록 vs 후 6블록).
2. **지표**: 시간당 상충률(보행자-차량 / 차량-차량 분리), PET 분포(중위수·1.5s 미만 비율),
   무단횡단 건수·경로, ROI별 상충률.
3. **통계 처리**: 상충은 계수(count) 자료이므로 블록별 발생률에 포아송/음이항 검정,
   **95% 신뢰구간**을 병기. 블록 수가 확보되지 않으면 "경향" 수준으로만 서술하고
   단정적 표현을 금한다.
4. **노출 보정**: 개선 후 통행량 자체가 변할 수 있으므로 반드시 노출(진입수) 정규화
   지표로 비교. 원시 건수 비교는 부록으로만.
5. **결론 보고서 구성**: ① 전·후 위험지도 대비 ② ROI별 상충률 변화표(신뢰구간 포함)
   ③ 무단횡단 변화 ④ 잔존 위험 지점과 추가 개선 제언.

## 10. 예상 처리시간 및 일정 계획

### 10.1 처리시간 (RTX 5060 Ti 16GB 기준 추정)

전제: SAHI 1024 슬라이스당 30~50ms, 크롭 적용 시 프레임당 8슬라이스.
**3.3절 벤치마크 실측으로 반드시 보정할 것.**

| 작업 | 단위 소요 | 5분 영상 1편 (15fps=4,370프레임) |
|---|---|---|
| SAHI 검출 (크롭, 8슬라이스) | 0.3~0.5s/프레임 | **22~36분** |
| SAHI 검출 (전체, 15슬라이스) | 0.5~0.9s/프레임 | 36~66분 |
| 추적 + 좌표변환 + 상충분석 | — | 5분 내외 |
| 모델 미세조정 (1회성) | — | 3~6시간 |

**총량 시나리오**: 개선 전 8편 재분석 + 개선 후 동량 촬영 시
검출 기준 편당 30분 → **16편 ≈ 8시간 = 야간 배치 1회**. 관측량을 권장 기준
(회당 90분×2일×전·후)으로 늘려도 총 72블록 ≈ 36시간 = 야간 배치 4~5회로 수용 가능.

## 12. 위험 요소 및 대응

| 위험 | 가능성 | 대응 |
|---|---|---|
| 미세조정 후에도 수목 아래 보행자 누락 | 중 | 라벨 추가·증강(그림자 합성), 그래도 미달 시 해당 구역을 "관측 한계 구역"으로 보고서에 명시하고 그 구역 통계는 별도 취급 |
| 개선 공사로 GCP 지물 소실 | 저 | GCP를 6점 이상 여유 선정, 공사 범위 밖 지물 우선 |
| 개선 후 촬영 조건 불일치(계절·그림자) | 중 | 시간대 매칭 우선, 불일치 블록은 비교에서 제외 |
| 상충 정탐률 70% 미달 반복 | 중 | 짝짓기 조건(교차각·PET창) 재조정 → 그래도 미달 시 "자동 선별 + 전건 육안 확정" 하이브리드로 전환(자동은 후보 축소기 역할) |
| GPU 처리시간 추정 초과 | 저 | 크롭 확대, conf 상향, 필요 시 야간 배치 횟수 증가로 흡수 |
| 데이터 유실 | 저 | 4.2 백업 규칙 준수 여부를 주간 점검 |
