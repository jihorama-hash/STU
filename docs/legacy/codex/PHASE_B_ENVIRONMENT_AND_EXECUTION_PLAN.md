## 1. 보고서 목적

본 보고서는 회전교차로 드론 영상의 Vision AI 기반 교통안전 분석을 본격적으로 수행하기 전에 필요한 환경 구축, 코드 안정화, 품질 검증, 전체 영상 처리 및 최종 산출물 작성 절차를 구체화하기 위해 작성되었다.

기존 파일럿 분석에서는 저샘플링, 궤적 분절, 오검출, 프레임 정합 오차 및 PET 상충 오판정이 확인되었다. 따라서 본분석은 기존 결과를 단순 재실행하는 방식이 아니라 다음 원칙에 따라 추진한다.

1. GPU 및 Python 분석 환경을 먼저 정상화하고 버전을 고정한다.
2. 본처리 전에 핵심 코드의 정확성과 OS 호환성을 개선한다.
3. 짧은 영상과 지상검증 영상으로 단계적 시험을 수행한다.
4. 사전에 정의한 품질 게이트를 통과한 설정만 전체 영상에 적용한다.
5. 모든 분석 설정과 결과의 재현성을 확보한다.

## 4. 세부 실행계획

### 4.1 1일차 오전: GPU 및 Python 환경 구축

#### 4.1.1 WSL2 GPU 접근 정상화

Windows PowerShell에서 다음 항목을 확인한다.

```powershell
nvidia-smi
wsl --status
wsl --version
wsl --update
wsl --shutdown
```

조치 순서는 다음과 같다.

1. Windows용 최신 NVIDIA Studio 또는 Production 드라이버를 설치한다.
2. `wsl --update`로 WSL과 커널을 갱신한다.
3. Windows를 재부팅한다.
4. WSL2를 다시 실행한다.
5. Windows와 WSL 양쪽에서 `nvidia-smi`를 확인한다.

WSL 내부에 NVIDIA Linux 디스플레이 드라이버를 별도로 설치하지 않는다. Windows 호스트 드라이버가 WSL에 GPU를 전달하는 구조이므로 Linux 드라이버를 중복 설치하면 충돌할 수 있다.

**합격 기준**

- Windows와 WSL 양쪽에서 GPU 이름이 정상적으로 표시될 것
- WSL의 `nvidia-smi`가 오류 없이 실행될 것
- 예상 GPU VRAM이 확인될 것
- 시스템 재부팅 후에도 GPU 접근이 유지될 것

GPU 접근 문제가 해결되지 않으면 전체 분석을 진행하지 않고 GPU 패스스루 문제를 우선 해결한다.

#### 4.1.2 Python 가상환경

프로젝트 전용 가상환경을 구성한다.

```bash
cd /home/jiho/GPT_Round
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip setuptools wheel
```

가상환경 활성화 후에는 `python`과 `pip`가 `.venv` 내부 실행파일을 가리키도록 한다.

#### 4.1.3 분석 패키지

다음 패키지를 기본 구성으로 설치한다.

| 구분 | 패키지 |
|---|---|
| GPU·딥러닝 | torch, torchvision |
| 객체 검출 | ultralytics, sahi |
| 추적 | supervision |
| 영상 처리 | opencv-python |
| 수치·데이터 | numpy, scipy, pandas |
| 보고·시각화 | matplotlib, openpyxl |
| 품질 관리 | pytest, ruff |

PyTorch는 공식 설치 선택기에서 Linux, Pip, Python 및 GPU에 맞는 CUDA 빌드를 선택한다. RTX 50 계열 지원 여부를 확인하고, 설치 후 실제 CUDA 행렬 연산을 수행하여 커널 호환성을 검증한다.

#### 4.1.4 환경 고정

설치가 완료되면 다음을 저장한다.

- `requirements.txt`: 프로젝트에서 직접 사용하는 패키지

- Python, PyTorch, CUDA 및 GPU 정보
- 환경 검증 결과

**환경 합격 기준**

- Ultralytics 모델의 CUDA 추론 성공
- `src/28_verify_environment.py`의 필수 항목 통과

일정은 GPU 성능 벤치마크와 품질 게이트 결과에 따라 조정한다. 검출 또는 추적 품질이 기준에 미달하면 전체 처리를 늦추고 모델·파라미터 개선을 우선한다.

## 7. 1일차 종료 목표

2026년 7월 30일 작업 종료 시점의 목표는 다음과 같다.

1. WSL2에서 NVIDIA GPU가 정상적으로 동작한다.
2. 프로젝트 `.venv`와 분석 패키지 설치가 완료된다.
3. 환경과 패키지 버전이 파일로 고정된다.
4. 환경 검증 스크립트의 필수 항목을 통과한다.
5. Linux 실행을 방해하는 경로 문제가 수정된다.
6. PET 핵심 로직의 자동 테스트가 작성되고 통과한다.
7. DJI_0484 연기시험을 실행할 수 있는 상태가 된다.

## 8. 결론

현재 영상자료와 저장공간은 본분석 수행에 충분하며, 데이터 형식도 일관되어 있다. 다만 WSL2 GPU 접근이 차단되어 있고 분석 패키지가 설치되지 않았으므로 환경 정상화가 가장 먼저 수행되어야 한다.

본 프로젝트는 환경 구축 직후 전체 영상을 실행하는 방식보다 코드 안정화, 단편 연기시험, 지상검증 및 품질 게이트를 순서대로 통과한 뒤 전체 처리로 확대하는 것이 적절하다. 특히 기존 파일럿에서 확인된 낮은 정탐률과 궤적 품질 문제를 고려하면 DJI_0482 지상검증 결과가 전체 처리 착수 여부를 결정하는 핵심 기준이 된다.

최종 결과는 원본 영상, 코드, 모델, 파라미터, 환경 및 품질 검증 기록이 함께 보존되어야 하며, 동일 환경에서 재실행 가능한 형태로 관리한다.
