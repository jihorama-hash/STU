# 재구축 계획

## 목표

현행 회전교차로 분석 파이프라인의 재현성을 유지하면서 객체·궤적 품질을 먼저 검증하고, 이후 한국 무신호 횡단보도의 횡단사건·보행자-차량 상호작용·안전지표 분석으로 확장한다. 분석과 데모는 동일한 버전 산출물을 사용한다.

## 현행 파이프라인 진단

| 단계 | 현재 상태 | 주요 보완 |
|---|---|---|
| 검출·추적 | `tracks.csv` 생성 | raw detection 별도 보존, 객체사건 GT 매칭 |
| 필터 | `filtered_tracks.csv` 및 요약 | 실제 객체 생존율·오제거율 |
| 병합 | `filtered_tracks_merged.csv` 및 link 보고 | fragmentation·ID switch·오병합 검증 |
| ROI 위험후보 | `events.json` | 단위 정합, 궤적 교차점 기반 PET 검토 |
| 횡단사건 | 미구현 | 접근·대기·진입·차로통과·완료 상태 |
| 상호작용사건 | 미구현 | 보행자-접근차량 pairing 및 완전한 분모 |
| PDI 개념시험 | 미구현 | 30분 간이절차, 수동확인 사건만 잠정 DPD |

## 단계별 품질 게이트

### Gate 0 — 기준선 동결과 단위 점검

- 기준 영상·구간·FPS·모델·임계값·체크섬 기록
- Homography 출력좌표의 실제 단위 확인
- 픽셀 임계값과 실세계 임계값 분리
- 기존 결과를 덮어쓰지 않는 출력 버전 규칙 확정

### Gate 1 — Ground truth와 평가도구

- 객체사건 및 횡단/상호작용 사건 CSV 스키마
- 실제 객체와 자동 트랙 매칭 규칙
- event recall, complete trajectory recall, time coverage
- fragmentation, ID switch, maximum missing gap
- stage-by-stage survival rate

이 Gate에서는 모델·FPS·필터 임계값을 변경하지 않는다.

### Gate 2 — 객체·궤적 품질

- 보행자와 차량을 분리하여 평가
- 원시→필터→병합 각 단계의 실제 객체 생존과 오탐 변화 비교
- 내부 목표값은 `internal_provisional_gate`로 기록
- 게이트 미달 시 안전지표 공식 추가보다 누락 원인을 우선 개선

### Gate 3 — 횡단사건과 상호작용쌍

- 보행자 접근·대기·진입·횡단·완료 사건 생성
- 각 횡단사건에 관련 접근차량 연결
- 사람이 확인한 실제 조우 대비 양쪽 유효궤적 확보율 산출
- 후보 생성 전후 결과와 제외사유 보존

핵심 지표:

\[
\text{상호작용쌍 관측률}=
\frac{\text{양쪽 유효궤적이 확보된 실제 조우 수}}
{\text{사람이 확인한 실제 보행자-차량 조우 수}}
\]

### Gate 4 — 행동 및 SSM 검증

- 양보·감속·정지·대기시간 규칙 검증
- PET 정의를 ROI 점유간격과 궤적 교차점 기반 값으로 구분
- TTC의 일정속도 가정, 적용시점, 최소거리와 단위 명시
- 사건별 precision·recall 및 수동검토 상태 보고

### Gate 5 — 30분 PDI 개념 반영형 간이분석

- 정식 지점 PDI와 안전등급은 산출하지 않음
- A/B 선후관계 및 A0/A1/B0/B1/B2 분류 가능성 검토
- \(S_m,V_m,V_x,a_5\) 또는 명확히 이름 붙인 대리변수 산출
- 수동 확인되고 실세계 변수 품질을 충족한 사건만 `provisional_dpd`
- B2 수정식과 `formula_version` 저장
- 표본기간·좌표·속도·분모·한국 적용 한계를 결과에 동시 표시

### Gate 6 — 전체 배치와 데모

- 앞선 게이트 통과 후 고정 설정으로 실행
- 출력 스키마·파라미터·체크섬 검증 후 재개/건너뛰기
- 실제 결과, 미검증 후보, 예시자료를 UI에서 구분
- GPU 없는 환경에서도 사전계산 결과 재생

## 완료조건

각 구현단계는 관련 테스트 통과, 동일 표본의 기준선 비교, 변경 설정과 파이프라인 단계 보고, 재현 가능한 예제 출력, 짧은 검증요약 및 `DECISION_LOG.md` 기록을 모두 충족해야 완료로 본다.
