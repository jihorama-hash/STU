# COCO 트랙 연속성 보정 결과

작성일: 2026-07-31 KST  
대상: `DJI_0482` 전체 시간축의 7개 독립 구간

## 적용 규칙

동일 클래스의 두 트랙 사이에 겹침이 없고 아래 조건을 모두 만족할 때만 앞 트랙의
ID로 병합했다. 원본 `track_id`는 `original_track_id` 열에 보존했다.

- 단절 시간: 0초 초과 0.75초 이하
- 중복 시간: 최대 0.75초, 동일 프레임 발점 중앙거리 40px 이하
- 속도 외삽 위치 오차: 70px 이하
- 이동 방향 변화: 35° 이하
- 속력 비: 2.0 이하
- 객체 폭·높이 비: 2.0 이하
- 각 트랙에서 속도를 산출할 관측값이 최소 2개 존재

동일 종점 또는 동일 시작점에 복수 후보가 있으면 종합 오차 점수가 가장 낮은
일대일 연결만 허용한다.

보정은 외형 임베딩을 사용하지 않는 보수적인 운동 기반 연결이다. 0.75초보다 긴
가림이나 서로 매우 가까운 동일 클래스 객체의 교대는 자동 병합하지 않는다. 향후 전체
영상 분석에서는 병합 보고서를 보존하고, PET 후보에 직접 관여하는 연결만 우선 수동
검토한다.
