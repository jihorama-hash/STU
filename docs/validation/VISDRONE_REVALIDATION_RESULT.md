# VisDrone 새 독립 구간 재검증 결과

작성일: 2026-07-31 KST  
영상/구간: `DJI_0482.MP4`, 220–280초  
상태: 제외 마스크 적용 후 재검증 완료

## 조건

기존 대표구간(150–210초)과 1차 독립 구간(0–60초)에 겹치지 않는 60초를 사용했다.
두 모델 모두 원본 4K, 유효 14.985fps, 1024 슬라이스 15개, confidence 0.15,
동일 ByteTrack 조건으로 처리했다.

1차 독립 검증에서 확인된 두 고정 오탐 위치에 좁은 차량 제외 마스크를 추가했다.
차량 트랙 관측점의 50% 이상이 마스크 안에 있을 때만 제거했다. 1차 검증의 실제 차량
표본 18개는 모두 보존되고 목표 고정 오탐 2개는 제거됨을 사전 확인했다.

VisDrone은 COCO가 포착하지 못한 수동 기준 motorcycle `#1169`를 포착했다. 다만
VisDrone `bus #31`은 화면 우측 하단 횡단보도 표시를 약 5초간 bus로 유지한 오탐이다.
이 위치는 새 제외 마스크 대상과 다른 곳이다.

30개 표본과 5개 기준 트랙은 전체 데이터의 불편 precision/recall 추정치가 아니라
품질 게이트용 표본과 reference-track coverage다.

## 판정

VisDrone은 속도 저하 없이 장기 person 트랙과 수동 기준 coverage를 다시 개선했다.
하지만 표본 precision은 COCO보다 3.3%p 낮아 사전 기준인 최대 3%p 저하를 0.3%p
초과했다. 또한 새 위치의 고정 오탐이 남아 위치별 제외 마스크를 계속 추가하는 방식만으로
일반화 문제를 해결할 수 없음이 확인됐다.

따라서 VisDrone V2의 전체 영상 기본 적용과 V3 학습은 계속 보류한다. 다음 단계는
고정 오탐 위치를 추가로 외우는 마스크 확장이 아니라, 트랙의 위치 분산·속도·박스 형태와
정적 배경 일치도를 결합한 고정 객체 판별기를 별도 검증 세트에서 개발하는 것이다.
데모에서는 COCO를 기본으로 유지하고 VisDrone은 비교용 `experimental` 결과로 표시한다.
