# 객체 인식·궤적 재현율 검토 및 개선 방법 보고서

작성일: 2026-08-07 KST
상태: 방법 검토 단계 — 개선 구현 및 전체 재분석 미착수
대상: 무신호 횡단보도 드론 영상의 객체 검출·추적 및 안전성 분석

## 1. 보고 목적

총 재생시간 약 30분인 대상 영상을 검토하는 과정에서 보행자와 차량의 객체 인식률 및
궤적 연속성이 예상보다 낮을 가능성이 확인됐다. 객체나 궤적이 충분히 포착되지 않으면
PET, TTC 또는 새로 도입할 안전지표도 실제 위험을 과소평가할 수 있다.

본 보고서는 즉시 모델을 교체하거나 전체 영상을 재처리하기 위한 실행안이 아니다. 현재
파이프라인을 다시 정리하고, 객체·궤적 재현율을 영상 처음부터 시간순으로 측정하는 방법과
성능 미달 시 적용할 수 있는 개선 대안을 비교하기 위한 검토 문서다. 구체적인 변경과
재분석은 본 방법을 충분히 검토하고 평가 기준을 확정한 뒤 시작한다.

## 2. 핵심 판단

1. 현재 119건의 자동 위험 후보와 56건의 1차 검토 대상은 전체 실제 사건의 전수목록이
   아니라 현재 모델이 찾아낸 후보로 해석해야 한다.
2. 안전지표를 변경하기 전에 객체 검출, 추적, 필터, 사건 생성 중 어느 단계에서 실제
   객체가 누락되는지 구분해야 한다.
3. 기존 검증은 표본 precision과 일부 수동 기준 트랙 coverage를 확인했지만, 모든 실제
   객체를 분모로 한 완전한 recall 검증은 아니었다.
4. 영상 전체에 프레임별 박스를 새로 그리는 방식보다, 각 영상을 처음부터 끝까지 확인하는
   사건·궤적 단위 전수검토가 현실적이다.
5. 안전사건 선별 단계는 오탐을 일부 허용하더라도 재현율을 우선하고, 최종 판정 단계에서
   사람 검토로 정밀도를 확보하는 이단계 구조가 적합하다.

## 3. 현재 적용 파이프라인

현재 기준선은 단일 종단간 모델이 아니라 다음 단계의 조합이다.

`COCO YOLO11m → 슬라이스 검출 → 클래스별 ByteTrack → 규칙 기반 필터 → 분절 병합 → PET/TTC 후보 생성`

### 3.1 객체 검출

| 항목 | 현재 값 |
|---|---|
| 검출 모델 | Ultralytics YOLO11m |
| 가중치 | `models/yolo11m.pt` |
| 학습 기반 | COCO 사전학습, 현장 영상 미세조정 없음 |
| 입력 영상 | 원본 4K |
| 처리 주기 | 원본 2프레임당 1프레임, 유효 약 14.985fps |
| 슬라이스 | 1024×1024, 프레임당 15개 |
| 슬라이스 중첩 | 0.20 |
| 검출 confidence | 0.15 |
| 클래스별 NMS IoU | 0.50 |
| 대상 클래스 | person, bicycle, car, motorcycle, bus, truck |

현재 코드는 SAHI와 유사한 방식으로 슬라이스를 직접 생성하고, 각 타일의 검출을 원본 좌표로
복원한 뒤 클래스별 NMS를 적용한다.

### 3.2 객체 추적

| 항목 | 현재 값 |
|---|---|
| 추적기 | Supervision ByteTrack |
| 구성 | 프로젝트 표준 클래스별 별도 추적기 |
| 트랙 활성 임계값 | 0.15 |
| 최소 매칭 임계값 | 0.80 |
| 소실 트랙 유지시간 | 3.0초 |
| 최소 연속 프레임 | 1 |
| 위치 기준점 | 검출 박스 하단 중앙점 |

현재 구성에는 객체 외형 임베딩을 이용한 ReID가 없다. 같은 차량이 프레임마다 `car`,
`bus`, `truck` 등으로 다르게 분류되면 클래스별 추적기 사이에서 ID가 분절될 수 있다.
또한 3초의 lost buffer는 재등장 객체를 기존 트랙과 다시 연결할 기회를 제공할 뿐, 검출이
없는 구간에 실제 관측 박스를 생성하지 않는다.

검출 단계와 트랙 활성 임계값이 모두 0.15이므로, 0.15 미만의 저신뢰 박스는 ByteTrack에
전달되지 않는다. 따라서 저신뢰 검출을 기존 트랙에 재연결하는 ByteTrack의 장점이 제한될
가능성이 있다.

### 3.3 트랙 필터와 분절 병합

원시 트랙에는 다음 필터가 적용된다.

- 지속시간 0.5초 미만 제거
- 발점 좌표의 공간확산 15픽셀 미만 제거
- 차량 제외 마스크 점유율 0.5 이상 제거
- 차량의 도로 마스크 점유율이 0.1 미만이면 제거
- 단, 도로 밖에서도 50픽셀 이상 움직인 차량 트랙은 예외 보존

필터 후 같은 클래스의 트랙은 시간 간격 0.75초, 예측 위치 오차 70픽셀, 방향 변화 35도,
속도·크기 비율 2배 등의 조건으로 병합된다.

현재 저장소에 있는 7개 전체 분석 결과에서는 원시 트랙 3,355개 중 1,301개가 필터 후
남았고, 2,054개가 제거됐다. 이후 63개 분절 연결을 수행해 1,238개 트랙이 남았다. 약 61%의
제거율은 곧바로 낮은 정확도를 뜻하지는 않지만, 실제 보행자나 짧은 횡단 궤적이 필터에서
함께 제거됐는지 반드시 확인해야 할 규모다.

## 4. 기존 모델 비교 결과의 해석

### 4.1 COCO YOLO11l

YOLO11l은 동일 대표 구간에서 YOLO11m보다 약 27% 느렸으며, 차량 트랙 일부는 개선됐지만
보행자 장기 궤적과 분절 지표는 개선하지 못했다. 따라서 모델 크기만 키우는 방법은 현재
우선 대안으로 보기 어렵다.

### 4.2 VisDrone 미세조정 YOLO11m V2

VisDrone V2는 소형 보행자, 장기 보행자 트랙 및 일부 오토바이 포착을 개선했다. 대표
구간에서는 5초 이상 person 트랙이 10개에서 46개로 증가했고, 독립 구간에서도 COCO가
놓친 기준 객체를 추가 포착한 사례가 있었다.

다만 독립 검증의 표본 precision이 COCO보다 약 3.3~3.4%p 낮았고, 수목·횡단보도 표시
등을 장기 차량으로 추적하는 오탐이 나타나 전체 적용이 보류됐다. 기존 결정은 합리적인
precision 관리였지만, 안전사건 선별이라는 새 목적에서는 VisDrone 결과를 COCO의 누락을
보완하는 보조 후보로 다시 평가할 필요가 있다.

## 5. 전체 영상의 시간순 검토 방법

### 5.1 검토 단위

전체 재생시간이 약 30분이면 유효 15fps 기준으로 약 2만 7천 프레임이다. 전 프레임 완전
라벨링도 불가능한 규모는 아니지만, 화면에 등장한 모든 객체에 박스와 ID를 부여하면 단순
재생보다 훨씬 많은 시간이 필요하다. 먼저 사건·궤적 단위로 전수검토하고, 필요한 구간만
프레임 단위로 정밀 라벨링하는 방식이 효율적이다.

각 영상을 처음부터 끝까지 시간순으로 확인하고, 프레임이 아니라 실제 객체의 출현 또는
횡단을 하나의 사건으로 기록한다. 총 재생시간이 약 30분이므로 일부 구간을 표본으로 먼저
판정하기보다 전체 영상을 순서대로 1차 전수검토하는 방법을 우선한다.

### 5.2 원본 우선 판독

자동 오버레이를 먼저 보면 검출되지 않은 객체를 사람도 놓칠 수 있다. 다음 순서를 고정한다.

1. 자동 검출을 표시하지 않은 원본 영상으로 실제 객체와 횡단사건을 기록한다.
2. 실제 객체의 등장·이탈 시각과 주요 구역 통과 시각을 기록한다.
3. 이후 원시 YOLO 검출, ByteTrack 원시 궤적, 필터 후 궤적, 병합 후 궤적을 차례로 대조한다.
4. 어느 단계에서 객체 또는 궤적이 사라졌는지 기록한다.
5. 판단이 어려운 사건만 프레임 단위 정밀 라벨링 대상으로 분리한다.

### 5.3 객체·궤적 판정값

| 판정값 | 정의 |
|---|---|
| `complete` | 실제 관측 구간 대부분을 동일 ID로 정상 추적 |
| `partial` | 실제 객체는 포착했지만 궤적의 주요 구간이 누락 |
| `missed` | 원시 검출에서 전혀 포착하지 못함 |
| `fragmented` | 한 실제 객체가 여러 ID로 분절 |
| `id_switch` | 서로 다른 실제 객체 사이에서 ID가 전환 |
| `class_error` | 실제 클래스와 자동 클래스가 다름 |
| `filtered_out` | 원시 트랙은 있으나 규칙 기반 필터에서 제거 |
| `merge_error` | 다른 객체를 병합하거나 같은 객체 병합에 실패 |
| `not_observable` | 가림·화질로 사람도 신뢰성 있게 판독할 수 없음 |

### 5.4 권장 기록 필드

- `video_id`
- `ground_truth_object_id`
- `object_class`
- `first_visible_seconds`, `last_visible_seconds`
- `crossing_entry_seconds`, `crossing_exit_seconds`
- `origin_zone`, `destination_zone`
- `occlusion_condition`
- `matched_raw_track_ids`
- `matched_filtered_track_ids`
- `matched_merged_track_id`
- `track_status`
- `visible_duration_seconds`
- `detected_duration_seconds`
- `maximum_missing_gap_seconds`
- `fragment_count`
- `id_switch_count`
- `related_vehicle_ground_truth_id`
- `review_notes`
- `reviewer`

전체 객체 목록과 자동 결과의 매칭은 별도 표로 관리하고, 모델 학습용 프레임 박스 라벨은
`missed`, `partial`, `id_switch` 및 정상 대조 표본에 한해 추가한다.

## 6. 측정 지표

### 6.1 객체 사건 재현율

`자동으로 한 번 이상 포착한 실제 객체 수 / 사람이 확인한 실제 객체 수`

프레임 단위 recall보다 먼저 확인할 지표다. 보행자, 자전거, 오토바이, 자동차 계열을
분리하고 영상·구역·가림 조건별로 산출한다.

### 6.2 완전 궤적 재현율

`complete로 판정된 실제 객체 수 / 사람이 확인한 실제 객체 수`

한 번 검출됐더라도 횡단보도 내부 궤적이 없으면 안전분석에 사용할 수 없으므로 객체 사건
재현율과 분리한다.

### 6.3 궤적 시간 커버리지

`자동 추적된 시간 / 사람이 판독할 수 있었던 실제 관측 시간`

평균과 중앙값뿐 아니라 하위 10% 값을 함께 확인해 특정 영상이나 가림 구역의 심각한 누락이
전체 평균에 가려지지 않도록 한다.

### 6.4 궤적 연속성

- 실제 객체당 자동 트랙 수
- 분절률
- ID 전환률
- 최대 연속 누락 시간
- 횡단보도 내부 누락 시간

### 6.5 상충쌍 관측률

`보행자와 관련 차량의 유효 궤적을 모두 확보한 실제 조우 수 / 실제 보행자–차량 조우 수`

PET·TTC·양보 여부를 계산하려면 양쪽 객체가 모두 필요하므로, 안전분석 채택 여부를 판단할
때 가장 중요한 지표다.

### 6.6 단계별 생존율

실제 객체가 다음 각 단계까지 살아남은 비율을 기록한다.

`원시 검출 → ByteTrack → 규칙 필터 → 분절 병합 → ROI 사건 생성`

이 지표를 통해 검출 모델, 추적기, 필터, 사건 로직 중 어느 부분을 먼저 개선해야 하는지
결정한다.

### 6.7 잠정 내부 품질 게이트

다음 값은 외부 표준이 아니라 검토를 시작하기 위한 내부 제안값이다. 예비 검토 결과와
연구 목적에 따라 확정해야 한다.

| 지표 | 잠정 목표 |
|---|---:|
| 보행자 횡단사건 포착률 | 90% 이상 |
| 차량 사건 포착률 | 95% 이상 |
| 보행자 완전 궤적 재현율 | 80% 이상 |
| 횡단보도 내부 최대 연속 누락 | 0.5초 이하 |
| 보행자–차량 상충쌍 관측률 | 85~90% 이상 |

HOTA와 함께 DetA 및 AssA를 산출하면 검출 품질과 ID 연결 품질을 분리해 모델·추적기 비교에
사용할 수 있다. 다만 본 연구의 최종 품질 게이트는 상충쌍 관측률과 횡단 궤적 완전성을
우선한다.

## 7. 실패 단계별 개선 대안

### 7.1 원시 YOLO 검출 재현율이 낮은 경우

먼저 추가 학습 없이 다음 조건을 동일 검증 구간에서 비교한다.

| 실험 | 타일 | 중첩 | 추가 조건 |
|---|---:|---:|---|
| 기준선 | 1024 | 0.20 | 현재 설정 |
| 후보 A | 768 | 0.30 | 소형 객체 확대 효과 확인 |
| 후보 B | 640 | 0.30~0.40 | 경계 누락과 처리시간 함께 확인 |
| 후보 C | 선택된 타일 | 선택값 | 전체 프레임 검출 1회 병행 |

추가 검토 항목은 다음과 같다.

- 검출 후보 저장 임계값과 신규 트랙 활성 임계값 분리
- 검출 후보 임계값 0.03~0.05 시험
- 횡단보도와 접근로에 한해 원본 전체 프레임 처리
- COCO와 VisDrone 검출 결과의 합집합 사용
- 중복 박스 통합에서 NMS와 NMM 비교
- 영상·구역별 실제 객체 픽셀 크기에 따른 recall 분석

설정 변경만으로 목표를 충족하지 못하면 현장 영상 미세조정을 검토한다. 학습 자료는
무작위 정상 장면보다 다음 실패 사례를 우선한다.

- 수목·그림자 아래 보행자
- 원거리 소형 보행자
- 여러 명이 붙어 이동하는 장면
- 정지 또는 횡단 대기 중인 보행자
- 보행자·자전거·오토바이 혼동
- 노면표시·화단·시설물 오탐
- 타일 경계에 걸친 객체

첫 시험은 조건을 층화한 약 500~1,000프레임 규모로 시작하고, 원본 프레임과 실제 추론
크기의 타일을 함께 사용하는 방안을 비교한다. 구체적인 표본 수는 최초 3개 영상의 객체
밀도와 라벨링 시간을 측정한 뒤 확정한다.

### 7.2 필터 단계에서 실제 객체가 제거되는 경우

- 사람과 차량의 최소 지속시간·이동거리 기준 분리
- 횡단보도 내부 person 트랙은 짧아도 보존
- 대기·정지 보행자에는 이동거리 필터 미적용
- 원시·필터 결과를 모두 보존하고 안전후보 단계에서 교차 사용
- 고정 오탐은 위치별 마스크만 계속 늘리기보다 배경 정합과 시간적 정지성을 함께 사용
- 필터 임계값은 precision뿐 아니라 실제 객체 생존율을 기준으로 선택

### 7.3 검출은 되지만 ID 분절·전환이 많은 경우

- ByteTrack에 저신뢰 검출을 별도 구간으로 공급
- track activation, matching threshold, lost buffer를 독립적으로 조정
- 차량 세부 클래스를 `vehicle`로 통합해 추적한 뒤 시간 다수결로 세부 클래스 결정
- ByteTrack과 BoT-SORT를 같은 검출 결과에서 비교
- 드론 움직임이 있는 영상에서는 카메라 움직임 보정 시험
- 가림 후 재등장이 중요한 경우 선택적 ReID 시험
- 실시간 제약이 없으므로 미래 프레임까지 사용하는 오프라인 분절 병합 검토

보간 또는 예측으로 생성한 위치는 실제 검출점과 구분해 저장한다. 긴 가림 구간을 임의로
연결하면 존재하지 않은 동시점유나 PET/TTC 사건을 만들 수 있으므로 안전지표 계산에는 별도
신뢰도 표시가 필요하다.

### 7.4 객체·궤적은 충분하지만 안전사건이 누락되는 경우

- ROI 경계와 영상별 homography 정합 재검증
- 같은 큰 ROI 점유가 아니라 실제 교차 경로 기반으로 사건 생성
- 보행자–차량 조우를 먼저 생성한 뒤 PET/TTC 계산
- 양보율, 보행자 대기시간, accepted/rejected gap, 감속행태를 PET/TTC와 병행
- 원시 위험사건 건수 대신 보행자 횡단 또는 조우 100건당 비율 사용
- 안전지표마다 분석 가능 사건 수와 상충쌍 관측률을 함께 보고

## 8. 권장 개선 실험 순서

1. 최초 3개 영상으로 검토 양식, 판정 기준 및 소요시간을 확정한다.
2. 전체 약 30분 영상을 원본 우선 방식으로 처음부터 시간순으로 검토한다.
3. 원시·필터·병합·사건 단계별 재현율을 산출한다.
4. 필터 과삭제 여부를 먼저 판정하고, 필요하면 클래스별 필터를 조정한다.
5. 1024/768/640 타일, 중첩률 및 전체 프레임 검출을 비교한다.
6. 저신뢰 검출과 ByteTrack 임계값 분리를 시험한다.
7. COCO 단독과 COCO+VisDrone 후보 합집합을 비교한다.
8. 목표 미달 시 현장 영상 미세조정 모델을 시험한다.
9. 동일 검출 결과에서 ByteTrack과 BoT-SORT를 비교한다.
10. 독립 영상에 고정 설정을 적용해 최종 품질 게이트를 확인한다.
11. 기준 통과 후에만 전체 대상 영상 재분석을 시작한다.

각 단계에서는 한 번에 하나의 주요 요인만 변경하고 동일한 ground truth를 사용한다. 트랙 수가
늘었다는 이유만으로 개선으로 판정하지 않고, 객체 사건 recall, 궤적 완전성, 상충쌍 관측률,
precision 및 처리시간을 함께 비교한다.

## 9. 안전지표와 관측 신뢰성의 결합

향후 무신호 횡단보도 분석에서는 다음 지표군을 함께 검토한다.

- 노출량: 보행자 횡단 수, 차량 통과 수, 보행자–차량 조우 수
- 양보행태: 차량 양보율, 보행자 진입 후 정지율, 감속 시작 위치
- 보행자 부담: 대기시간, 거부 gap 수, 우회·후퇴 행동
- 시간간격: accepted/rejected gap 및 PET 분포
- 위험행태: 가까운 통과, 급감속 및 잠정 TTC
- 관측 신뢰성: 객체 포착률, 궤적 완전성, 상충쌍 관측률, 가림 비율

보고값은 원시 건수보다 `보행자 횡단 100건당 위험사건`, `보행자–차량 조우 100건당 양보
실패`처럼 노출량으로 정규화한다. 결과에는 `양보율 82%, 분석 가능 횡단 91/110건`과 같이
분자·분모 및 관측 가능률을 함께 표시한다.

## 13. 현재 결론

현재 결과만으로 객체 인식률이나 궤적 재현율이 최종적으로 낮다고 단정하지 않고, 원시 검출과
후처리 결과를 분리한 시간순 전수검토로 이를 먼저 정량화한다. 검출 실패가 확인되면 타일·
임계값·COCO+VisDrone 후보 병합을 먼저 시험하고, 이후 현장 미세조정을 검토한다. 추적 실패가
주원인이면 저신뢰 검출 연결, 차량 통합 추적, BoT-SORT 및 제한적 ReID를 비교한다.

품질 게이트를 통과하지 못한 상태에서는 PET/TTC나 새로운 안전지표를 확정 통계로 사용하지
않는다. 개선 이후에도 목표 재현율에 도달하지 못하면 자동화 범위를 후보 생성으로 제한하고,
사람이 횡단객체와 상충쌍을 보정하는 반자동 분석으로 전환한다.
