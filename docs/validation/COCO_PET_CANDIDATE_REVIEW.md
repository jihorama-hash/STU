# COCO PET 후보 1차 검토

작성일: 2026-07-31 KST  
대상: DJI_0482 0–60초, 150–210초

## 후보 축소

최신 COCO 필터와 좌표 정합을 적용한 초기 PET 후보는 각각 32건과 36건이었다.
동일 방향 차량 추종을 제외하기 위해 이미지 평면 속도 벡터의 최소 교차각 20°를
적용하자 각각 15건과 19건으로 감소했다.

그중 `PET ≤ 1.5초` 또는 `접근 중 TTC ≤ 3초` 조건을 만족하고 ROI·트랙 쌍 중복을
제거한 검토 대상은 각각 6건과 7건이다.

넓은 ROI의 단순 순차 점유를 줄이기 위해 ROI 내부 두 궤적의 최근접 거리를 계산하고
160px 이내 조건을 추가했다. 최종 필름스트립 판정 결과:

- 확인: 차량–차량 PET 2건
  - 41.375초: track `165/147`, PET 1.335초, 최근접 79.9px
  - 44.444초: track `147/181`, PET 1.001초, 최근접 6.3px
- 철회: 154.054초 person `#2` / car `#18`
  - 같은 큰 ROI를 순차 점유했지만 궤적 최근접 조건을 충족하지 못함
- 대표 기각 원인: 동일 차량의 트랙 분절, 서로 먼 경로, PET가 1.5초를 넘는
  TTC-only 후보

확인 2건은 `validated_events.json`에 PET 확인 사건으로 분리했다. TTC는 픽셀 평면
순간 속도 근사이므로 확인 사건에서도 잠정값이다.

## 다음 조치

확인 사건은 0–60초 구간 전용 검증 번들에만 포함한다. 현재 데모의 220–280초 번들에는
다른 구간 사건을 혼합하지 않는다.

후속 트랙 continuation 보정 결과 0–60초 트랙 수는 98개에서 96개로 줄었지만,
PET 후보 13건과 확인 사건 2건의 트랙 쌍·시각·PET 값은 모두 유지됐다. 세부 규칙과
구간별 결과는 `docs/validation/TRACK_CONTINUATION_RESULT.md`에 기록했다.
