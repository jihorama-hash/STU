기존 후보와 같은 사건으로 대조했다.

## 판정

중첩 창의 자동 후보는 총 4건이지만 모두 기존 분석에서 이미 검출된 후보다.

- 61.595초 차량–차량 후보 1건
  - 기존 60–120초 후보와 일치
  - 필름스트립에서 동일 검은 차량의 ID 중복·전환으로 이미 기각
- 217.184초 보행자–차량 후보 3건
  - 기존 210–220초 후보와 일치
  - PET 2.736–3.537초이며 TTC 조건이 없어 우선 확인 기준 미달

새로운 경계 횡단 PET/TTC 후보와 확정 사건은 모두 0건이다. 따라서 현재 확정 사건
목록은 0–60초 차량–차량 PET 2건으로 유지한다.

## 의미와 한계

이번 결과로 독립 구간의 트랙 초기화 때문에 놓친 사건은 확인되지 않았다. 다만 이는
현재 ROI, 교차각, 최근접 거리 및 최대 PET 5초 기준 안에서의 결론이다. 전체 영상의
고유 객체 수를 만들려면 여전히 구간 간 전역 ID 연결이 필요하지만, PET 사건 검증을
위한 필수 선행조건은 아니다.
