# 개선 전 원본 영상 분석 준비 점검

작성일: 2026-07-31 KST  
대상: `data/raw/before/`의 8개 영상

## 결론

8개 파일 모두 컨테이너·비디오 패킷 점검을 통과했고, 공통 형식은 3840×2160,
29.97fps, HEVC Main 10이다. 모든 영상에 DJI_0481 기준 homography가 존재한다.

DJI_0481~0487은 시작·중간·종료 대표 프레임에서 촬영 구도가 안정적이며 기존 ROI가
대체로 일관되게 정합된다. DJI_0488은 약 120초부터 드론 하강과 카메라 회전이
시작되므로 `0–118초`만 분석 가능 구간으로 사용한다.

잔여 추론은 약 2.08시간으로 예상한다. 후처리와 후보 검토 시간은 별도다.

## 전체 배치 전 필수 보정

현재 `roadway_mask.png`는 기준 영상 좌표계이고, 필터 코드는 트랙의 원본 영상 좌표에
마스크를 직접 조회한다. DJI_0482 외 영상에서는 최대 약 100px의 카메라 위치 차이가
있어 차도 경계 객체가 잘못 제거될 수 있다. 각 영상의 역 homography로 차도 마스크를
원본 영상 좌표계에 변환한 뒤 사용해야 한다.

`vehicle_false_positive_exclusion_mask.png`도 DJI_0482 표본에서 만든 마스크다.
다른 영상에 그대로 사용하지 말고 영상별로 정합한 뒤 대표 구간에서 재검증해야 한다.
이 두 마스크 문제를 해결하기 전에는 7개 영상 전체 GPU 배치를 시작하지 않는다.

## 권장 분석 순서

1. 영상별 차도·오탐 제외 마스크 생성 및 오버레이 확인
2. DJI_0486 60초 독립 시험
3. 필터 유지율과 ROI 정합 확인
4. DJI_0481, 0483_Cut, 0484, 0485, 0486, 0487 전체 분석
5. DJI_0488은 0–118초만 분석
6. 영상별 PET 후보 통합 및 보행자–차량 후보 별도 검토

## 후속 준비 완료

영상별 차도·오탐 제외 마스크 8세트를 생성하고 대표 프레임 오버레이를 확인했다.
DJI_0486 0–60초 독립 시험에서도 필터 유지율과 ROI/PET 처리가 정상 동작했으므로
전체 배치 진행 조건을 통과했다. 상세 결과는
`docs/validation/DJI_0486_MASKED_PILOT_RESULT.md`에 기록했다.

정합 확인 자료는
`outputs/validation/video_audit/all_videos_alignment_contact_sheet.jpg`와
